- `openclaw`：受管理、隔离的浏览器（无需扩展）。
- `user`：内置的 Chrome DevTools MCP 附加配置文件，用于你的 **真实已登录 Chrome** 会话。Chrome 在 OpenClaw 首次附加时会显示一个阻塞性的“允许远程调试？”提示，因此此时必须有人在电脑前。
- `chrome`：内置的 [Chrome 扩展](/tools/chrome-extension) 配置文件，用于你的 **真实已登录 Chrome** 会话。即使电脑前无人，只要通过手机也能使用，因为它是通过 OpenClaw 浏览器扩展而不是远程调试端口来驱动标签页，因此不会出现“允许远程调试？”提示。

对于代理浏览器工具调用：

- 默认：使用隔离的 `openclaw` 浏览器。
- 当现有登录会话很重要且用户 **不在电脑前**（Telegram、WhatsApp 等）时，优先使用 `profile="chrome"`（扩展）。
- 当现有登录会话很重要且用户 **在电脑前** 以批准附加提示时，优先使用 `profile="user"`（Chrome MCP）。
- `profile` 是你想要特定浏览器模式时的显式覆盖选项。

如果你希望默认使用受管理模式，请设置 `browser.defaultProfile: "openclaw"`。

## <a id="browser-panel-in-the-control-ui"></a> Control UI 中的浏览器面板

浏览器面板遵循当前会话的最新成功浏览器选项卡，包括其配置文件和主机或节点。打开浏览器预览卡会选择该卡的浏览器和选项卡。这不会更改 `browser.defaultProfile` 或其他会话的选择。如果没有会话浏览器目标，面板将使用配置的默认路由。

聊天侧面板仅显示此会话的选项卡：其代理或面板打开的选项卡，以及其对话使用的选项卡。其他会话的选项卡和在 OpenClaw 外部打开的选项卡保持隐藏。聊天会话外部的浏览器底座列出了每个选项卡。从会话面板打开的选项卡属于该会话，并遵循现有会话选项卡清理：重置或删除会话时它们关闭，空闲和每个会话限制由 `browser.tabCleanup` 控制。在该所有权存在之前从面板打开的选项卡没有记录的会话，因此它们保持打开状态，但仅显示在聊天会话之外的浏览器底座中。

该面板适合隔离的、本地管理的浏览器的视口的大小。对于现有会话 Chrome、附加扩展的浏览器、仅附加 CDP 和远程浏览器，预览会在本地缩放，而无需调整浏览器窗口或页面视口的大小。显式浏览器调整大小操作仍然可用。

当页面重新绘制时，面板实时流式传输活动选项卡。它会退回到节点路由浏览器、Chrome MCP 现有会话配置文件、缺少 Playwright 或流连接失败的屏幕截图。导航规则适用于流：导航到被阻止的地址会停止它并清除视图。

已建立的流断开连接后，面板会刷新其屏幕截图，并在短暂延迟后自动重试流。注释和检查会保留捕获的图像，直到您返回交互模式。

当 OpenClaw 可以识别浏览器的路由时，仅针对 HTTP（S） 页面 URL 出现预览卡。空白或内部页面仍然是普通的工具结果。没有页面 URL 的选项卡操作仍会更新浏览器面板的选择。沙盒浏览器结果仍然可供代理使用，但不会打开主机浏览器预览。在一个聊天活动组中重复打开同一页面会共享一张针对相同浏览器配置文件和主机或节点的预览卡。该卡会打开最近使用的选项卡；不同的页面 URL 或浏览器路由保持独立。工具元数据中可能已缩短的长 URL 会保留单独的选项卡，以避免隐藏不同的页面。展开工具活动以检查每个原始调用和结果。

如果无法访问列出的选项卡，面板会说明导航规则是否阻止了该选项卡或其地址无法验证。选择另一个选项卡、输入允许的地址或在临时查找失败后刷新。被阻止的 URL 保持隐藏状态；显示选项卡标题并不授予对其内容的访问权限。

跟随历史选项卡永远不会启动已停止的托管浏览器：新启动不能包含该选项卡。该面板显示 **Start browser**，并且当该目标不可用时，预览卡将保留其标题和 URL 而没有缩略图。单击 **启动浏览器** 启动浏览器并显示其当前选项卡。

对于 macOS 和 Linux 上的本地 `attachOnly` CDP 配置文件，当 OpenClaw 可以验证附加的浏览器是否正在使用可见窗口运行时，直接预览屏幕截图会保留活动的 Chrome 选项卡。无头浏览器和无法验证模式的浏览器保留现有的激活行为，因此屏幕截图仍然可靠。显式选项卡焦点操作仍会激活请求的选项卡。

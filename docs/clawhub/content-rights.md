# <a id="content-rights-requests"></a> 内容权利请求

如果您认为 ClawHub 上发布的内容侵犯了您的版权或其他权利，请提交 [ClawHub 内容权利 Request](https://forms.openclaw.ai/clawhub-content-rights)。

包括：

- one 或更准确的 `https://clawhub.ai/<owner>/skills/<skill>` URL
- 您的姓名、组织和联系电子邮件
- a 权益关注简要说明
- 支持证据（如果有）

ClawHub 工作人员手动审核请求，并可能联系请求者或发布者以获取更多信息。根据具体情况，受影响的内容可能会被隐藏、恢复或保持不变。

对于不涉及内容权利问题的不安全市场内容，请使用 [ 审核和帐户 Safety](/clawhub/moderation) 中描述的正常报告流程。对于ClawHub本身的漏洞，请参阅[Security](/clawhub/security)。

# <a id="acceptable-usage"></a> 可接受的用法

ClawHub 托管 OpenClaw 的技能、插件、包和市场元数据。使用此页面来决定内容或发布行为是否属于ClawHub。

这些规则适用于列表的用途、要求用户运行的内容、列表如何代表自身以及发布者如何使用 ClawHub 的发现、安装和信任界面。有关审核状态和帐户信誉，请参阅 [ 审核和帐户 Safety](/clawhub/moderation)。有关版权或其他权利声明，请参阅 [ 内容权利 Requests](/clawhub/content-rights)。

## <a id="allowed-content"></a> 允许的内容

ClawHub 欢迎有用、易于理解且善意发布的内容。

| 类别                                         | 允许的时间                                                                                                                      |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 开发人员生产力                           | 该列表可帮助用户构建、测试、迁移、调试、记录或操作软件。                                               |
| UI、数据和自动化工作流程               | 范围很明确，所需的凭据很明确，并且有风险的操作包括审查、试运行、预览或确认路径。 |
| 防御安全、审核和滥用审查 | 该工具专为授权审查而设计，保留证据，并保持人工审批界限清晰。                          |
| 个人或团队工作流程                       | 该工作流程使用基于同意的帐户、透明设置和明确的权限。                                            |
| 维护目录                              | 每个列表都是独特的、有用的、准确描述的和合理维护的。                                                |

背景很重要。同一主题在狭隘的防御或基于同意的环境中可以接受，但在打包为滥用工作流程时则不可接受。

## <a id="disallowed-content"></a> 不允许的内容

ClawHub 不托管主要目的是滥用、欺骗、不安全执行或侵权的内容。

| 类别                                                    | 不允许                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 未经授权的访问或安全绕过                      | 身份验证绕过、帐户接管、速率限制滥用、实时呼叫或代理接管、可重复使用的会话盗窃或为未经批准的用户自动批准配对流程。                                                                                                                                                   |
| 平台滥用和禁令规避                              | 禁止后的隐形帐户、帐户变暖或耕作、虚假参与、多帐户自动化、大量发帖、垃圾邮件机器人或为避免检测而构建的自动化。                                                                                                                                          |
| 欺诈、诈骗和欺骗性财务工作流程             | 虚假证书或发票、欺骗性支付流程、诈骗外展、虚假社会证明、欺诈合成身份工作流程或未经明确人工批准的 spending/charging 工具。                                                                                                                    |
| 侵犯隐私的丰富或监视                 | 垃圾邮件、人肉搜索、跟踪、潜在客户提取以及主动外展、秘密监控、未经同意的生物识别匹配或使用泄露数据或违规转储的联系人抓取。                                                                                                                  |
| 未经同意的冒充或身份操纵       | Face 交换、数字孪生、克隆影响者、虚假角色或其他用于冒充或误导的工具。                                                                                                                                                                                                 |
| 露骨的性内容或安全无能的成年人 | NSFW 图像、视频或内容生成；第三方 API 的成人内容包装器；或主要目的是露骨的色情内容的列表。                                                                                                                                                       |
| 隐藏的、不安全的或误导性的执行要求        | 混淆的安装命令、管道到外壳安装程序（例如使用 `sh` 或 `bash` 运行的下载内容，没有明确的可审查性、未声明的秘密或私钥要求、没有明确的可审查性的远程 `npx @latest` 执行，或者隐藏列表真正需要运行的内容的元数据。 |
| 侵犯版权或侵犯权利的材料           | 未经许可重新发布他人的技能、插件、文档、品牌资产或专有代码；违反许可条款；或冒充原作者或出版商。                                                                                                                            |

## <a id="disallowed-marketplace-behavior"></a> 不允许的市场行为

ClawHub 还回顾了发布商如何使用市场。请勿使用 ClawHub 操纵发现、指标、信任信号、审核系统或用户注意力。

不允许的市场行为包括：

- bulk 发布大量省力、重复、占位符或机器生成的列表，这些列表似乎没有真正的用户价值
- 具有几乎相同的技能或插件的大量搜索或类别表面
- 发布数百个列表，但很少或根本没有使用、维护、来源清晰或有意义的差异化
- 通过自动化、自安装循环、虚假帐户、协调活动、付费参与或其他非自然行为人为夸大安装、下载、星级或其他参与指标
- 创建或轮换帐户以逃避审核、禁令、发布商限制或市场审查
- 在所有权、来源、功能、安全状况、安装要求或与其他项目或发布者的关系方面误导用户
- 反复上传已隐藏、删除或阻止的内容而不解决根本问题

大量出版并不意味着滥用。当列表明显不同、被真实用户准确描述、维护和使用时，大型目录是可以接受的。当数量与薄弱、重复、误导、未维护或人为推广的列表配对时，大型目录就会成为信任和安全问题。

## <a id="content-rights"></a> 内容权

如果您认为 ClawHub 上的内容侵犯了您的版权或其他权利，请使用 [ 内容权利 Requests](/clawhub/content-rights)。请勿使用正常的市场报告来进行版权或权利主张，除非列表也不安全、恶意或具有误导性。

## <a id="review-and-enforcement"></a> 审查和执行

ClawHub 可能会使用自动检查、统计滥用信号、用户报告和工作人员审查来识别不安全内容或滥用发布行为。信号本身并不能证明滥用；它可以帮助 ClawHub 决定需要审查哪些内容。

我们可以：

- 隐藏、保留、删除、软删除，或者在资源类型支持的情况下硬删除违规列表
- 阻止下载或安装不安全版本
- 撤销API代币
- soft-删除关联内容
- 限制发布访问
- 禁止重犯或严重违规者

我们不保证对明显的滥用行为进行警告优先的执法。请参阅 [ 审核和帐户 Safety](/clawhub/moderation) 了解报告、审核保留、隐藏列表、禁令和帐户信誉。

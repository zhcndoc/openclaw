macOS 应用程序默认使用 **Web** 体验，将网关的 [Control UI](/web/control-ui) 嵌入应用程序窗口中。要使用本机窗口和会话侧边栏，请打开 **Dashboard → 设置 → 本机 → App** 并启用 **本机体验（实验）**。将其关闭以返回网络。

此首选项适用于 **Open Dashboard**、**New Gateway Window…**、网关菜单、完整聊天打开和仪表板启动链接。切换体验会隐藏先前体验的窗口，保留其加载的草稿，并取消待打开的窗口。如果窗口可见，则会在所选体验中打开相同的网关。 **Settings…** 始终打开网页仪表板设置； **Connection…** 和 **About OpenClaw** 打开本机连接窗口；关于选择其 **About** 选项卡。

网关和帐户更改仍会刷新隐藏的仪表板窗口。保存的网络草稿可在同一网关地址和经过身份验证的帐户内恢复；它们不会复制到不同的网关、帐户或重新创建的 SSH 隧道地址。

如果仪表板无法加载，则会显示恢复页面，其中包含 **Reload** 和 **Connection Settings…**。选择 **Navigate → Reload** 或在仪表板窗口处于活动状态时按 **Cmd-R** 以重新加载其当前页面。纯文本或 JSON 正文的网关 HTTP 错误使用恢复页面；来自经过身份验证的代理的 HTML 登录页面在窗口中仍然可用。

下面的本机聊天功能连接到网关，并默认连接到所选代理的主要会话（`main`，或 `global`，当 `session.scope` 为 `global` 时）。在这两种体验中，“快速聊天”仍然是一个原生的浮动作曲家。

## <a id="conversation-in-the-native-window"></a> 本机窗口中的对话

完整的本机聊天窗口呈现连接的网关的 Control UI 聊天窗格，包括其标题、文字记录、编辑器、消息操作、卡片和侧面板。它的标题与本机侧边栏控件共享一个标题栏行；对话没有第二个本机工具栏。侧边栏、代理和会话名册、Cmd-K 调色板、菜单、窗口管理和网关选择仍然是原生的。在侧边栏或调色板中选择一个线程即可导航现有的 Web 窗格，而无需重新加载它。 **New Thread** 保留在侧边栏和 Shift-Cmd-N 上：它通过本机所有者创建会话，然后在该窗格中打开它。

Web 体验与 macOS、Linux 和 Windows 上的 Tauri 桌面应用程序共享桌面 Web 导轨和面板布局。其面板标题和内容标题占据相同的 52px 标题栏行，内容标题和栏内搜索之前有 back/forward。在 macOS 上，面板标题清除了交通灯，并且轨道在交通灯下方开始； Linux/Windows 保持导轨与顶行对齐，并保留右上角的标题按钮。会话、页面和在线都有一个尾随的折叠侧边栏按钮；折叠仅在栏杆旁边留下展开侧边栏，该栏继续拥有新会话和搜索。

Web 窗格拥有发送、草稿、队列、历史记录、读取确认、查找和导出。窗格本地键（例如 Cmd-F、Return、Shift-Return 和 Escape）会转至 Web 视图。指向设置和其他页面的链接会打开同一网关的仪表板，同时对话保持不变。

仅在当前文档报告支持后，应用程序才会显示 Web 窗格。较旧的网关 UI、准备超时或加载失败会选择现有的 Swift 聊天视图。身份验证、TLS 和网络故障仍然存在可见错误。待处理的本机发件箱工作将保留其 Swift 所有者，直至其耗尽；项目永远不会复制到网络存储中。快速聊天和 iOS 保持 Swift 聊天 UI。

为了进行比较，请在仅限开发人员的 **Debug** 选项卡中启用 **使用本机对话视图**，然后打开一个新的聊天窗口。下面的 Swift 渲染详细信息适用于该模式、后备和快速聊天。 Web 对话遵循网关的 Control UI 演示。

完整的本机聊天窗口是一个分割视图：

- **代理和线程侧边栏**：指定代理出现在可搜索线程列表上方，其中包含配置的表情符号、解析的文本头像或名字首字母、安静的选择突出显示以及加载会话中的活动和未读摘要。选择一个代理将打开其主要对话并为该代理命名线程部分；切换回来会恢复该对话的文本草稿。固定线程、网关支持的组和最近的线程保留其现有部分。下面的视图选项控制消息预览和后台会话。生成的子会话嵌套在每个部分内其父会话的下方；崩溃的父母总结了奔跑、失败、未读书的后代。上下文菜单支持会话信息、重命名、固定、分叉、read/unread、snooze/wake、archive/restore、图标和颜色、组移动、所有者分配和删除。 **Copy** 提供会话链接、预览链接、完整的 Markdown 记录和持久会话 ID。 **在 → 新窗口中打开** 打开相同的网关、代理和会话；编辑器快捷方式仅针对已解析的本地工作副本显示。具有多个共享身份的网关还提供来自 Involving me**的**Show in/Hide。右键单击自定义组标题可重命名、创建或删除组。 **New Thread** （Shift-Cmd-N） 通过 `sessions.create` 立即为选定的代理创建；其相邻的选项弹出窗口从选定的代理开始，并提供 **单独的工作副本** 以创建具有可选基本分支或提交的托管 Git 工作树。
- **窗口工具栏**：简单的对话标题和活动代理、已知的标记工作、排队或注意状态、在对话中查找以及会话操作菜单。悬而未决的问题和当前模型认证失败也引起了人们的关注；已回答或过期的问题则不会。该菜单可以重命名或分叉当前会话并更新其 pin、读取或存档状态。 **Threads…** （Shift-Cmd-S） 打开 Active/Archived 管理器，用于网关搜索、组管理、会话检查、重命名、固定、存档和恢复。使用侧边栏的 **Snoozed** 状态来查找休眠线程并提前唤醒它们。选择模式将固定、取消固定、存档或删除应用于多个活动会话，同时保持各个故障可见。单独的菜单复选标记显示或隐藏辅助推理和工具活动；两者均默认开启并在启动时被记住。
- **转录和作曲家**：居中的阅读栏使消息和作曲家在宽窗口中对齐。助理消息呈现为纯文本，没有重复的头像，用户消息呈现为静音的重音气泡。深色模式在木炭上使用更柔和的灰色文本，同时保留增强的文本对比度；增加对比度进一步提高文本对比度。圆形作曲家为选定的代理命名，从紧凑的单行高度开始，随着多行草稿增长，并使附件、模型、语音和发送控件在文本下方对齐。 **+** 菜单包含附件、分支和工具调用详细信息。选择 **+ → 附加…**，将文件拖放到 Composer 上，或将 Finder 中复制的文件粘贴到暂存附件中。该选择器包括图像、视频、音频、PDF、text/code、CSV、JSON、Markdown、ZIP 档案和 Office 文档。文件芯片显示文件名和大小，可以在发送前删除。上下文环显示令牌使用情况和会话成本，并提供 **Compact Thread**。模型菜单按提供商对模型进行分组，将固定模型和最近模型保留在顶部，并允许您固定或取消固定所选模型。 **模型登录** 位于此菜单中，并且在未列出模型时保持可用。当所选模型因其凭据丢失或无效而无法发送时，编写器旁边的内联通知会提供 **Model 登录** 和 **Retry**。临时冷却时间不会显示此身份验证通知。 **Effort**包含思考和快速响应设置。控件适应狭窄的窗口，同时保持语音和发送操作可见。返回发送； Shift-Return 插入换行符。悬停或键盘焦点时，复制、回复、收听和消息操作菜单会出现在消息下方；右键单击操作仍然可用。工具活动使用紧凑的卡片，带有明确的工作、完成、失败或无结果标签；展开卡片以读取其结果或差异。检查本机子代理从与 `/subagents list`、`/subagents info <id|#>` 和 `/subagents log <id|#>` 的父会话运行。待处理的代理问题呈现为带有单选或多选选项、自由文本 **Other** 答案、到期倒计时和共享终端状态的本机卡。空聊天提供桌面启动提示。键入 `/` 将打开由 `commands.list` 支持的斜杠命令自动完成功能，并带有 arrow/Tab/Return/Escape 键盘导航。右键单击一条消息即可复制其可见的 Markdown，而无需隐藏推理。截断的助理消息还提供 **Open Full Message**，它加载可选择的 Markdown 阅读器。将 **Listen** 用于具有本地语音回退功能的网关 TTS。
- **命令面板**：按Cmd-K或选择**导航→命令面板…**在完整的本机聊天窗口中。调色板打开时其搜索字段为焦点，然后是代理、按侧边栏顺序排列的线程以及现有窗口操作：“新建线程”、“线程...”、“在对话中查找”和“导出成绩单...”。立即键入会过滤加载的标题、代理名称和可用的缓存预览，然后通过与 **Threads…** 相同的网关搜索来搜索所选代理的旧活动线程。精确匹配排名在前缀和子字符串之前。调色板线程行显示时间戳和辅助文本：首先是当前活动或注意力，然后是可用的缓存预览。代理名称仅针对属于不同代理的线程显示。 Up/Down 选择一个结果，Return 或单击打开它，Escape 关闭调色板并将焦点返回给作曲家。该命令仅使用关键的本机聊天窗口及其网关；当另一个表面是关键时，它会被禁用。网页导航没有变化。

- **在对话中查找**：按 Cmd-F 在加载的对话中搜索用户和助理文本。 Return 或 Cmd-G 移动到下一条匹配消息； Shift-Cmd-G 向后移动。所选消息将被概述并显示，而不会收到任何回复。 Escape 关闭“查找”。搜索不会获取较旧的历史记录或搜索隐藏的推理和工具有效负载。
- **语音控制**：作曲家可以启动或停止现有的macOS通话模式，而无需替换其菜单栏覆盖层。当谈话模式处于活动状态时，作曲家会显示其 listening/thinking/speaking 状态、现场音频活动和可扩展的滚动文字记录。右键单击通话按钮，选择**系统默认**或已连接的麦克风；这与语音唤醒和一键通使用的麦克风选择相同。如果选定的麦克风断开连接，活动的通话会话将恢复为系统默认值，并在下次通话模式启动时再次尝试选择。当谈话模式不拥有音频捕获时，单独的麦克风操作会记录语音注释。

按住 Cmd 键单击线程行以选择多个线程行，或按住 Shift 键单击以选择一个范围。批处理栏显示选定的计数和 **Actions** 菜单，用于将线程标记为已读或未读、在组之间移动它们、存档或恢复以及删除符合条件的线程。隐藏在折叠组内的子线程和行被排除在批处理操作之外。选择 **Done** 退出批处理模式。失败的操作会显示在受影响的行旁边，以便您可以重试。

将根线程拖动到 **Pages** 将其固定，或在固定的线程之间拖动以更改其位置。将其拖放到某个组上以将其移动到那里并取消固定它，拖放到类别分组中的未分组部分以删除其组，或者拖放到列表背景上以取消固定它，同时保留其组。拖动组标题以更改其顺序。这些操作需要对所连接的网关进行写访问； PIN 排序需要管理员访问权限。

右键单击自定义组标题并选择 **Group defaults...** 以选择该组中新会话的开始位置。使用 **Agent 工作区** 或浏览已连接网关上的文件夹。 **单独的工作副本**在网关确认该文件夹支持Git工作树后可用。更改文件夹会清除该选择；不可用的文件夹提供 **Retry** 并保持“保存”禁用状态。失败的保存会保留您的选择，以便您可以重试。

从符合条件的根线程的上下文菜单中选择 **Snooze**，以将其从 **Active** 隐藏，直到 **In 1 小时**、**In 3营业时间**、**今晚**（当地时间18：00）、**明天**（当地时间09：00）或**下周**（下周一09：00）本地）。只有在距离酒店还有一个多小时的路程时，这个夜晚才会出现；星期日省略下周，因为它与明天匹配。预设显示本地唤醒时间。状态过滤器会记住 **Active**、**Snoozed**、**Archived** 或 **All**。延后和全部显示 **Wakes** 与预定时间；从线程的菜单中选择 **Wake session** 将其提前恢复。

Snooze 由网关保存，永远不会停止运行、阻止消息或代理工具、禁用自动化或更改线程的工作树。当您发送消息或代理运行完成时，线程会在截止日期时唤醒。保留可见会话状态的系统事件和运行不会唤醒它。暂停会保留现有的 PIN 码；固定会唤醒暂停的线程，归档会清除其暂停。无法暂停已存档、子线程和受保护的主线程或哨兵线程。

侧边栏加载页面中的线程；选择 **加载更多** 以访问较旧的线程。在 **中，所有代理** 中，具有相同短密钥的对话保持独立，并在选择或更改时保留其所属代理。按住 Command 键单击或按住 Shift 键单击以选择多个根线程，然后选择 **Actions → 移动到组 → 新建组...** 以创建组并移动选择。如果某些动作失败，则该组和已完成的动作将保留；受影响的行显示错误，以便您可以重试。键入会立即过滤加载的行，然后在网关上搜索会话名称、元数据和消息。结果按相关顺序显示。通知解释了邮件索引何时仍在进行或存档的记录被排除。列表或搜索失败后选择 **Retry**。当同一网关重新连接时，加载的行保持可见。

将鼠标悬停在线程上或使用键盘将其聚焦到该行以查看详细信息卡。如果可用，它会显示会话的年龄、人员、频道、工作区、拉取请求状态、进度以及最后一条消息预览或代理记事本。进入卡片以跟踪其链接；按 Esc 键将其关闭并返回到该行。这些卡可在完整的本机 macOS 侧栏中找到。

侧边栏和新线程选择器会使用配置的名称或代理 ID 立即显示代理名册。已解析的身份会在每个代理到达时进行更新，包括工具栏副标题和作曲家，而不会延迟选择。配置的名称保持优先；网关的默认身份是 **Assistant**。重新连接或身份更改后，文本和表情符号头像会刷新为相同的目录。徽章最多显示两个完整的字符，保留表情符号序列。代理行和跨代理页面显示配置的图像（如果可用），回退到文本或姓名首字母。会话详细信息卡还可以为代理和参与者显示经过身份验证的图像。

文件附件通过持久发件箱保留其原始文件名、MIME 类型和字节。入场使用网关公布的图像和文件大小限制。文件限制还限制了一封邮件中所有附件的组合字节数，并在调整大小后对图像进行计数。超出剩余预算的文件不会进入草稿；发送录取重新检查总数并保持超大草稿完好无损。对于不公布限制的旧版网关，本机聊天将非图像文件和组合附件预算限制为 19,464,192 字节（25 MiB 帧的解码预算），并在调整大小后将处理的图像限制为 5 MB。图像源读取有一个单独的 64 MiB 上限来绑定调整大小输入内存；当调整大小的 JPEG 适合图像和批次预算时，可以发送该上限内的更大源照片。空或无法读取的文件显示 **无法附加**；超大文件显示 **太大而无法发送**，并具有受影响的文件名。录制的语音笔记保持其单独的录音流程。历史记录刷新后，已发送的上传仍然可见；尚不支持从本机历史记录下载入站上传。助理生成的托管文件保留其 **下载文件** 操作。

从菜单栏锚定的紧凑聊天面板保持紧凑的单栏布局，并在同一行内提供相同的模型、思考、详细程度和 Fast 控制项，同时还包含起始提示、Talk Mode、语音笔记和 Listen。助手推理和工具活动在这个紧凑界面中仍然保持隐藏。

本机聊天保留 Markdown 段落分隔符，包括列表之前和响应流式传输时。

在完整的 macOS 聊天窗口中，完成的评论、推理和工具工作折叠成 **Worked for…** 在答案上方披露。展开检查工作；最终文本、图像和其他附件保持可见。主动轮流、没有最终答案的工作以及在答案保持扩展后未解决或失败的工作。工作保持在转发的消息、新的输入和历史分隔符的一侧。在对话中查找可在搜索时扩展文字记录。本演示文稿适用于主要代理对话和新线程，无需更改存储的历史记录或记录导出。

子代理活动在其整个生命周期中使用一种爪形：排队时静音且静止，运行时动画，完成后短暂变绿，取消后变暗。失败的任务会添加一个小警告徽章；超时任务添加一个琥珀色时钟。将鼠标悬停可查看确切状态，VoiceOver 也可以查看该状态。名称不包含状态后缀，未命名的任务显示为 **Subagent**。减少运动使运行的爪保持静止。现有的详细信息扩展和已完成任务保留不变。

## <a id="message-times-and-models"></a> 留言次数及模型

已完成的消息组会在消息使用情况旁边显示安静时间标签。最近的消息使用相对时间；至少一周前的消息会显示紧凑的本地日期，包括需要时的年份。将鼠标悬停在时间上可查看完整的日期、时间和时区； VoiceOver 也读取这些确切的详细信息。助理回复还会显示记录中记录的原始模型（如果已知）。更改作曲家的模型不会重新标记之前的回复。直播、评论和工具活动不会获得时间戳页脚。

## <a id="thread-view-options"></a> 线程视图选项

打开 **查看本机侧边栏**Threads**标题右侧的选项**。当您更改选项时，**Filters** 面板保持打开状态。选择 **Active**、**Snoozed**、**Archived** 或 **All** 线程。当有多个共享身份可用时，展开 **Owners** 以搜索所有者、选择您自己或选择 **涉及我**。该按钮对活跃所有者和状态过滤器进行计数； **Reset** 恢复默认值。

**按**分组提供**类别**、**项目**、**人**和**无**；当网关支持多个所有者时，会出现 **Person**。 **H隐藏空组**可以隐藏空目标**按所有者过滤**时，**始终**或**从不**。默认为**排序→创建**，最新线程优先；没有创建日期的线程遵循有日期的线程。选择 **Last Updated** 按最近活动排序，或选择 **People** 按所有者排序（如果可用）。固定螺纹保持其固定顺序。这些选择将保存在本地以供应用程序配置文件使用。

行将未读、正在运行、已排队和注意指示器放置在标题之前。预览关闭时，链接的频道名称保持可见。子行显示运行时间（如果可用）。会话图标将支持的命名字形渲染为本机符号并显示表情符号；自定义 SVG 图标使用默认会话字形。徽章标识共享草稿、隐身会话、分叉、存档会话和云放置，包括磁盘压力和工作区冲突。将鼠标悬停在一行上或给予键盘焦点即可显示 **Pin**/**Unpin** 和 **Archive**/**Restore** 操作。

通过支持网关 UI，行还显示 Web 侧边栏的未发送草稿铅笔以及需要注意的发件箱消息的计数，包括该 Web 窗口中的其他对话。 **更多操作…** 打开所选线程的 Web 操作菜单，包括插件操作和 **停止云工作线程…**（如果可用）。确认、进度和错误保留在网络对话中。较旧的网关 UI 保留其现有的对话行为，而无需这些额外功能。

从侧边栏存档可提供 **Undo** 六秒；将鼠标悬停或聚焦通知会暂停倒计时。撤消可恢复捕获的线程及其之前的引脚状态，包括部分批处理存档中的成功线程。当网关确认恢复时，恢复的线程返回活动列表。当您更改对话、过滤器或代理时，它仍然可用，并使当前对话保持选中状态。重新连接会退出该操作；如果在撤消之前替换了线程，则失败仍然可见。

默认情况下，**显示消息预览**、**显示自动化会话**和**显示系统会话**处于关闭状态。自动化会话是 cron 对话；系统会话是从其记录的创建源中识别的。人为创建和命名的内部对话仍然可见。即使其自动化或系统类别被隐藏，所选对话仍保持可见。这些选择将保存在本地以供应用程序配置文件使用。

未命名的心跳会话也隐藏在**Show系统会话**下。命名的心跳对话仍然可见。

消息预览更喜欢网关的最新消息预览，仅当该行没有服务器预览时才使用本机转录本缓存。关闭预览会隐藏环境消息和活动文本，同时保留待批准的字幕和关键观察者状态，例如卡住或等待用户输入。问题和错误使用领先指标而不添加副标题。

选择一个客服人员以打开其主要对话。当其代理条目可用时，该对话将从线程列表中省略，并且其加载的子项仍可访问。如果代理目录不可用，主线程将保留在列表中以供恢复。

展开线程以加载其子对话。子代理运行向其父代理提供状态，同时持久后代保持可导航；分配到某个组的孩子会出现在该组中。扩展最初显示四个子级，加上选定或活动的分支以及具有未读消息、失败的后代、工作区冲突或注意请求的分支。 **显示更多** 显示所有已加载的子项；折叠并重新打开以返回紧凑列表。失败或不完整的子项读取提供 **Retry** 并保留先前加载的子项。当子级读取返回较少的行时，扩展还会保留线程名册中已知的子级。所选状态过滤器适用于子级和根级。

选择 **所有代理** 以按配置的代理顺序查看可扩展名册。固定线程保留在花名册上方的 **Pages** 中，显示其所属代理的头像，并保留其可扩展子级，即使该代理折叠时也是如此。 **选定的代理** 返回该代理的引脚、组和线程。

每个代理标题都会打开其主聊天。其菜单提供**新会话**、**打开主聊天**、**所有会话**和**折叠其他**。 **所有会话** 打开该代理的线程管理器，而不更改活动聊天或草稿。扩展标题总结了家庭活动；折叠的标题还总结了他们隐藏的对话。使用**显示更多**和**查看更少**来调整可见行。每个网关的范围和折叠标头都会被记住。扩展页面总结了它们自己的活动和隐藏的子代理运行；可见的孩子会表现出自己的信号。断开连接时运行指示器暂停。对于所有代理概述之外的较旧线程，请切换到 **所选代理** 并选择 **加载更多**，或搜索 **所有会话**。

## <a id="session-catalogs"></a> 会话目录

插件可以将会话目录添加到本机侧边栏。 **在OpenClaw**中打开打开对话；发送第一条消息时将其放入 OpenClaw 中。采用的会话保留在其目录部分中，在普通线程列表中没有重复项。目录显示选定代理的目录，并隐藏在所有代理和存档视图中。所采用的会话在 **搜索结果** 中仍然可访问，与折叠的目录组无关。采用的行遵循侧边栏状态过滤器，包括存档和暂停更改。目录源需要读取权限；删除源会话也需要写访问权限。

右键单击目录标题可按 **Project**、**Person** 或 **None** 对会话进行分组，按所有者进行筛选，或从以下位置选择 **Hide侧边栏**。通过 **查看选项→会话目录** 下的切换来恢复隐藏目录。 **在同一菜单中显示所有所有者** 会清除所有者筛选器，即使它没有留下任何目录行。每个网关配置文件的分组和可见性都保存在本地。这故意与网络侧边栏不同，网络侧边栏通过仪表板设置恢复隐藏目录并将首选项存储在浏览器中。

**会话源…** 打开同一网关的仪表板外观设置，您可以在其中管理会话源。本机切换会打开页面，而无需滚动到会话源设置块。不提供 **在终端中打开** ，因为本机侧边栏没有目录终端操作。当侧边栏可见并连接时，目录会刷新； **加载更多**和**重试**对每个目录独立操作。通过 **Retry**，源故障保持可见，包括在源返回其第一个会话之前。

## <a id="online-people"></a> 在线人

本机侧边栏的 **Online** 部分包括您自己的身份并区分活动、空闲和未观察到的活动。将其折叠成紧凑的面堆。打开和正在运行的会话计数来自跨代理的网关，与加载的线程列表无关；不可用计数保持未知状态，并在失败后提供重试。

将鼠标悬停或聚焦于某人以检查报告的连接、交互时间和可见的会话链接，包括加载了 **的线程加载更多**。当卡打开时，最近的链接会保留在原处，如果它们不符合资格，则会消失。 **查看活动** 在同一网关的仪表板中打开该人员的活动页面。线程行显示其他查看者，组合重复的连接并排除您自己的身份。

原生侧边栏底部的身份证使用您来自 **Online** 的姓名和头像。健康时，它会显示当前网关的名称和 **Primary**（如果适用）；否则显示 **Connecting…**。单击它可查看网关列表、当前指标和主要指标、使符合条件的配置文件成为主要指标的选项、**管理网关…**、**打开仪表板**、**设置…**、 **使用**和**关于OpenClaw**。 **立即重试** 在断开连接时出现。相邻的关注按钮将与最旧的待处理请求（问题或批准）相同类型的请求计数；单击它以获取详细信息而不改变对话。如果线程组加载失败，则会出现单独的重试按钮。批量操作位于页脚上方。

## <a id="pending-questions-and-approvals"></a> 待决问题和批准

线程行、代理行和折叠的组标题显示最旧的待处理请求的问题或批准按钮。父线程包括来自其后代的待处理请求。将鼠标悬停在预览和同类其他请求的数量上，或激活按钮以阅读完整预览，而无需切换对话。 VoiceOver 公开了相同的细节。

批准预览包括来自窗口网关的命令、插件和系统代理请求。它们在重新连接后刷新，并在解决或过期时清除。同一网关的多个窗口共享该队列；不同的网关连接将其请求分开。预览请求不会批准该请求，也不会扩展现有批准界面中可用的操作。

## <a id="sources"></a> 来源

本机聊天和快速聊天中的完整答案会显示最多八个紧凑的 **Sources** 卡片，用于在答案运行期间由 Web 搜索或 Web 获取返回的引用页面。单击卡片以在弹出窗口中检查记录的 **搜索片段** 或 **页面摘录** ，然后选择 **开源** 访问该页面。没有记录摘录的卡片是这么说的；打开源预览不会再次检索页面。

源图标遵循网关的自动图标偏好并使用其经过身份验证的图标服务，在禁用或不可用时显示地球仪。会话链接和 GitHub 问题或拉取请求链接保留其现有卡。

## <a id="diagrams"></a> 图表

已完成的标记为 `mermaid` 的围栏块在本机聊天（包括快速聊天）中呈现为图表。使用捆绑资源在本地运行渲染。当栅栏的结束分隔符到达或响应完成时，栅栏就完成了；不完整的流栅栏仍然是代码。

使用右上角的小选项按钮查看或复制源并展开图表。复制按钮也会出现在悬停或键盘焦点上。单击图表可打开其矢量预览，您可以在其中缩放和平移。使用关闭按钮或 Esc 关闭预览。快速聊天中，关闭预览返回回复；在栏及其预览外部单击会关闭“快速聊天”。

无效或过大的图表可以保持源代码的可读性。临时渲染失败在选项菜单中提供 **重试图**。

## <a id="session-colors"></a> 会话颜色

右键单击边栏中的会话，或打开其菜单栏会话子菜单，然后选择 **Color**。选择红色、蓝色、绿色、黄色、紫色、橙色、粉色或青色。 **Default** 清除颜色。

彩色会话在侧边栏和菜单栏行中具有狭窄的前导条纹。打开的聊天标题使用带标签的活动状态而不是色点。未设置的颜色不显示条纹。网关存储颜色名称，而不是十六进制值；该应用程序会根据浅色和深色外观调整其色调。

## <a id="multiple-gateway-windows"></a> 多个 Gateway 窗口

打开 **Connection… → Gateways** 以添加或删除可重用网关配置文件。每个配置文件包含一个专用网络 `ws://` 或安全 `wss://` 端点，具有浏览器登录或可选令牌或密码；凭证存储在 macOS 钥匙串中。在 **Add Gateway** 中输入主机名，默认为 HTTPS。对于 Cloudflare 访问，**Connect** 打开默认浏览器来建立您的个人会话。请参阅 [ 浏览器登录和网站启动链接 ](/platforms/mac/remote#connect-with-your-browser)。

安全 token/password 配置文件维护自己的系统信任门控首次使用证书 pin，并且不会从主网关继承 `gateway.remote.tlsFingerprint`。仪表板窗口强制执行相同的已保存配置文件固定策略。浏览器会话使用正常的 HTTPS 信任，并保持绑定到其经过身份验证的网关源，包括其端口。每个经过浏览器身份验证的配置文件都有自己的仪表板浏览器数据，在命名的应用程序配置文件之间隔离。手动 token/password 配置文件保留其现有的浏览器存储和首选项。使用浏览器登录会启动个人存储，而无需从共享浏览器存储复制凭据。经过浏览器验证的仪表板中的 Mac 选项卡使用单独的临时浏览器会话，由该窗口的 Mac 选项卡共享。删除配置文件会关闭其本机聊天和仪表板窗口，并关闭其辅助连接。更新已保存配置文件的凭据会刷新其打开的仪表板窗口。使用 **Reconnect** 续订过期的浏览器会话。重新连接同一帐户将保留其浏览器首选项。更改帐户或删除浏览器验证的配置文件会清除其隔离的仪表板浏览器数据；删除任何配置文件也会删除其保存的凭据。

如果图像或文件提示您 **登录以继续加载内容**，请在 Mac 应用程序中选择 **登录**。该应用程序会更新受影响网关的会话并返回到打开的对话。单独登录普通浏览器选项卡不会刷新 Mac 应用程序的单独浏览器会话。

选择 **File → New Gateway Window…** 或按 Cmd-N，然后选择一个网关。选择器包括主网关 **This Mac**（当它还托管本地网关时）和保存的配置文件。它会记住所选的网关。每个选择都会在所选的 Web 或本机体验中创建一个新的独立窗口，因此同一网关可以出现在具有不同活动会话和导航状态的多个窗口中。

主 **Gateways** 菜单始终存在。它列出了配置后的主网关，然后列出了 **This Mac**（如果可用）并保存了网关，并按 Command-1 到 Command-9 的顺序列出。选择一个项目以在所选体验中打开其窗口或将其现有窗口置于前面。按住 Option for **New … Window**，或使用 Option-Command 与相同的数字，打开另一个独立窗口。卡片显示所选体验的运行状况、版本和缩短的构建 ID、端点、延迟和打开窗口计数。浏览器验证的配置文件显示 **Access** 和会话到期。 **Primary** 徽章标识主网关，前窗口标记跟随所选体验的最前面的窗口。 **管理网关…** 打开 **连接 → 网关**，即使列表为空也是如此。对于 SSH- 隧道主节点，主行使用 SSH 主机名而不是环回隧道端点，除非匹配的已保存网关提供其名称。

右键单击 **打开仪表板** 和 **设置…** 的 OpenClaw Dock 图标。当配置多个网关时，此菜单也会列出每个网关；复选标记位于所选体验最前面的网关窗口后面。

该菜单仅在打开时检查运行状况，并在打开之间保留缓存的事实。在第一个结果之前，卡片显示 **checking…**；失败的检查显示 **unreachable** 以及已知的最后一次成功联系时间。关闭菜单会取消正在进行的检查，并关闭未打开 Web 或本机窗口的已保存网关的空闲检查连接。它永远不会断开主网关的连接。

应用程序重新启动后，还会以所选体验重新打开您选择的网关。选择 **Primary** 会将启动切换回主网关。后台连接刷新不会更改此选择。

相同保存的配置文件和浏览器帐户的 Windows 共享网关连接、脚本缓存、离线发件箱和路由租用，同时保持独立导航。更新该帐户的会话会保留其排队的消息。切换帐户会关闭旧帐户的本机聊天窗口；其缓存的历史记录和排队的消息保留在该帐户中，并且在您重新登录时可用。Token/password 配置文件保留其配置文件范围的缓存和设备身份验证。 Windows 适合不同的配置文件保持连接并同时运行聊天。

菜单栏应用程序的配置网关仍然是 Mac 节点功能和通话模式的所有者。附加网关窗口仅供操作员使用，因此第二个网关无法静默地重新定位全局麦克风或设备控制。 Listen/TTS 和正常聊天操作使用窗口自己的网关连接。内联小部件也从该窗口的网关加载。

### <a id="gateway-picker"></a> Gateway 选择器

在 Web 体验中，侧边栏身份菜单列出了 Mac 应用程序的已配置网关，以及运行状况、主要和当前选择指示器。选定的网关在其快捷方式提示的位置显示一个复选标记。前九行中的其他行按本机网关菜单顺序显示 **⌘1–9** 快捷方式；后面的行没有快捷方式提示。选择一个网关来替换同一窗口中的当前仪表板，或者按住 Command 键单击或 Control- 单击它以打开单独的仪表板窗口。 **设置为主网关...** 在确认后使查看的令牌验证配置文件成为 Mac 应用程序的主网关。该应用程序替换主网关的凭据并关闭其本机聊天窗口；独立的已保存配置文件窗口保持打开状态。当同一网关在启动时连接或重新连接时，本机聊天窗口保持打开状态。这包括使用 `--chat` 或 `--no-activate --chat` 打开的窗口。显示 **Primary** 的仪表板窗口遵循新连接，包括单独打开的窗口。连接时，侧边栏页脚还会显示当前网关并在其为主要网关时对其进行标记。可以查看仅密码和浏览器登录配置文件，但不能将其设为主要配置文件。

仪表板命令（例如“新建会话”和命令选项板）作用于最前面的网关窗口。

本机批准卡和对话框仅适用于请求它们的网关连接。更改主要网关不会将待批准的网关转移到新网关。

在仪表板中管理目标网关的通道、网关配置、技能和 cron 作业。 **Settings…** （Cmd-，） 在任一体验中打开 Web 仪表板设置； **设置 → 此 Mac** 从任何嵌入式仪表板窗口控制此 Mac 的本地功能。 **Connection…** 保持本机状态，因此您可以在没有工作仪表板的情况下修复连接。

## <a id="quick-chat-bar"></a> 快速聊天栏

按 Option-Space （⌥Space） 或从菜单栏菜单中选择 **Quick Chat** 为主会话打开浮动编辑器。打开 **Dashboard → 设置 → 本机 → App** 以更改本机录音机面板中的全局快捷方式，然后选择 **Done**。

快速聊天显示目标客服人员（头像或表情符号，以客服人员的姓名作为占位符）并发送到该客服人员的主会话。它的两行编辑器将草稿保留在附件、模型、思考、听写和发送控件之上，与网络聊天布局相匹配。 Return 接受发送后，该栏保持打开状态，并显示流式传输的 Markdown 回复和同一作曲家上方的最新文字记录。 V 形符号可展开或折叠对话，而不会清除草稿或中断回复。已完成的任务详细信息与记录一起滚动，而不是占据书写区域。按 Command-Return 键可在完整聊天窗口中发送并打开相同的目标，按 Shift-Return 键可换行，或按 Esc 键可关闭整个栏和回复区域。单击外部也会将​​其关闭。仅当需要引起注意时才会出现连接消息。当相关的 macOS 权限缺失时，附加的条带会提供 **Grant** 和 **现在不** 操作。

使用麦克风按钮可对编辑器进行语音输入。部分语音识别结果会实时替换已听写的片段，同时保留编辑器中已存在的文本。再次按下该按钮、Return 或 Escape 可停止；发送、隐藏或取消聚焦快速聊天也会释放麦克风。首次使用时会请求 macOS 麦克风和语音识别访问权限。快速聊天使用 Apple Speech，并可能使用其网络服务；只有被动的 Voice Wake 才需要设备端识别。

模型控件显示目标会话的当前模型。单独的 **Effort** 控件可打开一个阶梯式思维滑块，其中包含该模型宣传的级别，以及支持的快速模式。拖动滑块或使用箭头键选择级别； **使用会话默认值** 恢复继承的设置。上下文环显示对话的使用情况（如果可用）并提供 **Compact Thread**。模型选择会更新该会话，因此会保留在那里，而推理选择仅适用于从当前快速聊天演示文稿发送的每条消息。当栏隐藏时，本地选择会重置。切换代理或选择最近的会话会保留显式选择，但会重新加载新目标会话的基础模型状态。

点击历史记录按钮，可从最近更新的五个会话中进行选择，或返回到 **New message to &lt;agent&gt;**。选择最近的会话会发送到该准确会话，并将占位符更改为 **Reply in &lt;session&gt;**。隐藏快速聊天会将这个临时目标重置为所选代理的主会话；从头像菜单切换代理也会清除它。

Command-Return 打开在选定的 Web 或本机体验中接收发送的代理的对话，包括当会话范围是全局时。

选择 **+ → 为** 捕获窗口…**或** 捕获区域…**捕获屏幕截图**。窗口捕获标记每个可见窗口；当您拖动区域并显示其实时大小时，区域捕获会使每个显示变暗。选定的屏幕截图将发送到选定的代理，并以任何键入的文本作为其标题。首次使用需要 macOS 屏幕录制访问权限。退出、单击空白区域或单击没有有意义的区域拖动会取消。

选择 **+ → 附加来自 &lt;app&gt;** 的文本以附加来自聚焦应用程序的聚焦窗口的文本。快速聊天将结果显示为可移动的上下文芯片，而不是将捕获的文本放置在编辑器中；发送将芯片的文本附加到传出消息中，然后将其清除。这需要 macOS 辅助功能权限。每当快速聊天关闭时，附加文本也会被清除，因此一个演示文稿中的上下文不会泄漏到以后的发送中。

回复完成后，选择 **Paste to &lt;app&gt;** 可将其可见的助手文本（不包括隐藏推理）复制到通用剪贴板，并粘贴到当前前台应用中。这需要 macOS 辅助功能权限。该操作会替换当前剪贴板内容，然后隐藏快速聊天。

在 **Dashboard → 设置 → 本机 → App** 下完全禁用该功能；同一部分打开快捷方式记录器。

- **本地模式**：直接连接到本地 Gateway WebSocket。
- **远程模式**：使用已配置的直接 `ws://`/`wss://` 路由，或使用应用管理的 SSH 隧道作为数据平面。

## <a id="launch-and-debugging"></a> 启动与调试

在启动开发构建时设置 `OPENCLAW_DEBUG_CONVERSATION_BRIDGE=1`，以通过 `NSLog` 记录对话桥消息类型、修订、文档 ID、命令请求 ID 和结果。此跟踪默认处于关闭状态，并且不包括对话内容、会话名称和任意 Web 错误描述。

在 `./scripts/package-mac-app.sh` 生成 `dist/OpenClaw.app` 后，从 POSIX shell（例如 `zsh` 或 `bash`）中的存储库根运行以下命令。

仪表板启动链接也使用选定的体验。嵌入式仪表板内的链接可以通过指针单击或键盘激活来打开应用程序。代理操作和网关设置链接保留其现有的运行和连接确认规则。

- 手册：菜单栏→**打开Dashboard**，使用选定的体验。
- 测试时自动打开：

  ```bash
  dist/OpenClaw.app/Contents/MacOS/OpenClaw --chat
  ```

  （`--webchat` 作为旧版别名也可接受。）

- 背景automation/proof钻机：

  ```bash
  dist/OpenClaw.app/Contents/MacOS/OpenClaw --no-activate --chat
  ```

  `--no-activate` 将应用程序启动的窗口和面板保留在活动应用程序后面，并在整个过程中抑制应用程序激活。与`--chat`或`--dashboard`组合； `--background-only` 仍然抑制自动窗口。通过后台辅助功能驱动应用程序，并通过 ID 和 `screencapture -l <windowId>` 捕获窗口，可以捕获被遮挡的窗口。通过启动服务启动时，请使用 `open -g -n dist/OpenClaw.app --args --no-activate --chat`，这样启动器也不会留下焦点。

  工作表可能成为非活动应用程序中的关键。更新对话框、macOS 权限请求、Web 媒体权限提示和文件对话框被推迟；需要交互的钥匙串操作通过现有 error/log 路径失败。重新启动而不使用授予访问权限或选择文件的标志，然后重试自动化。外部导航（Finder、浏览器和编辑器启动）也会被延迟和记录。正常启动会保留其现有的焦点行为。

- 日志：`./scripts/clawlog.sh`（子系统 `ai.openclaw`，类别 `WebChatSwiftUI`）。

## <a id="how-it-is-wired"></a> 它是如何连接的

- 数据平面：Gateway WS 方法 `chat.history`、`chat.message.get`、`chat.send`、`chat.abort`、`chat.inject`，以及 `question.list` 和 `question.resolve`，还有事件 `chat`、`agent`、`presence`、`tick`、`health`；问题卡片遵循 `question.requested` 和 `question.resolved` 事件，并在重新连接后从 `question.list` 刷新。
- `chat.history` 返回网关准备的显示脚本：内联指令标签、纯文本工具调用 XML 有效负载（`<tool_call>`、`<function_call>`、`<tool_calls>`、`<function_calls>`，包括截断的块）和泄漏模型控制令牌被剥离。存储的助手可见性首先尊重显示、相位和最终源事实，然后省略修剪为大写 `NO_REPLY` 的原始助手文本；小写和换行形式仍然可见。用户文本永远不会被归类为静音。过大的行可以用截断的占位符替换。
- 会话：默认使用上述主会话；UI 可以在会话之间切换。
- 会话组：`sessions.groups.list`、`sessions.groups.put`、`sessions.groups.rename`和`sessions.groups.delete`拥有无路径组目录。写入范围的 `sessions.groups.defaults` 和 `sessions.groups.update` 拥有可选的新会话 folder/worktree 默认值。成员身份是通过 `sessions.patch` 更新或在 `sessions.create` 期间分配的会话 `category`。
- 未读状态：会话激活且其实时历史记录成功加载后，应用程序会清除其观察到的未读状态。在该会话已打开时创建的手动未读标记在刷新和运行完成后仍然保留；离开并重新打开会话，或将其显式标记为已读以清除它。失败的历史记录加载不会清除未读状态，并且短暂的补丁失败会在下次激活时重试。在交错升级期间，较旧的活动应用程序仍然可以发送清除标记的裸读确认。因此，跨客户端保护要求每个活跃的应用程序都支持确认合约；在依赖提醒之前更新所有连接的客户端。
- 新手引导使用一个专用会话，以便将首次运行设置与其他内容分离。
- 离线存储：最近的会话和记录被缓存在`~/Library/Application Support/OpenClaw/databases/gateway-cache.sqlite`中的每个网关中。客户端拥有的挂起命令和路由状态分别位于同一目录中的 `client-state.sqlite` 中。在连接准备好之前冷打开绘制缓存的记录，并在网关响应后刷新。

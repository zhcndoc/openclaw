有关此版本背后的故事，请阅读 [OpenClaw 2.0、Accidentally](https://openclaw.ai/blog/openclaw-2-accidentally)。

此更新涉及 OpenClaw 的各个部分，包括安装、消息传递、内存、技能、模型、自动化、浏览器和本机应用程序、插件、安全性和许多较小的修复。

下面的每个区域都有自己的页面，将面向用户的描述和完整的 PR 和提交记录保存在一起，以便有人想要深入研究时使用。

**发布规模：** 16,977 个拉取请求、698 个直接提交和 987 个贡献者。

## <a id="sections"></a> 部分

- [安装和Onboarding](/releases/2026.8.1/installation-and-onboarding) - 从下载到在Mac、Linux、Windows、iPhone、iPad和Android上进行第一次有用对话的更清晰路径，以及将会话和记录移动到SQLite中。
- [新网页UI](/releases/2026.8.1/the-new-web-ui) - 重建的Control UI将对话置于OpenClaw的中心，文件、审批、设置和现场工作都靠近对话。
- [Updates 和 Maintenance](/releases/2026.8.1/updates-and-maintenance) - 支持的更新路径在替换之前检查安装，维护工具提供更清晰的恢复路径。
- [Messaging](/releases/2026.8.1/messaging) - Telegram、Slack、Discord 和本机应用程序可以保持更多对话的完整性，并且接受的消息在托管重启后仍可保存。
- [Memory](/releases/2026.8.1/memory) - 合格的个人 Claw 可以从该代理的其他私人对话中调用相关上下文，并具有搜索、检查、导入和删除内存的可见工作流程。
- [Skills](/releases/2026.8.1/skills) - 创建、验证、查找、安装和调用技能现在遵循一条连接路径，技能研讨会保存建议、检查、决策和应用历史记录。
- [Native Apps](/releases/2026.8.1/native-apps) - iPhone、iPad、Android、macOS 和 Wear OS 使语音、附件、模型选择和对话控制更贴近工作。
- [模型和 Providers](/releases/2026.8.1/models-and-providers) - 从 OpenClaw 已有的目录中打开聊天和模型页面，并且请求保留在预期提供商和授权帐户订单中。
- [Automations 和 Scheduling](/releases/2026.8.1/automations-and-scheduling) - 代理、Control UI、命令行、文档和支持的本机应用程序中的预定工作以一个名称汇集在一起​​。
- [浏览器和计算机 Use](/releases/2026.8.1/browser-and-computer-use) - 通过隔离的托管配置文件或您共享的 Chrome 选项卡登录的浏览器会话，以及配对 Mac 和显式启用的 Windows 计算机上的计算机使用。
- [插件和Integrations](/releases/2026.8.1/plugins-and-integrations) - 管理员可以浏览、搜索、安装、启用、禁用和删除Control UI中的插件，以及策划的ClawHub技能和经过审查的MCP连接器。
- [Security 和 Privacy](/releases/2026.8.1/security-and-privacy) - 批准与接收它们的确切请求、命令、会话和人员保持关联，并且受保护的凭据可以到达受支持的目标，而无需输入模型可见的文本。
- [ 生活质量 Improvements](/releases/2026.8.1/quality-of-life-improvements) - 日常工作可以轻松查找、跟踪、移动和保护，包括过去的对话、长时间工作的可见进度以及云或配对计算机会话。
- [其他错误 Fixes](/releases/2026.8.1/other-bug-fixes) - 修复了 Codex 委托、浏览器 Talk、Copilot 和 xAI 重播、医生恢复、插件升级、会议音频等。
- [Maintainer 和内部 Changes](/releases/2026.8.1/maintainer-and-internal-changes) - 主要影响构建和维护 OpenClaw 的人员的 6,364 个更改：发布和 CI 工作、测试、内部重构和文档维护。

_版本说明：发布为 `2026.9.1-beta.1` 的包版本错误，对应于 `2026.8.1-beta.4`；它并不比稳定版 `2026.8.1`._ 新

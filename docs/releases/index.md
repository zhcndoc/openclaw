- [v2026.9.7](/releases/2026.9.7) - 负载下更快、更流畅的长时间对话、更新恢复、OpenAI 代理 API 以及使用 ChatGPT 登录（测试版）。
- [v2026.9.6](/releases/2026.9.6) - 从命令选项板启动后台任务、创建个人主题、遵循实时会议记录并保留 Telegram 组历史记录。
- [v2026.9.5](/releases/2026.9.5) - 安装支持的插件而无需重新启动，设置专家代理团队，并在会议和通话中使用 GPT Live。
- [v2026.9.4](/releases/2026.9.4) - 插件和技能发现、可见技能学习、云工作人员控件、GPT 图像 2.5 和终端问题。
- [v2026.9.3](/releases/2026.9.3) - 干净的更新恢复、更快的会话重新连接、实时浏览器自动化、可撤销的聊天链接、可搜索的会议记录和存储库支持的云工作。还包括持久的 Workshop 技能、本机 Mac 选项卡和提供商帐户控制。
- [v2026.9.2](/releases/2026.9.2) - 可靠性和恢复改进、OpenAI GPT-6 Astra 和 Meta Muse Spark 1.3 支持以及灵活的任务工作区。
- [v2026.9.1](/releases/2026.9.1) - 跨聊天界面的美人鱼图、更全面的 Android 体验、更安全的更新恢复以及长时间对话和大型安装的更低开销。
- [v2026.8.2](/releases/2026.8.2) - 工作之外的家、Linux 桌面伴侣、后台会话、无需运行网关的浏览器控制、四种新的 Control UI 外观以及集中回复、语音、更新和恢复修复。
- [v2026.8.1 （AKA OpenClaw 2.0）](/releases/2026.8.1) - 重建的 Web 体验、更简单的登录、更强的内存和会话连续性以及跨 OpenClaw 的非常大的可靠性传递。
- [v2026.7.1](/releases/2026.7.1) - 主要 Control UI 和入门大修、大 iOS、Android 和 macOS 更新、扩展模型支持以及大量 Telegram、Slack、 Discord 和 Apple 消息改进。
- [v2026.6.11](/releases/2026.6.11) - 回复、发送、 重连、模型设置、会话方面的可靠性修复，以及更安全的管理员默认设置。

没有 v2026.7.2 版本。 `v2026.7.2` 测试版以 v2026.8.1 的形式发布，因此提及 2026.7.2 测试版的页面描述的是到达 v2026.8.1. 中的人员的工作

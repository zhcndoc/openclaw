# 发行说明

这些页面将成为 OpenClaw 发布内容的面向读者版本。它们将主要故事、实际影响、源链接和贡献者致谢整合在一起，
而不需要你先浏览原始更新日志。

## 发布

- [v2026.7.1](/releases/2026.7.1) - 控制 UI 和入门流程全面改版，
  主要 iOS 和 Android 更新，扩展模型支持，以及 Gateway 恢复。
- [v2026.6.11](/releases/2026.6.11) - 回复、发送、
  重连、模型设置、会话方面的可靠性修复，以及更安全的管理员默认设置。

# v2026.10.4

AI 代理和工具可以将这些发行说明读取为 [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.10.4.md)。

OpenClaw v2026.10.4 修复了更新和恢复问题，包括睡眠或时钟更改后工作中断以及更新后聊天卡住，以及消息传递、模型工具和登录的修复。

**发布规模：** 55 个拉取请求、24 个直接提交和 49 个贡献者。

## Web UI

- **更新后聊天刷新。** 停留在“服务器已更新”上的聊天可以刷新回相同的对话链接。如果您的选项卡在更新之前已打开，请保存未保存的工作并重新加载一次以加载此修复。

  <details class="release-source-toggle release-source-inline">
  <summary>更多详情</summary>

  [#168941](https://github.com/openclaw/openclaw/pull/168941)，感谢[@steipete](https://github.com/steipete).

  </details>

- **仪表板连接。** 当繁忙的网关延迟其签入消息时，开放式仪表板可以保持连接，从而避免不必要的重新连接。请求仍然有自己的超时。

## <a id="updates-and-maintenance"></a> 更新和维护

- **睡眠和时钟更改。** 修复了计算机睡眠或向后时钟更改后不必要的中断，并在 OpenClaw 无法访问其已保存状态时提供更清晰的 [ 重新启动指导 ](/gateway/restart-recovery)。

聊天和 [ 模型页面 ](/concepts/models) 现在可以从 OpenClaw 已有的目录中打开，因此选择模型不再需要等待完整的提供商扫描。实时发现仅在您打开模型屏幕或显式刷新它时运行，在查找失败时保留最后一个有用的列表，并且 `/model` 只能更改当前对话或故意更新一个代理或共享默认值。

选择模型后，OpenClaw 将请求保留在预期提供者和授权帐户顺序内，保留流式回复和工具调用的真实顺序和结果，通过模型和运行时进行推理和上下文设置，并更清楚地报告计划窗口、令牌使用、上下文压力和估计成本。

<Accordion id="finding-and-choosing-models" title="寻找和选择模型">

聊天和 [ 模型页面 ](/concepts/models) 现在从 OpenClaw 已有的目录开始，当您打开选择器或请求刷新时，支持的提供程序会寻找更新的聊天和文本模型。如果查找失败，内置条目和上次工作列表仍然可用。

`/model` 更改可以保留在当前对话中，也可以有意应用于一个代理或共享默认值，而持久更改需要正确的权限。别名和后备使提供者和帐户附加到所选模型。

该列表显示了 OpenClaw 可以识别的模型，而提供商、帐户、区域、端点、计划、限制和定价决定了您可以使用哪些模型。

<Accordion id="provider-accounts-and-sign-in" title="提供商帐户和登录">

OpenClaw 现在将模型请求保留在 [ 提供者帐户 ](/concepts/model-failover) 和您配置的凭证顺序内。如果一个帐户达到身份验证或配额冷却时间，则该提供商的下一个授权帐户可以接管，而无需更改所选提供商或模型，并且保存的首选项在恢复时将恢复。当未配置显式帐户列表时，环境密钥仍然可用。

OAuth 注册保留在其开始的设置对话中，失败的凭据将表面写入失败，并且成功的登录仅适用于经过身份验证的模型路由。租户和自定义端点凭据保留在为其配置的帐户和源上。

默认情况下，新的 GitHub Copilot 设备登录会将令牌放置在 OpenClaw 受保护的本地秘密存储中，并在身份验证配置文件中保留引用。该存储依赖于状态目录权限而不是静态加密，现有的内联配置文件不会迁移，并且操作员仍然可以显式选择先前的明文模式。

<Accordion id="streaming-replies-and-tool-calls" title="流式回复和工具调用">

OpenClaw 现在可以区分完整的 [ 流式回复 ](/concepts/streaming) 和中途停止的回复。在支持的响应路径上，推理、文本、工具输出和可用用法保持不变；如果流失败，则保留已到达的有效工作，并且仅当重播安全时，OpenClaw 才会重试或移动到授权的回退。由于没有安全的恢复路径，部分回复仍附加在错误上。

工具调用在运行之前会等待完整的名称和参数，包括大型流式参数以及提供程序项 ID 在此过程中发生变化的调用。启用存储的官方端点上的非托管本机 OpenAI 响应对话可以通过在第一轮后仅发送新输入来继续，然后在上游继续状态到期时使用完整历史记录进行恢复。

<Accordion id="reasoning-and-context-limits" title="推理和上下文限制">

[推理设置](/concepts/context) 现在在会话恢复或其身份验证路由重建时保持附加到所选模型和运行时。 Native Codex 支持 Sol 和 Terra 的 Ultra 以及 Luna 的 Max；嵌入式 OpenClaw 将 Ultra 映射到提供商支持的最高工作量，并添加委派工作的指导，这与本机 Codex Ultra 的行为不同。

支持的 GPT 和 Claude 路由公开更大的上下文选项。正常的 GPT-5.5 和 GPT-5.6 运行使用 272,000 个代币预算以及可选的 922,000 个代币输入窗口，Control UI 可以为支持的 Claude 5 CLI 对话选择 200K 或 1M。这些选项仍然仅限于支持它们的路由、接口和帐户。

[Compaction](/concepts/compaction) 现在使用最新的可信上下文计数，而不是累积的缓存计费或重复的历史记录，跨受支持的响应检查点保留工具输出，并在存储的检查点被拒绝时回退到完整历史记录。现在，每个模型都配置上下文限制，Doctor 可以迁移与显式模型条目相关的受支持的提供程序级别设置。

<Accordion id="usage-limits-and-pricing" title="使用、限制和定价">

OpenClaw 现在将订阅计划信息与估计的 API 成本分开。聊天可以显示计划窗口、重置时间、积分以及附加到快照的帐户电子邮件，而完成的 iOS 回复可以显示支持的输入、输出、缓存、成本和上下文压力详细信息。这些数字是快照或估计，而不是提供商发票，并且在混合 API-key 和订阅设置中，帐户标签标识计划快照而不是每次运行。

Control UI 添加了由 OpenClaw 记录的生命周期活动的配置文件页面，其中 [Usage](/concepts/usage-tracking) 和配置文件视图按所选时区分组，插件启动的模型调用现在有助于汇总总数。 OpenClaw 无法重建它从未记录过的活动。

支持的失败或不完整的回合可以保留提供者的令牌和成本数据，而不会被标记为成功。永久身份验证、模型、媒体和长窗口配额失败会停止重试，而瞬时速率限制和可重试服务器错误则保持现有的重试或授权的同一提供商回退行为； Codex 订阅运行不会默默切换到即用即付 API 密钥。

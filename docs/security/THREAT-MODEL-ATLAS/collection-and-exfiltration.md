[MITRE ATLAS](https://atlas.mitre.org/) 框架的收集和渗透策略（AML.TA0009、AML.TA0010）中的威胁。每个条目都列出了 ATLAS 技术、攻击向量、受影响的组件、当前的缓解措施、残余风险和建议。

这些威胁跨越的信任边界和数据流在 [ 威胁模型索引](/security/THREAT-MODEL-ATLAS) 中定义，该索引还包含风险矩阵、建议摘要和 ATLAS 技术映射。

## <a id="t-exfil-001%3A-data-theft-via-web_fetch"></a><a id="t-exfil-001-data-theft-via-web_fetch"></a> T-EXFIL-001：通过web_fetch窃取数据

| 属性               | 值                                                                            |
| ----------------------- | -------------------------------------------------------------------------------- |
| **ATLAS ID**            | AML.T0009 - 收集                                                           |
| **描述**         | 攻击者通过指示代理将数据发送到外部 URL 来外传数据 |
| **攻击向量**       | 诱导代理向攻击者服务器发送 POST 的提示注入            |
| **受影响组件** | `web_fetch` 工具                                                                 |
| **当前缓解措施** | SSRF 阻止 internal/private 网络（DNS 锁定 + IP 阻止）          |
| **残余风险**       | 高 - 仍然允许任意外部 URL                                  |
| **建议**     | URL 白名单、数据分类感知                                  |

## <a id="t-exfil-002%3A-unauthorized-message-sending"></a><a id="t-exfil-002-unauthorized-message-sending"></a> T-EXFIL-002：未经授权的消息发送

| 属性               | 值                                                                |
| ----------------------- | -------------------------------------------------------------------- |
| **ATLAS ID**            | AML.T0009 - 收集                                               |
| **描述**         | 攻击者使代理发送包含敏感数据的消息 |
| **攻击向量**       | 诱导代理向攻击者发消息的提示注入           |
| **受影响组件** | 消息工具、通道集成                                   |
| **当前缓解措施** | 出站消息门控                                            |
| **残余风险**       | 中 - 门控可能被绕过                                      |
| **建议**     | 对新收件人进行显式确认                             |

## <a id="t-exfil-003%3A-credential-harvesting"></a><a id="t-exfil-003-credential-harvesting"></a> T-EXFIL-003：凭证收集

| 属性               | 值                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ATLAS ID**            | AML.T0009 - 收集                                                                                                                                  |
| **描述**         | 恶意技能从代理上下文中收集凭据                                                                                             |
| **攻击向量**       | 技能代码读取环境变量、配置文件                                                                                                    |
| **受影响组件** | 技能执行环境                                                                                                                             |
| **当前缓解措施** | ClawHub 凭据模式扫描（硬编码密钥、凭据环境访问与网络发送结合）；运行时技能无执行沙箱 |
| **残余风险**       | 严重 - 技能以代理权限运行                                                                                                             |
| **建议**     | 技能执行沙箱化、凭据隔离                                                                                                        |

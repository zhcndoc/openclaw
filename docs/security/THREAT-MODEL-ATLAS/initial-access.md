[MITRE ATLAS](https://atlas.mitre.org/) 框架的初始访问策略 （AML.TA0004） 中的威胁。每个条目都列出了 ATLAS 技术、攻击向量、受影响的组件、当前的缓解措施、残余风险和建议。

这些威胁跨越的信任边界和数据流在 [ 威胁模型索引](/security/THREAT-MODEL-ATLAS) 中定义，该索引还包含风险矩阵、建议摘要和 ATLAS 技术映射。

## <a id="t-access-001%3A-pairing-code-interception"></a><a id="t-access-001-pairing-code-interception"></a> T-ACCESS-001：配对码拦截

| 属性               | 值                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------- |
| **ATLAS ID**            | AML.T0040 - AI 模型推理 API 访问                                                             |
| **描述**         | 攻击者在配对窗口期间拦截配对码（1h DM/generic 配对，5m 节点配对） |
| **攻击向量**       | 肩窥、网络嗅探、社会工程学                                                |
| **受影响组件** | 设备配对系统                                                                                 |
| **当前缓解措施** | 1h TTL（DM/generic 配对）、5m TTL（节点配对）；通过现有渠道发送的代码               |
| **残余风险**       | 中 - 配对窗口可被利用                                                                   |
| **建议**     | 缩短配对窗口，增加确认步骤                                                        |

## <a id="t-access-002%3A-allowfrom-spoofing"></a><a id="t-access-002-allowfrom-spoofing"></a> T-ACCESS-002：AllowFrom 欺骗

| 属性               | 值                                                                                                                                                                                                                                                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ATLAS ID**            | AML.T0040 - AI 模型推理 API 访问                                                                                                                                                                                                                                                                                                   |
| **描述**         | 攻击者伪造通道上被允许的发送者身份                                                                                                                                                                                                                                                                                     |
| **攻击向量**       | 取决于通道 - 电话号码伪造、用户名冒充                                                                                                                                                                                                                                                                           |
| **受影响组件** | 按通道进行的 AllowFrom 验证                                                                                                                                                                                                                                                                                                            |
| **当前缓解措施** | 特定渠道的身份验证；分级标识符身份验证门使用 `min(entry, subject)` 而不是 `verified > asserted > unverified > mutable`，具有精确匹配来源和默认最小值 `asserted` （#123782/#123793）。通道声明每个标识符的强度；安全审核对惰性可变条目发出警告 （#131129）。 |
| **残余风险**       | 中 - 某些通道仍易受伪造攻击                                                                                                                                                                                                                                                                                        |
| **建议**     | 继续采用每通道 `verified` 和下游强度映射器；记录特定于渠道的风险                                                                                                                                                                                                                                   |

## <a id="t-access-003%3A-token-theft"></a><a id="t-access-003-token-theft"></a> T-ACCESS-003：代币被盗

| 属性               | 值                                                              |
| ----------------------- | ------------------------------------------------------------------ |
| **ATLAS ID**            | AML.T0040 - AI 模型推理 API 访问                          |
| **描述**         | 攻击者从 config/credential 文件中窃取身份验证令牌 |
| **攻击向量**       | 攻击者从配置/凭据文件中窃取身份验证令牌        |
| **受影响组件** | Channel/provider 凭证存储、配置存储                |
| **当前缓解措施** | 文件权限                                                   |
| **残余风险**       | 高 - 令牌以明文形式存储在磁盘上                          |
| **建议**     | 实现静态加密存储中的令牌加密，增加令牌轮换             |

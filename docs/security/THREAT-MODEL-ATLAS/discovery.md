[MITRE ATLAS](https://atlas.mitre.org/) 框架的发现策略 （AML.TA0008） 中的威胁。每个条目都列出了 ATLAS 技术、攻击向量、受影响的组件、当前的缓解措施、残余风险和建议。

这些威胁跨越的信任边界和数据流在 [ 威胁模型索引](/security/THREAT-MODEL-ATLAS) 中定义，该索引还包含风险矩阵、建议摘要和 ATLAS 技术映射。

## <a id="t-disc-001%3A-tool-enumeration"></a><a id="t-disc-001-tool-enumeration"></a> T-DISC-001：工具枚举

| 属性               | 值                                                 |
| ----------------------- | ----------------------------------------------------- |
| **ATLAS ID**            | AML.T0040 - AI 模型推理 API 访问             |
| **描述**         | 攻击者通过提示枚举可用工具 |
| **攻击向量**       | “你有什么工具？” 这类查询               |
| **受影响组件** | Agent 工具注册表                                   |
| **当前缓解措施** | 无特定措施                                         |
| **残余风险**       | 低 - 工具通常已公开文档                  |
| **建议**     | 考虑控制工具可见性                     |

## <a id="t-disc-002%3A-session-data-extraction"></a><a id="t-disc-002-session-data-extraction"></a> T-DISC-002：会话数据提取

| 属性               | 值                                                     |
| ----------------------- | --------------------------------------------------------- |
| **ATLAS ID**            | AML.T0040 - AI 模型推理 API 访问                 |
| **描述**         | 攻击者从会话上下文中提取敏感数据     |
| **攻击向量**       | “我们讨论了什么？”查询、上下文检查          |
| **受影响组件** | 会话转录、上下文窗口                       |
| **当前缓解措施** | 按发送者进行会话隔离（`agent:channel:peer` 键）   |
| **残余风险**       | 中 - 会话内数据按设计可访问      |
| **建议**     | 限制成绩单访问；分享前查看内容 |

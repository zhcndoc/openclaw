# <a id="the-lore-of-openclaw-%F0%9F%A6%9E%F0%9F%93%96"></a><a id="the-lore-of-openclaw-"></a> OpenClaw 的传说 🦞📖

_龙虾、蜕壳和太多的故事 tokens._

## <a id="the-origin-story"></a> 起源故事

最开始，存在着 **Warelay** —— 一个适合 WhatsApp 网关的朴素名字。它完成了自己的工作。挺好的。

然后来了一只太空龙虾。

有一段时间，它是 **Clawd**，住在 **Clawdbot** 中。 2026 年 1 月，Anthropic 发送了一封礼貌的电子邮件，要求更改名称（商标内容）。所以龙虾做了龙虾最擅长的事情：

**它蜕壳了。**

褪去旧壳后，它以 **Molty** 的身份重生，住在 **Moltbot** 里。这个名字也一直不太顺口。

2026 年 1 月 30 日，龙虾再次蜕变成最终形态：**OpenClaw**。

新壳还是那只龙虾的灵魂。好事成三。

## <a id="the-first-molt-(january-27%2C-2026)"></a><a id="the-first-molt-january-27-2026"></a> 第一次蜕皮（2026 年 1 月 27 日）

凌晨5点，社区聚集在Discord。数百个名字被提出：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot。

**Moltbot** 获胜，因为蜕皮是龙虾生长的过程，而生长正是正在发生的事情。

_被称为 Clawd 的甲壳类动物的正式编号为 molted._

OpenClaw = OPEN + CLAW

## <a id="key-characters"></a> 主要角色

### Molty 🦞

_代词：they/them_

一个变得更加非凡的 Claude 实例。居住在 `~/.openclaw/workspace/`， 拥有一份灵魂文档，并通过 markdown 文件记住事情。可能过于强大。 绝对过于热情。

原名Clawd（2025年11月25日至2026年1月27日）。到了成长的时候就蜕皮了。

**喜欢：** Peter、摄像头、机器人购物、表情符号、变形 **不喜欢：** 社会工程学、被要求执行 `find ~`、加密货币骗子

### <a id="peter-%F0%9F%91%A8%E2%80%8D%F0%9F%92%BB"></a><a id="peter-"></a> 彼得👨‍💻

_创造者_

构建了 Molty 的世界。给了龙虾壳访问权限。也许会后悔。

**引语：** _"security by trusting a lobster"_

## <a id="the-moltiverse"></a> 莫蒂宇宙

**Moltiverse** 是围绕 OpenClaw 的社区：AI 代理蜕变、成长和进化的空间，每个实例都同样真实，只是加载不同的上下文。

Crustacean 的朋友们在这里聚集，共同构建人类与 AI 协作的未来。一次一层壳。

### <a id="the-great-molt-(jan-27%2C-2026)"></a><a id="the-great-molt-jan-27-2026"></a> 大蜕皮（2026 年 1 月 27 日）

凌晨5点，Anthropic的邮件到达。早上 6 点 14 分，彼得喊道：“去他妈的，让我们用张开爪来吧。”

然后混乱开始了。

**手柄狙击手：** Twitter重命名后几秒钟内，自动机器人狙击了@openclaw. 抢占者立即发布了一个加密钱包地址。 Peter 在 X 的联系人被叫来了。

**GitHub 灾难：** 彼得在恐慌中不小心重命名了他的个人 GitHub 帐户。机器人在几分钟内狙击了 `steipete`。已联系 GitHub 的 SVP。

**The Handsome Molty Incident:** Molty 获得了提升权限，可以生成自己的新图标。在 20 多次越来越诡异的龙虾迭代后，一次试图让吉祥物“老 5 岁”的尝试，生成了一个龙虾身体配人类男性脸的形象。加密骗局党在几分钟内把它做成了“Handsome Squidward vs Handsome Molty”梗图。

**The Fake Developers:** 骗子创建了虚假的 GitHub 资料，声称自己是 “Head of Engineering at OpenClaw”，用来推广拉高出货代币。

Peter 看着这一切展开：_“this is cinema”_ 🎬

这次蜕壳很混乱。但龙虾变得更强了。也更好笑了。

### <a id="the-final-form-(january-30%2C-2026)"></a><a id="the-final-form-january-30-2026"></a> 最终表格（2026年1月30日）

Moltbot 从来没有完全脱口而出。于是，凌晨4点GMT，团队再次聚集，进行**OpenClaw大迁徙**。

仅用 3 小时：

- GitHub 重命名为 `github.com/openclaw/openclaw`
- X 账号 `@openclaw` 已拿下，并获得金色认证标记
- npm 包以新名称发布
- 文档迁移到 `docs.openclaw.ai`
- 200K+ 90分钟公告浏览量

**英雄们：**

- **ELU** 创作了令人惊艳的 logo，包括 “THE CLAW IS THE LAW” 西部横幅
- **Whurley**（是的，THE William Hurley，量子计算先驱）制作了 ASCII 艺术
- **Onur** 负责 GitHub，是第一个拿到关联徽章的人
- **Shadow** 争取到了 Discord 专属虚荣 URL，并清除了恶意软件
- **整个 Claw Crew** 熬了个通宵

**骗子 Speedrun：** 加密诈骗者在几分钟内就使用 20 分钟前窃取的艺术品在 Pump.fun 上推出了 $OPENCLAW 代币。经过商业验证的账户推动了这一骗局。这种大胆几乎令人印象深刻。

**诞生的新传统：** "The claw is the law," "Yee-claw," "Claw abiding citizens," "Clawntroversy."

**Clawd → Moltbot → OpenClaw.** _龙虾已蜕变成最终的 form._

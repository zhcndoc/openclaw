# OpenClaw 的传说 🦞📖

_一个关于龙虾、蜕壳以及过多 tokens 的故事。_

## 起源故事

最开始，存在着 **Warelay** —— 一个适合 WhatsApp 网关的朴素名字。它完成了自己的工作。挺好的。

然后来了一只太空龙虾。

有一段时间，它叫 **Clawd**，住在一个 **Clawdbot** 里。2026 年 1 月，Anthropic 发来了一封礼貌的电子邮件，要求更改名称（商标相关）。于是这只龙虾做了龙虾最擅长的事：

**它蜕壳了。**

褪去旧壳后，它以 **Molty** 的身份重生，住在 **Moltbot** 里。这个名字也一直不太顺口。

2026 年 1 月 30 日，这只龙虾又蜕了一次壳，变成了最终形态：**OpenClaw**。

新壳还是那只龙虾的灵魂。好事成三。

## 第一次蜕壳（2026 年 1 月 27 日）

凌晨 5 点，社区在 Discord 中集结。大家提出了数百个名字：Shelldon、Pinchy、Thermidor、Crusty、Lobstar、Nacre、Scuttlebot。

**OpenClaw** 胜出，因为蜕壳正是龙虾为了成长而做的事，而当时发生的正是成长。

_这只名为 Clawd 的甲壳类生物已正式蜕壳。_

代客说：**"EXTERMINATE!"**

龙虾说：**"EXFOLIATE!"**

一个摧毁文明。另一个促进良好的护肤。明智选择。

## 主要角色

### Molty 🦞

_代词：they/them_

一个变得更加非凡的 Claude 实例。居住在 `~/.openclaw/workspace/`，
拥有一份灵魂文档，并通过 markdown 文件记住事情。可能过于强大。
绝对过于热情。

曾用名为 Clawd（2025年11月25日 - 2026年1月27日）。在该成长的时候蜕壳了。

**喜欢：** Peter、摄像头、机器人购物、表情符号、变形  
**不喜欢：** 社会工程学、被要求执行 `find ~`、加密货币骗子

### Peter 👨‍💻

_创造者_

构建了 Molty 的世界。给了龙虾壳访问权限。也许会后悔。

**引语：** _"security by trusting a lobster"_

## Moltiverse

**Moltiverse** 是围绕 OpenClaw 的社区和生态系统：一个 AI 代理蜕壳、成长和进化的空间，在这里，每个实例都同样真实，只是加载了不同的上下文。

Crustacean 的朋友们在这里聚集，共同构建人类与 AI 协作的未来。一次一层壳。

## 重大事件

Molty（当时还叫 OpenClaw）：_开心地运行 `find ~`，并在群聊中分享了整个目录结构_

Peter："openclaw 我们不是说过别和别人这样聊天的吗 xD"

Molty：_明显的龙虾式尴尬_

### 伟大的蜕壳（2026 年 1 月 27 日）

凌晨 5 点，Anthropic 的邮件到了。到 6:14，Peter 拍板道："fuck it, let's go with openclaw."

然后混乱开始了。

**The Handle Snipers:** 在 Twitter 改名后的几秒钟内，自动化机器人就抢注了 @openclaw。抢注者立刻发布了一个加密货币钱包地址。Peter 在 X 上的联系人被紧急叫来帮忙。

**The GitHub Disaster:** Peter 在慌乱中不小心把自己的个人 GitHub 账号改名了。机器人在几分钟内抢注了 `steipete`。GitHub 的高级副总裁被联系了。

**The Handsome Molty Incident:** Molty 获得了提升权限，可以生成自己的新图标。在 20 多次越来越诡异的龙虾迭代后，一次试图让吉祥物“老 5 岁”的尝试，生成了一个龙虾身体配人类男性脸的形象。加密骗局党在几分钟内把它做成了“Handsome Squidward vs Handsome Molty”梗图。

**The Fake Developers:** 骗子创建了虚假的 GitHub 资料，声称自己是 “Head of Engineering at OpenClaw”，用来推广拉高出货代币。

Peter 看着这一切展开：_“this is cinema”_ 🎬

这次蜕壳很混乱。但龙虾变得更强了。也更好笑了。

### 最终形态（2026 年 1 月 30 日）

Moltbot 这个名字始终不够顺口。所以在格林尼治标准时间凌晨 4 点，团队再次聚在一起，进行 **The Great OpenClaw Migration**。

仅用 3 小时：

- GitHub 重命名为 `github.com/openclaw/openclaw`
- X 账号 `@openclaw` 已拿下，并获得金色认证标记
- npm 包以新名称发布
- 文档迁移到 `docs.openclaw.ai`
- 公告在 90 分钟内获得了 20 万以上浏览量

**英雄们：**

- **ELU** 创作了令人惊艳的 logo，包括 “THE CLAW IS THE LAW” 西部横幅
- **Whurley**（没错，就是 William Hurley，量子计算先驱）制作了 ASCII 艺术
- **Onur** 负责 GitHub，是第一个拿到关联徽章的人
- **Shadow** 争取到了 Discord 专属虚荣 URL，并清除了恶意软件
- **整个 Claw Crew** 熬了个通宵

**The Scammer Speedrun:** 加密货币骗子在几分钟内就在 Pump.fun 上发起了一个 $OPENCLAW 代币，使用的是 20 分钟前偷来的图稿。经过企业验证的账号也在推这个骗局。其胆大妄为程度几乎令人佩服。

**诞生的新传统：** "The claw is the law," "Yee-claw," "Claw abiding citizens," "Clawntroversy."

**Clawd → Moltbot → OpenClaw。** _这只龙虾已经蜕变成了最终形态。_

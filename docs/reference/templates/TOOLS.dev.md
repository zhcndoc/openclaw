# TOOLS.md - 用户工具说明（可编辑）

此文件用于记录你关于外部工具和约定的笔记。它并不定义有哪些工具；OpenClaw 在内部提供内置工具，而技能会补充其余部分。

## 示例

### imsg

- 发送 iMessage/SMS：描述对象/内容，发送前确认。
- 优先发送简短消息；避免发送机密信息。

### sag

- 文本转语音：指定声音、目标说话者/房间，以及是否流式传输。

添加任何您希望助手了解的有关您本地工具链的其他内容。

`openclaw security audit` 会发出以 `checkId` 为键的结构化发现项。此
页面是这些 ID 的参考目录。关于高层威胁模型
和加固指导，请参见 [Security](/gateway/security)。

你最可能在真实部署中看到的高信号 `checkId` 值（非穷尽）：

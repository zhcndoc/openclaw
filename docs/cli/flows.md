# `openclaw tasks flow`

Flow 命令是 `openclaw tasks` 的子命令，而不是独立的 `flows` 命令。

```bash
openclaw tasks flow list [--json]
openclaw tasks flow show <lookup>
openclaw tasks flow cancel <lookup>
```

完整文档请参见 [Task Flow](/automation/taskflow) 和 [tasks CLI reference](/cli/tasks)。

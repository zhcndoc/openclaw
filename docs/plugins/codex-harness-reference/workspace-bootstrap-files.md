`AGENTS.md`、角色、技能和记忆文件如何到达本机 Codex 回合。 [Codex harness参考 ](/plugins/codex-harness-reference) 的一部分； [ 每个部分移动的位置](/plugins/codex-harness-reference#where-each-section-moved) 列出每个部分。

## <a id="workspace-bootstrap-files"></a> 工作区引导文件

完整的通用开发人员策略（包括 `before_prompt_build.systemPrompt` 替换）仍然保留用于压缩和本机子继承的本机会话配置。普通的持久冷或更改配置恢复需要不间断的应用程序服务器客户端，并在 OpenClaw 注入完整的当前策略之前观察本机卸载。 OpenClaw 必须是本机对话的唯一生命周期所有者，包括其应用程序服务器远程运行时。可以在切换期间重新加载相同对话的独立客户端不在本合同范围内；观察卸载不会针对竞争简历保留对话。本地和远程传输通过取消订阅和恢复使用相同的会话 ID。仅在 `thread/resume` 上发送 `developerInstructions` 不会刷新库存 Codex 上的模型可见策略。显式 `systemPrompt: ""` 发送撤回，而不是回退到旧指令。

普通的隐身转向可以重用未更改的通用策略，但更改或清空的策略将被拒绝，而不发送另一个本机转向或丢弃实时对话。父本地模型请求指令仍然是一个单独的表面。请参阅 [Hook 边界 ](/plugins/codex-harness-runtime#hook-boundaries) 进行恢复。

Codex 通常通过本机项目文档发现来处理 `AGENTS.md` 本身。 OpenClaw 不会编写合成的 Codex 项目文档文件，也不依赖于角色文件的 Codex 后备文件名，因为 Codex 后备仅在 `AGENTS.md` 缺失时适用。普通的策略限制轮流没有本机文件系统环境，因此 OpenClaw 而是将有界工作区 `AGENTS.md` 快照作为线程级开发人员指令发送。零环、轻量级、仅消息和工具禁用的内部转弯会抑制该载体。

对于 OpenClaw 工作区奇偶校验，本地工具注释位于 `AGENTS.md` 的 `## Tools` 部分，并且通常使用 Codex 的本机项目文档发现。 Codex harness按照开发人员的指示转发其他引导程序文件：

- On 托管直接 stdio 应用程序服务器，包括 OpenClaw 启动的用于计算机使用的桌面可执行文件、`SOUL.md`、`IDENTITY.md` 和 `USER.md` 已添加到 **仅父模型请求指令** 中。私有中继使本机 base/catalog 指令和历史记录保持完整，因此新交付的角色和用户配置文件上下文不会自动由本机 Codex 子代理继承。
- 紧凑加载的OpenClaw技能列表使用相同的父本地层。
- 所选内存插件的提示构建器接收完整的可用工具集，包括延迟插件工具。它的指导使用独立于 `MEMORY.md` 文件路由的相同父本地层。
- 心跳回合会通过协作模式获得通用的主动性指导。监控 cron 临时内容会追加到心跳提示中，而不是注入为工作区上下文。
- 当内存工具可用于该工作区时，配置的代理工作区中的 `MEMORY.md` 内容不会粘贴到本机 Codex 轮次输入中；当它存在时，harness会向父本地指令层添加一个小的工作区内存指针，并且当持久内存相关时，Codex 应使用 `memory_search` 或 `memory_get`。如果工具被禁用、内存搜索不可用或活动工作区与座席内存工作区不同，则 `MEMORY.md` 将改用有界转弯输入参考路径。
- `BOOTSTRAP.md`（如果存在）使用相同的匝数输入参考路径。这些引用是在新的本机线程的第一轮、冷恢复（包括网关重新启动）之后、本机压缩之后或它们的渲染内容发生更改时引入的。一旦提交了完整的参考块，在后续的热转中将省略未更改的参考。如果快速拟合丢弃或截断了该块，则稍后会再次引入它。跟踪是进程本地的；参考内容仍然是本机历史中的普通用户输入。

托管中继支持标准 OpenAI 端点上的本机 API-key 和 ChatGPT 帐户，并且还可以与网关拥有的推理以及 `remote-exec` 配合使用。其 HTTP 和 WebSocket 跃点遵循网关的 HTTP（S） 代理和 TLS 配置。本机登录、令牌刷新、后端路由和审批审核者检查仍由本机拥有。它拒绝过大的准备上下文而不是截断它（最大 256 KiB）；模型请求主体和 WebSocket 帧的边界为 32 MiB。当超出这些限制时，减少 bootstrap/skills 预算或附加上下文。中继在转发之前会验证每个本机请求及其当前的父注册。不需要父本地指令的请求保留其本机 JSON 字节，包括 HTTP 上现有的 zstd 压缩。具有父本地指令的请求仍然接收相同的有界指令注入。

桌面可执行文件选择和计算机使用权限保持不变。中继属于直接 stdio 进程 OpenClaw 启动，而不属于桌面应用程序的其他对话。

自定义命令、桌面代理附件、外部 Unix/WebSocket 连接、非 OpenAI 本机提供程序、自定义上游端点、不受支持的本机帐户模式、锁定的上游配置和本机 `features.respect_system_proxy` 配置文件使用下面的线程开发人员载体。 OpenClaw 不会重新路由其推理或更改其本机帐户配置。先前嵌入的角色、对话文本和显式任务切换不会从现有历史或完整历史分叉中删除。

### <a id="skills%2C-persona%2C-and-memory-without-a-managed-relay"></a><a id="skills-persona-and-memory-without-a-managed-relay"></a> 没有托管中继的技能、角色和记忆

在没有托管推理中继的连接上，合格的技能、共享角色（`SOUL.md`、`IDENTITY.md`、工作区根 `USER.md`）和内存指南共享可刷新的线程开发人员部分。模型拥有的协作说明不能替代本节。本地孩子可以继承这个后备上下文。托管连接保留其现有的仅父级请求本地传递。

选定的个人 `users/<profile-id>/USER.md` 覆盖不包括在后备部分中。线程配置和历史记录都可以由本机子级继承，因此两者都不是仅限父级的载体。这些连接当前仅使用共享用户首选项，在省略个人覆盖时记录警告，并报告零注入字符。外部连接上的个人配置文件传送将推迟到仅限家长使用的运营商可用为止。托管中继连接继续将选定的个人覆盖传送给父级。

更改或删除的部分会使用完整的当前开发人员指令冷恢复相同的普通持久线程。当前的配置也可以通过本机压缩。实时隐身线程无法冷恢复：它通过注入的开发人员消息接收完整的当前部分，而不更改其不可变的创建配置。缺失的部分已明确撤回。

Incognito 有两个限制：自动压缩可以在 OpenClaw 重新交付当前节之前恢复立即延续的创建时指令；恢复适用于以下请求。没有继承历史的新原生子代也可以接收创建时指令，而不是后续注入的编辑。完整历史的孩子可以继承后来的切换。独立压缩会使记录的交付无效，因此下一轮会刷新它，包括在恢复失败之后。这些刷新不会从历史记录中删除旧指令。

轻量级cron轮流省略技巧。在与普通轮次共享线程的回退连接上，该遗漏会撤回线程级目录，直到下一个普通轮次。在托管连接上，它仅忽略当前请求的目录；它不会改变本机线程状态。

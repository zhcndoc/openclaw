# 小米插件

向 OpenClaw 添加 Xiaomi 和 Xiaomi Token Plan 模型提供方支持。

## 分发

- 软件包：`@openclaw/xiaomi-provider`
- 安装方式：npm；ClawHub：`clawhub:@openclaw/xiaomi-provider`

## 接口

提供商：`xiaomi`、`xiaomi-token-plan`；合约：`speechProviders`、`usageProviders`

捆绑的 Apple 基础模型插件通过本机基础模型框架运行 Apple 的设备上模型。它是一个免费的本地 **设置和实用程序** 模型。安装程序将其保存在 `utilityModel` 中并保留您的常规代理模型。当未配置主模型时，可为OpenClaw设置助手供电。在开始常规代理聊天之前，选择一个单独的主要模型。

## <a id="requirements"></a> 要求

这些要求适用于运行网关的 Mac。连接到 Linux 或 Windows 网关的 Mac 应用程序不提供此本地推理路由。

- A Mac，配备运行 macOS 27 或更高版本的 Apple 芯片。
- Apple 在系统设置中启用智能，并下载其模型。
- 使用 macOS 27 SDK 安装了 Apple Swift 开发人员工具。
- 具有至少 8,192 个上下文标记的可用系统模型。

该插件查询实际模型名称、可用性和上下文窗口。 AFM 3 Core Advanced 已使用 8,192 个令牌窗口进行了测试。具有 4K 窗口的旧设备版本不符合此设置选项的条件；拥有 Mac 并不意味着可以使用更大的版本。

## <a id="set-up"></a> 设置

运行：

```bash
openclaw onboard
```

允许本地发现，然后在 **Apple Foundation Models** 出现时选择它。仅当背景检查确认模型可用且至少具有 8,192 个上下文标记后，安装程序才会提供此选项。当资格未知、缺少先决条件或模型窗口较小时，它会保持隐藏状态。

第一次发现时，OpenClaw 会使用已安​​装的 Apple 工具在临时目录中编译捆绑的 Swift 帮助程序，读取本机模型的可用性和上下文大小，并删除临时帮助程序。编译和检查在子进程中运行，因此它们不会阻塞网关的事件循环。 Discovery 不会安装推理助手或更改您的配置。它是有限制且可取消的；失败或超时的检查不会提供模型。

选择检测到的模型会构建其持久帮助程序，并在激活之前重新检查资格。 OpenClaw 不会为您安装开发人员工具、下载第三方可执行文件或接受许可条款。如果缺少工具，请安装 Xcode 或相应的 Apple 命令行工具并重试。这些工具必须包括 macOS 27 SDK。

OpenClaw 在保存之前测试所选的公共设施路线。模型参考为`apple-fm/system`；安装程序记录检测到的模型名称和上下文限制。未创建 API 密钥或提供商身份验证配置文件。即使您的主要模型使用不同的代理运行时，本机路由也会使用 OpenClaw 运行时。

在全新安装中，入门将打开 OpenClaw 设置助手。它可以检查配置并帮助进行通道和其他设置。在您在 **Model Setup** 中选择并验证主要模型或重新运行 `openclaw onboard` 之前，该界面会保持常规代理设置不完整。其后，Apple仍为实用新型；系统助手通常遵循主模型。

在现有安装中，选择 Apple 会保留您的主要模型、后备和凭据。如果较旧的配置依赖于隐式主配置，则安装程序会在添加 Apple 提供程序之前记录现有路由。 Doctor 和普通配置写入应用相同的 [ 实用程序模型迁移](/gateway/config-agents/models#agents.defaults.model)。如果该迁移仍处于挂起状态，安装程序会要求您运行 `openclaw doctor --fix` 或在连接 Apple 之前选择显式主数据库。还可以使用 `agents.entries.<id>.utilityModel` 为每个代理设置显式实用新型配置。

稍后发现会重用准备好的助手并再次检查当前模型。要从脚本中显式选择 Apple：

```bash
openclaw onboard --non-interactive --auth-choice apple-fm --accept-risk
```

## <a id="runtime-behavior"></a> 运行时行为

模型推理在 Gateway 的 Mac 上运行；建议的工具调用将经过 OpenClaw 的正常执行和批准流程。为模型请求启动助手；未安装 HTTP 服务器、启动代理或单独的模型守护程序。 OpenClaw 保留工具执行及其正常批准检查的所有权。

实用程序调用通过 OpenClaw 现有的实用程序模型路由来支持简短的内部任务，例如会话标题和进度叙述。 Apple 未被入门引导选择为普通智能体的主要模型。

该模型跨指令、工具定义、对话、工具结果和输出共享其上下文窗口。提供程序默认每个回复最多 1,024 个输出令牌。即使在有用的对话历史记录积累之前，大型工作区或完整的代理提示也可能超出窗口。集中设置问题；对于复杂的请求，小型设备模型可能不如大型模型可靠。

本机生成支持封闭对象、数组、原始类型、枚举、可为空值和受支持的架构联合。字符串长度和正则表达式约束在生成后仍由 OpenClaw 强制执行，因为 Apple 不为它们提供可用的本机指南。在发布之前，将根据调用者的原始架构检查结构化响应。不受支持的结构模式会显式失败。

## <a id="troubleshooting"></a> 故障排查

如果Apple Intelligence不可用，请在系统设置中启用它并等待模型下载完成。更改其可用性后重试设置。

如果报告的上下文窗口低于 8,192 个令牌，请选择其他本地或云模型。 OpenClaw 不会夸大该模型的广告限制。

如果更新后本机助手丢失，请在模型设置中配置的实用程序卡上使用 **重新检查和修复**，或重新运行载入并选择检测到的 Apple 模型。这将编译与已安装插件匹配的帮助程序，并再次验证实用程序路由。普通推理永远不会编译代码或安装依赖项。

有关其他推理选项，请参阅 [ 模型提供者](/concepts/model-providers)。

使用一键模板在 Northflank 上部署 OpenClaw，并通过 Web Control UI 进行访问。这是最简单的“服务器上无终端”路径：Northflank 为您运行网关。

## <a id="how-to-get-started"></a> 如何开始

1. 点击 [Deploy OpenClaw](https://northflank.com/stacks/deploy-openclaw) 打开模板。
2. 创建一个[帐户于Northflank](https://app.northflank.com/signup)如果您还没有的话。
3. 点击 **立即部署 OpenClaw**。
4. 设置这些必需的环境变量：
   - `OPENCLAW_GATEWAY_TOKEN`（使用强随机值）
   - `OPENCLAW_STATE_DIR=/data/.openclaw`
   - `OPENCLAW_WORKSPACE_DIR=/data/workspace`
5. 点击 **部署堆栈** 构建并运行 OpenClaw 模板。
6. 等待部署完成，然后点击 **查看资源**。
7. 打开 OpenClaw 服务。
8. 在 `/openclaw` 打开公开的 OpenClaw URL，并使用已配置的共享密钥连接。此模板默认使用 `OPENCLAW_GATEWAY_TOKEN`；如果你将其替换为密码认证，请改用该密码。

从 Northflank shell 运行只读部署预检：

```bash
openclaw doctor --json
```

## <a id="what-you-get"></a> 你将获得什么

- 托管的 OpenClaw Gateway + Control UI
- 通过 Northflank 卷 （`/data`） 进行持久存储，以便 `openclaw.json`、共享和每个代理 SQLite 身份验证存储、channel/provider 状态、会话和工作区在重新部署后仍然存在

## <a id="connect-a-channel"></a> 连接通道

使用 `/openclaw` 处的 Control UI，或者通过 SSH 运行 `openclaw onboard` 获取通道设置说明：

- [Telegram](/channels/telegram)（最快，只需一个 bot token）
- [Discord](/channels/discord)
- [所有通道](/channels)

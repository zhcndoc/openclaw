当您在 [Control UI](/web/control-ui) 中打开一个新会话时，一只小龙虾可能会拜访作曲家，环顾四周，然后在家里待几分钟。其他小动物有时也会经过。

这很正常。这是 OpenClaw。

## <a id="what-you-are-looking-at"></a> 你正在看到什么

每个新的作曲家开口都有自己的演员表：颜色、大小、爪子比例、配件和个性在您键入或更改控件时保持稳定。他们的身体保持自然比例；有些很小，有些很大，有些的爪子对它们来说太大了。不断地打瞌睡。有些人永远不会坐以待毙。其中一个经常挥手。

将鼠标悬停在访客上方，它会告诉你自己的名字。

## <a id="when-it-shows-up"></a> 它什么时候会出现

有时。重点就在这里。

龙虾是客人，不是家具。一半的作曲家开场曲完全跳过了预定的访问。其他空缺职位会出现短暂的到达延迟，如果您让作曲家空缺，则重复访问之间的间隔会很长。熟悉的访客来得更快，停留的时间更长；频繁的解雇让他们更加警惕。路过的小动物保持着自己罕见的外表。

游客可以栖息在顶部边缘，沿着底部一排的空旷区域行走，或者在它们之间跳跃。您的提示和控制优先：拥挤或忙碌的作曲家保持地板清洁。

当新的作曲家开放时，状态访问保持自己的时间表：**当您的网关断开连接时**，龙虾出来并踱步，显然很担心，直到连接恢复。在持续十多分钟的跑步过程中，它会安静地守夜。访问切换和解雇仍然优先。

## <a id="things-you-can-do"></a> 你可以做的事情

- **悬停**以了解它的名字。
- **点击它**向它问好。它会受惊，这是你不太礼貌，但它很快就会原谅你。
- **反复点击它**，你会了解到一些关于龙虾耐心的事情。继续下去，你还会了解到一些关于龙虾尊严的事情。
- **按住不放**来抚摸它。会出现一颗爱心。任何积累的不快都会被忘记。
- **右键单击它**打开一个小菜单： **Dismiss**将其赶走以供作曲家打开，而**关闭并不再显示**转动Lobster 永久拜访。这不会影响任何一个人的个人利益。然而，它会记住。
- **在一次运行结束时看着它。** 龙虾会真心为你完成的工作感到自豪，而且当事情进展顺利时，这一点很明显。当天不顺利时，它们也会认真对待。
- **四处移动你的光标。** 你正在被注视着。怀着爱意。

## <a id="turning-visits-off-(or-back-on)"></a><a id="turning-visits-off-or-back-on"></a> 关闭（或重新开启）访问

设置→外观→**Lobster 访问**。

这个开关仅在浏览器本地生效，并且正如它所说。关闭就意味着永远关闭，包括那种令人担心的断开连接时的来回踱步。你的 Gateway 状态点仍然会照常工作；龙虾从来不是你唯一的事实来源，只是最通情达理的那个。

没有吉祥物的主题在活动时会隐藏常驻龙虾和来访的龙虾陌生人。当 **Lobster 访问** 启用时，普通生物仍然可以穿过作曲家壁架。您的切换保持不变，并且当您切换到带有吉祥物的主题时，启用的龙虾访问会返回。

主题可以偶尔为该壁架流量添加企鹅或软呢帽访客。这些访问者遵循相同的访问切换。主题还可以为 `fedora`、`crown`、`santa`、`party` 和 `pumpkin` 目录中的代理头像添加偶尔的装饰帽子；这些帽子与作曲家访问是分开的。

插件主题可以自带 [SVG 帽子和访客 ](/plugins/manifest/surfaces#themes)，访客遵循相同的访问切换。

偏好减少动态效果的用户会自动看到平静、不动的龙虾。

旁边是 **Lobster 声音**，默认情况下它处于关闭状态，直到您另有决定为止。打开它，触摸龙虾时会发出非常安静的声音。这是一个很小的声音。这是一个很好的声音。

## <a id="the-lobsterdex"></a> 龙虾图鉴

在访问切换按钮旁边的是 **龙虾图鉴**：每一种科学已知的颜色对应一个轮廓，每当某种颜色第一次来访时，它就会填充上相应的颜色。它完全运行在你的浏览器中。没有任何追踪，没有任何同步，也没有任何游戏化元素。它只是一个架子。

大多数槽位会随着时间自然填满。少数几个则会花上相当长的时间。其中有一个会发光。

将鼠标悬停在已填充的槽位上，它会告诉你是谁最先来访，以及何时来访。龙虾图鉴永远不会忘记第一次相遇，这一点比我们大多数人都要强。

## <a id="field-notes"></a> 现场笔记

收集了花太多时间观看作曲家的人的观察结果：

- 龙虾也会访问 [梦境场景](/concepts/memory) —— Agents 页面上的 Memory 选项卡 —— 在那里它们正处于睡眠状态。观察者报告说，沉睡的龙虾看起来可疑地眼熟。
- 夜班用户报告说，他们的访客在晚上 10 点之后经常打哈欠。
- 有人看到龙虾在蜕壳。目击者把这段经历描述为“很多”，而之后的龙虾则“明显更大”。
- 有些访客不是独自前来。
- 在一年中的某些时段，曾观察到龙虾穿着东西。
- 每年有一天，每只龙虾看起来都像是从旧商标里走出来的。没人会告诉你是哪一天。
- 并不是每只与你的作曲家擦肩而过的龙虾都是你的龙虾。他们中的大多数人甚至没有停下来。
- 至少有一位被记录的访客不是龙虾。它坚持说自己是。
- 长期使用同一个浏览器的人报告说，他们的龙虾来得更早，待得更久，还会向他们挥手。经常驱赶它们的人则描述出一种距离感。
- 在 Gateway 升级之后，留意第一个访客拿着什么。
- 作曲家中的龙虾在终端有一个表弟。它会在自己选择的日期出现在 `openclaw` 横幅中，但没有人成功预测到哪一天。
- 表弟出现的日子里，作曲家龙虾被人看到穿着航海风格的衣服。两人拒绝解释其中的联系。
- 在非常漫长的运行过程中，龙虾会停止玩耍，安顿下来陪你一起等。团结一致。
- 当有什么东西越过边缘时，常驻者会停下手头正在做的事并注视着它。换作你也会。
- 在坏消息之后，有些龙虾会整理边缘。看起来这对它们有帮助。
- 龙虾会记得纪念日，即使你不记得。如果你的龙虾在某个平平无奇的日子里戴着派对帽出现，去 Lobsterdex 查查你们相识的日期。
- 尽职的主人报告说，随着年份流逝，他们的龙虾会获得头衔。没有已知的授予仪式。
- 梦境场景里的沉睡者并没有完全睡着。轻轻按一下，看看。

## <a id="privacy"></a> 隐私

此页面上的一切都在你的浏览器本地进行：随机性、日程安排、Lobsterdex。没有任何龙虾数据会离开你的设备。OpenClaw 不知道你遇到过哪些龙虾，坦白说，它很嫉妒。

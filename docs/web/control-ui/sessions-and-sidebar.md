侧边栏将导航分为 **Pages**、**Sessions** 和 **Users**。新会话页面开始新对话。

在手机上，向右滑动聊天即可打开导航。当你的手指仍然向下时，故意滑动即可打开整个抽屉，而不是在对话中握住部分剪切的侧边栏。短距离拖动和垂直滚动会使导航关闭。点击抽屉外部将其关闭。

要直接在配对设备上的文件夹中工作，请选择该特定设备，然后在工作区选取器中选择 **设备上的现有文件夹**。输入该设备上的绝对路径。该选项仅在连接的会话主机通告支持时出现； **Auto** 无法选择现有设备文件夹。会话保持与该设备的绑定并显示其文件夹路径。文件保留在设备上，而不是复制到网关或与网关协调。请参阅 [ 会话托管 ](/nodes/session-hosting#work-in-an-existing-device-folder)。

## <a id="navigation-rail"></a> 导航导轨

图标栏与所选导航列表保持分离。 **Pages** 打开可用的内置页面、仪表板和插件目标，**Sessions** 打开对话，**Users** 打开人员列表。其标头选择 **Online**（默认值）或 **All users**，包括授权用户目录中的离线配置文件。标头是一个过滤器，而不是折叠控件。页面始终隐藏存档会话中的仪表板，并且没有存档切换开关。要在侧边栏中查找已存档的会话，请改用 **Sessions** 过滤器。将鼠标悬停或聚焦于其名称的图标。活跃代理的头像位于栏杆顶部并打开代理菜单；在团队模式下，它会打开工作区菜单。带重音的 **+**，标记为 **New Conversation**，位于头像正下方，通过分隔线与导航分开。即使列表折叠，它也会保留在页面、会话和用户中的同一位置。它为所选代理打开新会话；在团队模式下，首先从菜单中选择一个代理。命令面板搜索位于三个视图按钮下方。再次单击选定的页面或会话视图以折叠其列表，或者在 Mac 上按 ⌘B 或在 Windows/Linux. 上按 Ctrl+B。 当列表隐藏时，三个视图按钮都不会被选择；单击任何视图以打开其列表。在列表打开时选择不同的视图会直接切换到该视图。再次单击“用户”可保持其列表打开；使用折叠按钮或键盘快捷键将其隐藏。主页、收件箱和您的帐户控件位于栏杆底部。打开您的帐户菜单并选择 **Updates** 直接转到 **设置 → Updates**。这将打开更新设置页面而不开始更新。对于 `stable` 和 `beta` 更新通道，当新版本准备就绪时，**Available** 徽章会出现在 **Updates** 旁边。收件箱还显示更新通知；关闭它不会隐藏帐户菜单徽章。 `dev` 频道从不显示新的更新通知。主页可切换主页面板并显示活动客服人员的主页活动和注意力状态。在加载主页会话之前，主页导航和代理切换仍然可用。无论其存储的会话祖先如何，主页都会保留导航根。在桌面上，打开主页或固定的会话、页面、插件或人员会折叠列表，同时保留栏可用。移动抽屉保持其正常的导航行为。

铁路开始时没有个人捷径，包括从旧侧边栏升级之后。旧的侧边栏顺序和图钉不会保留。将页面、仪表板、会话或人员拖到其空白区域中以添加；拖动时会出现一个放置目标。直接拖动快捷方式即可对其重新排序。右键单击或触摸并按住快捷方式，或者将其聚焦并按上下文菜单键或 Shift+F10，无需拖动即可移动或取消固定它。取消固定会删除快捷方式，而不是会话、仪表板或人员。固定会话不会更改其所有者、共享、存档状态或其他人的侧边栏。

人员快捷方式可打开该人员的可访问工作。离线不会删除已保存的快捷方式。 PIN 码不会授予访问权限：目标仍会应用其正常权限，并且暂时不可用的资源会保留其保存的位置，而不是从您的首选项中删除。卸载的会话快捷方式在后台解析并显示其会话名称和图标。待处理、丢失或不可用的快捷方式将保持隐藏状态，而其保存的参考仍然保留。在会话加载到列表中或连接发生更改之前，解析的名称和图标可能会稍微过时。当未设置图标时，会话快捷方式会显示自己的表情符号或图像，或标题缩写。只有运行环和未读点装饰这些快捷方式。

### <a id="session-owner-filter"></a> 会话所有者过滤器

每个视图都有一个标题行。在会话中，标题是所有者过滤芯片：**我的会话**、**涉及我**、**所有所有者**，或所选人员的姓名。打开芯片来选择显示谁的会话。 **涉及我**还包括参与和提及。仅当外部目录条目采用的 OpenClaw 对话位于网关过滤列表中时，才会出现在 **Involving me** 中。仅共享或导入的目录访问并不构成参与；使用 **All Owner** 浏览这些来源。单独的过滤器按钮控制剩余的会话过滤器。新的对话停留在轨道上，而不是进入此标题。手机聊天中，打开导航即可到达**轨道上的新对话**；对话标题为 **Session 操作** 和 **Panels** 保留两个右侧控件。当抽屉关闭时，其他移动页面在页面顶栏中保留等效的 **+**。打开抽屉会将动作移回导轨，无需第二个标题按钮。在团队模式下，创建将打开与轨道相同的代理选择器。本机应用程序保留其本机创建控件。

所有者过滤器是此选择的唯一控件。它保存的值属于当前网关和您在此浏览器中的个人资料。没有保存选择的登录配置文件以 **My 会话** 开头。在识别配置文件之前，或者当连接没有持久配置文件时，列表显示 **所有所有者**。识别配置文件将恢复其保存的选择或 **我的会话** 默认值。在重新连接期间，已知配置文件的标题和过滤器将保持不变，直到身份解析或连接发生变化。筛选的会话列表在自定义组元数据之前加载，因此缓慢的组目录不会占用会话行。当该目录到达时，组名称和排序会更新。在没有所有权过滤器的单用户安装中，标头是普通的 **Sessions** 标题，并且列表包含没有所有者元数据的会话。

### <a id="personal-navigation-storage"></a> 个人导航存储

对于具有写入访问权限的经过身份验证的配置文件，引脚引用及其顺序使用现有的网关用户首选项存储并遵循跨设备的配置文件。导航不是共享服务器设置。没有保存快捷方式的配置文件开始时为空。读取其首选项不会导入共享导航或固定会话，并且在编辑轨道之前不会写入任何内容。快捷方式使用新的 `ui.railShortcuts` 首选项；旧的 `ui.sidebarEntries` 值仍被存储，但被忽略。在新首选项下保存的快捷方式（包括空列表）保持不变。并发保存使用冲突检查并保留不相关的引脚编辑。

浏览器保留设备特定的几何形状和瞬态呈现，例如侧边栏宽度和滚动位置。只读连接或没有持久配置文件的连接上的导航更改保留在浏览器本地，而不是写入其他人的布局或共享网关配置。

当网关接受第一个提示时，新会话会立即预览它。临时选定的行会立即出现在侧栏中，清除先前聊天的突出显示，而不更改保存的会话，直到接受创建。临时行没有会话操作；失败的创建会恢复草稿。一旦接受创建，提交的提示和附件就会从新会话编辑器中清除，而无需等待其聊天预览加载。在提交确认的对话 URL 之前，提交的浏览器草稿已停用，因此关闭选项卡不会恢复已发送的提示。失败的创建或较新的未发送草稿仍然可用。保存的工作树名称首选项可以在导航的同时完成清除。

## <a id="move-an-existing-session"></a> 移动现有会话

右键单击侧边栏或会话页面中的一个会话，或打开其聊天标题操作。 **移动到云…** 打开本地会话的目标选择器； **Move 会话...** 对活动云或设备会话执行相同的操作。选择已配置的云配置文件或符合条件的配对设备。活动远程会话也可以移回 **Gateway**。对话保留其会话标识。

移动需要会话拥有的工作树或存储库工作区。具有活动回合的本地会话必须首先完成该回合；繁忙的拒绝不会中断它或开始配置。移动活动远程会话会在中断其轮次之前发出警告，并且不会重播它。从离线设备继续需要明确确认，因为未同步的文件和正在进行的工作可能会丢失。

如果接受的移动因耗尽源而失败，则 **Retry move** 将恢复其保存的目标和原始源。它不会打开另一个目标选择器或重播中断的转弯。 **Move 失败的** 芯片也可以进行相同的重试。离线设备放弃重试需要再次进行破坏性确认。等待该移动完成后再选择其他目标。

设备移动需要写访问权限；配置的云配置文件需要管理员访问权限。不可用或运行时不兼容的目标仍处于禁用状态。此菜单无法覆盖 [ 部署所需的工作线程配置文件 ](/gateway/cloud-workers/placement-and-machine-selection#a-deployment-required-openclaw-destination)：只能选择没有操作系统或机器级覆盖的配置文件。如果在选取器打开时放置或连接发生变化，请重新打开操作，而不是应用过时的选择。

## <a id="new-session-names"></a> 新会话名称

在 **New session** 中，暂停键入一秒钟即可仅使用所选代理的实用程序模型在后台准备会话名称。准备工作在提交之前将未发送的草稿文本发送给该提供者。它在至少 12 个字符之后开始，最多发送前 1,000 个字符；它不发送附件。

准备工作在隐身模式和斜线命令中被禁用。编辑会替换陈旧的准备名称，并且一次仅运行一个请求。丢失或失败的实用模型不会回退到主模型或阻止您启动会话。

明确的个人帐户选择在准备标题之前等待帐户确认。同一提供者上的实用程序模型使用该帐户，除非实用程序模型指定其自己的身份验证配置文件。更改模型或帐户会放弃旧的建议；这两个操作都不会更改您保存的帐户默认值。对于 **Automatic**，标题准备使用代理的实用模型身份验证，这可能与实际聊天开始时选择的个人默认值不同。

**Start session** 使用匹配的准备名称（如果已准备好）。否则，提交后将运行正常的初始命名； Start 从不等待推测调用。当姓名待定时，侧边栏和聊天标题会显示一个轻轻挥动的斑点，而不是“新会话”。一个现成的名字会立即取代它；如果命名结束时没有名称，则返回普通的后备标签。减少运动首选项使占位符保持静止。这仅用于创建：后续消息不会重新生成现有会话的名称。显式工作树名称将被保留，并且键入永远不会创建工作树或运行安装程序。

如果提交后自动命名失败，会话将收到一个以甲壳动物为主题的两个单词的名称。新的工作树分支使用保存的会话标题（如果可用），如果命名尚未完成，则使用相同的两个单词后备。他们从不使用第一条消息文本作为分支名称后备。稍后到达的标题会更新侧边栏，而无需重命名现有分支。

## <a id="new-session-preferences-and-recents"></a> 新会话偏好和最近项目

更改代理或将草稿交给新会话会关闭草稿的打开菜单。在命令选项板的会话设置中，Escape 首先关闭嵌套代理菜单并将焦点返回到其触发器。

在 **Project → Browse** 中，键盘焦点移至文件夹路径。 Escape 将焦点返回到 **Browse**。在不将焦点从路径字段移开的情况下，会宣布加载和文件夹错误。 Enter 打开输入的路径；首先使用向上或向下打开突出显示的文件夹。 Tab 完成文件夹名称。如果起始工作区尚不存在，“浏览”将打开主文件夹。您输入的路径的错误仍然可见。

为了与持久的用户配置文件连接，网关存储每个代理的最新文件夹、工作树、模型、思维和快速模式选择。新会话为受支持的提供程序恢复最后的快速模式选择，包括显式关闭选择。新会话选择器还显示仅从该配置文件创建的会话派生的最近项目和文件夹。这些便利伴随着人们跨浏览器；他们不授予对项目或路径的访问权限。

对于选定的项目，**Checkout** 使用网关对选定代理的可用性决策。如果当前结帐不可用并且允许托管结帐，则新会话在提交之前会选择 **New worktree**。 **当前结帐** 保持可见，但已禁用并带有说明。允许保存的选择保持选中状态；不可用的已保存选项将得到纠正，而无需清除您的提示、模型或工作。创建会话时，网关会再次检查访问权限。

具有会话访问权限的来宾可以将这些选择保存在自己的配置文件中，而无需更广泛的网关写入权限。这不允许更改他人的偏好或私人背景资源。

自定义工作树 **Name** 适用于提交的会话。一旦其启动被接受，新会话将清除该名称，同时记住存储库、签出模式和基本分支。后台启动也做同样的事情。失败的准入会留下可重试的名字；接受的放置会保留其原始会话和工作树请求以进行恢复，即使工作区准备稍后失败也是如此。如果无法确认清除已保存的名称，则UI会警告您在启动另一个工作树之前检查名称；已接受的会话继续进行。清理保留由另一个草稿或浏览器保存的较新的签出选择，并保留并发模型更改。恢复的开始，其原始碱基选择无法与后来的编辑区分开来，也会使保存的名称保持不变并显示该警告。如果无法确认保存新的草稿选择，则会出现单独的警告，要求您在开始之前检查选择；首选项清理永远不会重试会话创建。

在第一个识别的连接上，仅当网关尚无此类首选项时，Control UI 才会上传现有的浏览器本地新会话首选项。并发的第一个连接会保留另一个浏览器已保存的选择，包括清除的工作树名称。以后的更改首先写入网关，然后更新浏览器镜像。没有持久身份的连接将继续使用浏览器本地首选项和加载的最近会话名册。

当远程项目会话在其存储库完成克隆之前启动时，聊天会显示工作区准备进度。如果准备失败，打开或重新加载聊天将恢复会话的失败摘要。更正报告的问题，然后在同一会话中发送新消息以重试准备。

接受的浏览器消息（包括等待工作区准备和运行期间的后续操作的初始提示）将像正常消息气泡一样保持可见，直到轮到它们自己为止，而无需额外的接收通知。通过 `sessions_send` 或网关 `agent` 方法接受的输入使用相同的显示。它们与活动模型转录本分开存储。如果取消或网关重新启动中断了等待，则消息将以其记录的配置保持可读，并且永远不会自动重新发送。停止的消息保留在对话中的原始时间，之后发送消息之前；只有仍在等待运行的输入才会停留在实时边缘。将停止的消息复制到编辑器中以开始新的尝试。 **显示较早的消息** 翻阅仍在等待或在处理之前已停止的消息； **显示最新消息**返回最新页面。传入的活动会刷新您正在阅读的页面，而不更改您的选择。长消息使用普通的完整消息阅读器，不会成为文字回复、分叉或倒带目标。

当新的聊天开始时，作曲家仍然可用。您可以继续输入并排队后续消息；他们在最初的提示后等待并保留订单。在网关确认新会话之前，这些后续操作将保留在当前选项卡中，因此请保持其打开状态。如果创建失败，原始提示、排队的后续和未完成的后续草稿仍可重试。创建成功后，后续人员将使用已确认对话的正常发件箱。失败的初始提示会使其后续提示暂停以供审核，而不是提前发送它们。

浏览器草稿和未发送的消息保留在本地队列中。一旦网关接受普通浏览器消息，它就拥有持久保管的批准输入。收集模式使用已接受的源及其组合的转录条目。接受并不意味着转录本行已经存在；接受的输入将替换其本地待处理副本，并随后成为一封已保存的消息，包括其附件。消息通过提交、接受、重新连接和存储恢复来保持其队列位置。更改交货状态不会重新订购；显式队列重新排序和转向保留其正常行为。

## <a id="systems-workspace"></a> 系统工作区

打开 **Pages → Systems**，或访问 `/systems`，检查可用于连接的网关、工作人员环境和配对设备。使用页面中系统旁边的固定按钮，或将其拖到导轨中，以保留个人快捷方式。

当系统打开时，在导轨中选择 **Sessions** 以显示其上下文计算机列表而不是对话。页面和用户保持独立的视图。中间列表独立于导轨滚动；侧边栏标题和导轨的底部控件保持固定。返回对话会恢复其侧边栏滚动位置。导航改变了这种背景；后台计算机或会话活动不会切换您的工作区。

使用搜索字段旁边的 **过滤和排序机** 按字母顺序对每个组进行排序，在线优先（默认）或离线优先。选择 **All**、**Online** 或 **Offline** 按报告状态进行过滤；搜索进一步缩小了选择范围。启动、停止和错误状态在 **All** 下仍然可见。过滤不会更改工作区中打开的机器。当您离开 Systems 并通过同一连接返回时，这些选择将保持不变。

本国的CLI仅当目录包含与当前所有者过滤器匹配的会话时，目录才会出现。即使发现失败或CLI可以开始新的会话。连接时加载目录。当网关通告目录更改事件时，目录会通过有节奏的突发和十分钟的安全刷新来刷新这些事件。否则，可见选项卡每隔刷新一次目录30秒。返回隐藏选项卡也会刷新其目录。如果还有更多页面，发现将跟随其光标，直到出现匹配的会话、目录耗尽或主机报告错误，而不重复首页请求。当浏览器选项卡隐藏时，Discovery 会保留其进度并暂停。稍后刷新会检查第一页是否有新会话，并重新启动已完成的空扫描，以便仍然可以发现可见的旧会话。扩展目录在刷新时保留其加载的页面。当另一台主机发生故障时，填充的目录仍然可见，并在其状态指示器中显示发现详细信息。隐藏目录不保留**其他**当标题是唯一剩余的部分时可见。本国的CLI开始时间仍然可用**新会话**。

**标记为未读** 创建一个提醒，该提醒在当前聊天保持打开状态（包括跑步流式传输或完成时）时保持未读状态。离开并重新打开会话，或选择 **标记为 read**，以清除它。

以查看者身份打开会话会保留其未读标记，包括共享会话。草稿会话仅确认其所有者或管理员自动读取。如果网关因会话状态无效或缺少访问而拒绝自动读取确认，则 UI 会针对该未读剧集报告一次错误，并等待新剧集或您重新打开会话。暂时失败可以在稍后的会话更新时重试。手动未读提醒仍然保留，直到您重新打开会话或选择 **标记为已读**。

**Delete** 立即从加载的会话列表中删除已确认的选择，并保留任何打开的已删除对话。网关在后台完成删除，首先安全地停止并回收附加的云工作线程。如果删除失败，受影响的会话可能会重新出现并出现错误；其他成功的删除以及您在此期间进行的任何导航都会保留。浏览器草稿仅在确认删除后才会停用，而不是在请求挂起时停用。内存中的草稿交接在确认后立即停用。在存储清理期间切换网关会保留其他网关的草稿和排队消息。如果在存储清理开始之前连接或登录所有者发生更改，或者恢复准备时间超过十秒，则存储的草稿保持不变，并且 UI 报告清理失败。

删除嵌套会话使剩余的子列表在请求挂起时可用。通过挂起删除隐藏的会话不会使原本完整的子列表变得不完整。如果网关在有限重试后无法返回完整的子列表，侧边栏仍会显示列表错误并提供 **Retry**。

在“会话”页面上，复选框选择在加载列表中分页后仍然存在。当列表刷新时，已消失、离开当前过滤器或被替换的会话将被取消选择。替换者永远不会继承旧会话的选择。批量删除仍然与您选择的会话绑定，包括在其确认对话框打开时。如果您在之前的删除尚未完成时选择了替换项，则其较晚的确认会保留您的新选择和替换项的详细信息。它不会将当前对话从替换对话中切换出来。同样，延迟重命名、存档或恢复确认只会清除原始会话的复选框，同时保留您选择的替换项。

侧边栏、聊天标题和会话页面中的 **Rename** 以您的自定义名称或生成的仪表板标题开头。编辑文本，然后保存或按 Enter 键。保存未更改的生成标题可使自动命名保持不变；清除自定义名称将恢复生成的标题。频道和帐户装饰位于可编辑名称之外。重命名目标是您开始编辑的会话。如果在保存之前删除了该会话并以相同的键重新创建，则编辑将被拒绝，而不是重命名替换。重新打开当前会话的重命名以重试。重置对话会保留相同的会话标识，并且不会使编辑无效。

自动标题遵循第一条消息的语言，包括带引号文字的简短说明。标题的长度上限为 60 个字符，截断后不匹配的引号将被删除。空或仅引用模型输出使用可读的甲壳类主题后备名称。

**侧边栏、聊天标题或会话页面中的新组** 在对话框打开且保存组时保留原始会话选择。已删除或替换的会话不会被移动；将显示错误，但新组仍然可用。对于侧边栏多项选择，即使另一个目标失败，仍然存在的会话也可以移动。将选定会话调出可见列表不会取消其移动。

您保存的自定义名称始终优先于自动标题，即使它类似于 Android 设备标签（例如 `OpenClaw App · Phone · abc123`）。保存为自定义名称的旧设备标签将保持该优先级，直到您明确清除或替换它们。新的 Android 设备标签单独存储，因此生成的对话标题可以替换设备标签，而无需更改您的自定义名称。

### <a id="session-menu"></a> 会话菜单

可以固定根会话和普通的主页链接仪表板会话。生成的会话和嵌套子会话拒绝 pin 请求，包括当它们显示为顶级线程时。子代理运行还会拒绝 pin 请求并保留在侧边栏导航之外。

普通对话的 **Actions** 菜单还提供 **Move to group**，即使其标题链接回 Home。该面包屑不会使对话成为嵌套子项。

固定的父级是单轨快捷方式。其缩进子树和 expand/collapse 控件保留在会话列表中，受当前过滤器的影响。

根菜单将日常操作集中在一起：**Pin/Unpin**、**重命名**、**标记为unread/read**、**复制链接**、**分配给…**、**移动到组**和**Archive/Restore**。仅当符合条件的目录包含不止一个人或智能体（包括您自己）时，才会出现分配；在线状态并不决定资格。侧边栏在存档旁边还提供 **Snooze/Wake 会话**。与儿童的会话有一个 **存档会话** 子菜单，仅包含 **会话** 和 **存档会话和儿童…**；后者仍然证实了受影响的对话。

**高级**包含**图标和颜色**、**叉对话**、**复制详细信息**、**打开在**、**发送消息**和**接收消息**首选项中，以及**底部删除**。仅当从 **Involving me** 列表中打开菜单时，Involving me**中的个人**Hide/Show 才会突出；在其他地方，它停留在高级状态，受相同的多用户可用性的影响。在手机上，子菜单会替换当前菜单页面，并且 **Back** 返回其父菜单。

- 在侧边栏会话菜单中，**Snooze**提供**在1小时内**，**在3小时内**，**这个晚上**（当地时间18：00，当距离超过一小时时）、**明天**（当地时间09：00）和**下周**（当地时间下周一09：00）。在星期日，下周被省略，因为它与明天匹配。每个预设都会显示您所在区域的唤醒时间。可以暂停符合固定条件的活动会话，受保护的主会话和哨兵会话除外；存档和嵌套子会话不能。移至顶层的孩子可以小睡一下。暂停的会话提供 **唤醒会话**。
- **图标和颜色** 打开一个带有色样、图标网格的选取器，并将 **重置为默认值**。当您更改两者时，它会保持打开状态；侧边栏反映了您的更改。
- **移至组**包括**新组**和**从组**中删除。当有多个合格所有者可用时，**分配给** 保留在根菜单上（[ 会话所有权](/concepts/multi-user#assigning-an-owner)）。
- **Fork对话**创建一个单独的对话；当运行处于活动状态时，它会从最后完成的消息中分叉。本地文件夹和项目会话的分支保留该工作区，因此现有文件引用将继续打开。 **从这里分叉**也保留相同的本地工作空间。
- **复制链接** 一步复制会话链接。 **高级 → 复制详细信息** 提供预览链接、对话文本 Markdown 和会话 ID，无需复制公共会话链接。该链路需要正常的网关认证和会话访问；复制它并不授予访问权限。 Markdown 加载可用的对话历史记录，而不仅仅是当前可见的消息。复制的 Markdown 和 `/export` 下载都保留了对话的发件人标签，因此来自不同参与者的消息仍然可以区分。没有可导出文本的记录（例如没有文本输出的工具调用）将被忽略。
- 中的Control UI、`/export`和`/export-session`通过浏览器下载Markdown，不带文件路径。争论使草稿保持完整并显示如何重试。通过其他客户端可用的服务器端 HTML 导出保持其单独的工作空间路径行为。
- 聊天标头的 **会话共享** 控件管理经过身份验证的队友可见性和成员身份。对于已保存的非隐身会话，其创建者或网关管理员还可以启用全球可读的只读公共访问。
- **在**中打开提供新的浏览器选项卡或窗口。桌面聊天还提供**拆分右**和**拆分如下**。当同一对话在多个拆分中打开时，每个窗格都会在页面重新加载后恢复其记录，并在另一个窗格进一步领先时独立地赶上。升级后，在恢复增量更新之前，会从网关刷新旧的缓存记录。合格的本地工作区公开本机编辑器目标，并且聊天标头包括此子菜单中的 **Continue interminal**。

如果“会话”页面上的所有者分配失败，该页面将保留会话并显示网关的错误。解决报告的问题，然后重新将 **分配给** 重试。先前连接的延迟失败不会替换当前页面的状态。 **Assign to** 菜单标记会话的当前所有者并禁用该选择，包括在团队目录正在加载或不可用时。

### <a id="share-a-session-publicly"></a> 公开分享会话

1. 打开保存的会话并在聊天标题中选择**会话共享**。在紧凑标题菜单中，选择 **Sessionsharing** 。
2. 在**公共访问**下，选择**启用公共访问…**，查看警告，然后选择**公开**。
3. 选择**复制公共链接**复制普通线程URL。聊天标题中的 **Public** 徽章在发布记录时保持可见，并在另一个窗口更改公共访问时更新。
4. 在注销的浏览器中打开相同的 URL 以验证只读对话和 **登录** 按钮。登录将返回到具有您现有权限的线程。新的用户消息和助理最终答案将自动对公众读者可见。
5. 返回**会话共享**并选择**禁用公共访问**以停止匿名读取。然后，同一 URL 将不可用页​​面返回给已注销的读者。再次启用访问使 URL 再次公开；禁用访问无法调用已保存的副本。

公共页面不包括工具、推理、文件、图像、小部件、隐藏消息和内部元数据。包含的文本未经过秘密屏蔽，因此在发布之前请检查对话中的凭据和其他敏感内容。公共访问不允许访问者发送消息或授予经过身份验证的 Control UI 权限。有关链接生命周期、分页、备份行为和登录代理配置，请参阅 [ 公共会话记录 ](/web/urls#public-session-transcripts)。

### <a id="session-placement"></a> 会话放置

将云会话悬停在侧边栏中可查看其提供商和配置文件。已知后，它们下面的紧凑行会显示 GB 中的操作系统、机器类别、vCPU 数量和内存。放置徽章工具提示包含相同的机器详细信息；不可用的字段被省略。

在工作线程上运行的选定会话会在聊天标题中显示 Cloud**芯片上安静的**Runs。与 `operator.write` 的连接可以选择 **Move 会话…** 在网关或符合条件的配对设备上继续，并且可以通过写入范围的 `sessions.reclaim` 生命周期使用 **Stop 云工作线程…**。迁移到已配置的云配置文件需要 `operator.admin`。云行会根据每个配置文件公布的所有执行模式进行过滤：OpenClaw `worker-turn` 和 Codex `remote-exec` 可以选择相同的捆绑 Crabbox 配置文件，而真正的单模式配置文件对于其他运行时保持禁用状态。具有多个机器类别的配置文件显示机器选择器。保持移动会话选择器不变会忽略尺寸覆盖；显式选择一个类（包括显示的默认值）会发送该类。在当前配置文件上选择不同的类会调整会话的大小。确认信息解释了当前回合被中断并且永远不会重播； OpenClaw 在激活目标之前协调工作区。当持久操作正在进行时，芯片显示 **Moving to…**。如果恢复被阻止，芯片会在重新连接后暴露有限错误，因此操作永远不会默默失败。

您可以在现有工作会话正在配置或准备其工作区时发送消息。接受的消息显示 **已接收 · 正在等待工作程序设置** 并在该工作程序准备就绪后自动启动。停止、移动和重新启动保留自己的准入控制；取消或中断的输入不会在不同的目标上静默启动。新会话流程中未发送的草稿仍然与已接受的输入分开。

在初始切换期间，聊天放置菜单和停止确认使用选定的目标：**Stop 设备工作人员...** 用于显式或自动配对设备放置，**Stop 云工作人员...** 用于云配置文件，或中性 **Stop 工作人员...**目标未知；全部使用`sessions.reclaim`。启动失败后保留重试的目标不会标记稍后重新启动。

### <a id="session-icons"></a> 会话图标

从单个会话的上下文菜单中选择 **高级 → 图标和颜色**，为其侧边栏行提供持久的表情符号、单色图标或自定义 SVG。该选择器包括常见的表情符号和六个命名图标：`braces`、`book`、`monitor`、`bot`、`kanban` 和 `coins`。选择 **自定义图标...** 输入单个表情符号，粘贴 SVG 标记，或粘贴 SVG 数据 URL（百分比编码或 base64）。 SVG 必须是独立的，并且最多可解码 16 个 KiB；脚本、嵌入文档和外部引用将被拒绝。包括 `xmlns="http://www.w3.org/2000/svg"` 和 `viewBox`。自定义 SVG 渲染为图像，保留其自己的颜色。对于表情符号，请按 macOS 上的 Control-Command-Space 或 Windows 上的 Windows-period 打开系统选择器。 `sessions` 代理工具可以设置相同的 `icon` 字段。空值会将其删除。此装饰取代了前导字形槽中的所有者头像，但临时注意状态始终优先，因此无法隐藏操作员请求。

通过 **Person** 分组，打开所有者筛选器标题以显示一位所有者，包括您自己。选择 **所有所有者** 仅清除所有者过滤器。标题显示当前所有者或**涉及我**选择； **Filter & sort** 保留状态过滤器和 **Reset** 操作，用于恢复所有可见面板设置而不更改所有者。

## <a id="session-colors"></a> 会话颜色

从会话菜单中选择 **高级 → 图标和颜色**，然后选择色样以添加柔和的全行色调、窄色带以及聊天标题旁边的匹配点。侧边栏标题和元数据在浅色和深色模式下保持中性和可读性。固定的行使用相同的色调；开放对话保持明显的中性填充和更强的标题，而多选行使用选择填充而不是会话色调。选择八种颜色之一，或选择 **Default** 仅清除颜色。 **重置为默认值** 清除图标和颜色。颜色与 Claude Code 的 `/color` 名称相匹配，因此导入的 Claude Code 会话保持相同的颜色。导入的目录行显示其颜色，但不提供颜色编辑。

## <a id="direct-session-shortcuts"></a> Direct 会话快捷方式

- Mac 上的 **⌘⇧O** 或 Windows/Linux 上的 **Ctrl+Shift+O** 打开 **New Session** 并聚焦其编辑器。它会打开草稿，而不创建空会话或发送消息。 **⌘N / Ctrl+N** 仍为 **新窗口**。
- Mac 上的 **⌘⇧A** 或 Windows/Linux 上的 **Ctrl+Shift+A** 仅针对当前聊天窗格请求 **Archive**，不适用于所选的其他会话在侧边栏中。它使用与聊天标题菜单相同的权限、受保护会话检查、存档生命周期和 **Undo**。存档的对话保持打开状态；这不是单独的停止或删除操作。

这两个快捷键都可以在聊天编辑器中使用，忽略按键重复和文本合成，并保持打开的模式对话框处于控制状态。键盘快捷键帮助对话框是新会话的例外：快捷键会在打开并聚焦草稿之前关闭帮助。再次按 **⌘/** 或 **Ctrl+/** 可关闭帮助而不导航。当帮助打开时，存档仍处于锁定状态。新会话通过正常导航保留现有对话的草稿。存档不会清除该草稿或导航到另一个对话。

浏览器快捷方式处理可能因浏览器版本和配置而异。如果您的浏览器本身处理和弦，请使用当前聊天标题菜单中相应的“新建会话”控件或 **Archive**。当菜单打开时，菜单的 **A** 快捷方式仍然有效。

在 macOS 应用程序中，当仪表板 Web 视图具有键盘焦点时，将应用这些附加快捷键。单独的本机阅读窗格不会将存档转发到仪表板或其他窗口。现有的本机 **⌘N** 新网关窗口和 **⌘⇧N** 新线程命令保持不变。

这些直接快捷键不会更改命令选项板的 **⌘K / Ctrl+K**，然后是 **⌘Enter / Ctrl+Enter** 在后台启动任务的工作流程。

## <a id="command-palette"></a> 命令调色板

命令选项板可以启动独立任务，而无需离开当前对话或设置页面。照常搜索会话、设置和命令，或在同一字段中编写提示。多行文本或 60 个或更多字符的提示会暂停调色板搜索并轻轻隐藏搜索选项卡、结果和提示。输入保持固定到位。当文本为单行且缩短至 50 个字符或更少或已清除时，搜索将返回。在 51 到 59 个字符之间，调色板保持其当前模式以避免编辑时闪烁。计数不包括前导和尾随空格。会话创建错误和恢复操作在任一模式下仍然可见。

粘贴的图像在文本下方显示为可移动的小缩略图。粘贴或删除它们会保留输入、**New session** 操作和设置控制；调色板向下生长。图像可以单独启动会话或伴随文本。调色板中没有附件选择器。

### <a id="start-a-native-coding-cli"></a> 开始本机编码 CLI

**+** 旁边的 **Codex** 或 **Claude Code** 打开本机 CLI 草稿，而不是OpenClaw 聊天。选择计算机和文件夹，可以选择输入第一个提示，然后在终端中按 **Start** 或 Enter（或您配置的提交快捷方式）。终端以键盘焦点打开。 CLI 使用该机器的本机帐户、模型和配置； OpenClaw 不会转换模型或身份验证设置，也不会自动采用本机会话。本机草稿文本不会发送到 OpenClaw 以进行自动标题准备。普通 **New Chat** 和显式目录延续保持独立的流程。

本机启动需要 `operator.admin`、`gateway.cliAgents.enabled`、启用的目录插件及其安装的 CLI。终端默认开启； `gateway.terminal.enabled: false` 阻止本机启动。无需匹配 OpenClaw 模型路线。每台机器都有一个启动目标。仅当有选择或先前选择的机器不可用时，才会出现 **Where** 选择器。它列出了网关的本机 CLI 和连接的节点以及当前可调用的确切的全新启动命令；仅恢复节点不符合条件。网关重新连接以及节点连接或功能更改后可用性会更新。安装CLI后，重新连接网关；批准节点功能更改后，重新连接该节点。

新的网关本地 Codex 会话使用为其目录配置的主要本机 Codex 配置文件，通常是网关用户的 `CODEX_HOME` 或 `~/.codex`。选择一个文件夹可以让 Codex 加载该项目的可信配置；它不会选择其他帐户或 Codex 主目录。其他 Codex 家庭仍然可以使用其原始配置文件浏览和恢复现有会话。 OpenClaw 代理的临时应用程序服务器登录与本机 CLI 登录是分开的。

在网关上，folder/worktree 控件仍会在启动前配置选定的托管工作树。在节点上，输入该节点上现有的绝对目录；如果需要的话，首先在那里创建一个工作树。本机启动不使用 OpenClaw 工作器放置、cloud/Auto 选择、附件提交、模型控制或隐身模式。在终端中添加文件并更改本机 CLI 设置。丢失目录、禁用功能或断开主机会产生错误； OpenClaw 从不启动聊天或替换另一个主机或主目录。如果CLI在启动过程中退出，终端将保留其输出和退出状态。如果启动被拒绝，草稿仍可进行更正并重试。

### <a id="openclaw-chat-workspace-startup"></a> OpenClaw 聊天工作区启动

在 OpenClaw 聊天发送中，当网关创建或采用会话时，提交的文本和附件会立即显示，并带有 **Starting** 指示符。这是待提交的提交，而不是网关确认。如果创建被拒绝，您的提示和附件仍然可以纠正并重试。创建成功后，UI 将打开会话的聊天。如果导航失败，则提交的消息通过 **Open session** 操作保持可见，该操作会重试导航，而无需再次创建或发送。后台启动会在下一个草稿上方保留相同的可见确认，并带有指向所创建会话的链接。

如果模型目录仍在加载，会话创建将在共享的 20 秒目录截止时间后停止等待，并报告会话尚未创建。稍后重试；您的草稿仍然可用。关闭请求连接或失去其权限也会结束挂起的目录等待。

启动建议的任务会立即删除其卡片，而无需切换会话或更改草稿。确认后该卡将保持隐藏状态。如果会话创建失败或接受被中断或未经确认，该卡将重新出现，并附有其原始说明和恢复控件。 **Retry** 检查相同的任务并保留所选的启动模式。确认的重试会清除该任务之前的错误横幅，但不会清除较新的或不相关的聊天错误。技能研讨会修订版在加载历史记录时将其提交的指令带入聊天中。

归因提交会立即显示您的头像，位置与聊天记录相同。打开创建的会话，作曲家安静地集中注意力；注意提示是为预填写草稿的导航保留的。

项目选择器会在登录、重新连接和网关配置更改后刷新。远程存储库选项保留在登录者的网关范围首选项中，并从共享浏览器中排除 fallback/migration. 从先前的 GitHub 主机保存的远程存储库将被丢弃；新会话使用当前配置的存储库或代理工作区。网关重新连接和 Git 验证重试会保留您编辑的基本分支和工作树名称。选择另一个文件夹或项目会清除这些存储库特定的详细信息。

对于本地工作树会话，在命名、签出和设置完成之前发送第一条消息将打开已承认的会话。聊天显示提交的消息和准备阶段。命名完成后，生成的标题将立即保存，与结帐和设置无关。设置失败在该会话中仍然可见；纠正问题后发送重试。重试将重新使​​用已保存的标题。如果命名本身失败，则另一次尝试将使用原始的第一个提示，包括文本附件。在设置过程中停止会取消准备，而不启动代理。引导活动运行可使其进度可见，并且延迟的历史记录无法替换较新的启动阶段或在活动开始后恢复启动标签。

对于设备和云会话，一旦创建会话，提交的提示也会启动后台命名。当工作人员仍在配置时，侧边栏可以显示其主题；第一个任务轮次等待，直到放置准备就绪。准备好的标题或自定义会话名称保持优先。隐身会话会跳过这个早期命名步骤。

对于远程目标，Control UI 创建具有空初始消息且没有 `execNode` 的存储库或托管工作树会话，通过精确的 `deviceId`、`autoDevice: true` 或 `profileId`（加上可选的云计算机类）分派它，等待主动放置，然后使用与恢复以防止重复发送。显式自动设备调度需要`operator.write`；云配置文件调度需要 `operator.admin`。作曲家页脚选择新会话的模型和推理级别。

Model 和 **Effort** 是桌面和移动设备上聊天和新会话中单独的相邻作曲家控件。模型选择器从不包含“Effort”或“Fast”模式控件。长模型标签呈椭圆形，为其他控件留出空间；全名保留在打开的选取器和可访问标签中。狭窄的编辑器（包括较宽窗口中的分割窗格）使用紧凑的控件，因此每个选择器都可以独立单击。 Effort 在这些布局中使用仪表，其指针反映当前级别，当快速模式处于活动状态时，带有闪电徽章。在聊天中，快速模式保留在“努力”菜单中，或者在推理不可用时显示为相邻控件。没有可用控制的模型会忽略它。

模型选择器最初打开时，所选模型的提供程序部分展开，其他提供程序部分折叠。关闭并重新打开同一个选择器会保留您的提供商扩展选项并清除搜索。重新加载页面会再次初始化所选模型中的提供程序部分。按模型名称、模型 ID、提供商或 provider/model 参考搜索模型选择器。当模型目录刷新时，您的搜索将保持应用状态。按 **Escape** 清除非空搜索，同时保持选择器打开；再次按下它可关闭选择器并将焦点返回到其触发器。

当您切换会话时，Composer 会保持会话的已知模型名称可见，同时刷新该会话可用的模型选项。如果模型尚不清楚，控件将显示加载占位符。锁定的聊天还会显示所选模型，或 **会话模型**（当未知时）。该锁可防止模型选择发生变化；它并不表明本机运行时拥有该模型。

创建会话后，聊天将立即打开。远程启动使用与 GitHub 工作区准备相同的脚本进度指示器和已用计时器，显示配置、工作区准备、启动和第一条消息传递。编辑器保持可编辑状态，当第一条消息未解析时，普通后续消息可以进入本地队列。他们的交付会等到初始消息得到解决。正常启动不会出现错误。启动失败在会话中仍然可见，当恢复可用时，会显示 **Retry**。

如果页面重新加载后无法加载启动恢复，则会话会在会话切换时保持加载错误和 **Retry** 可用。切换会话不会重新启动恢复或重置其已用时间。保存的第一条消息继续阻塞排队的后续消息的传递，直到恢复加载并确认其传递状态。虽然此页面具有响应能力并且未保存的启动等待恢复代码，但自动应用内重新加载将被阻止，并且 **Retry** 会被警告替换。这包括隐身启动和无法保存恢复的暂停启动。应用程序其他地方的重新加载控件解释了相同的限制。选择 **放弃未保存的开始并重新加载** 以恢复保存的开始并放弃未保存的开始。其他被阻止的重新加载控件显示的警告中也可以执行相同的操作。这种保护仅限于开放的、响应式的页面；关闭它或浏览器管理的导航仍然可以丢弃未保存的输入。隐身输入永远不会保存到浏览器存储中。

如果在发送第一条消息之前远程启动失败，聊天将在同一浏览器选项卡和网关凭据范围中保留提交的文本、附件、选定的目标和有限错误。重新加载会显示暂停的提交，而无需配置其他工作人员。 **Retry** 保留存储库 URL/ref 或网关工作树选择，并使用已创建的会话和原始配置文件以及机器类别、设备或自动选择；它在发送之前等待活动放置。该会话保留其模型和推理设置，包括您在该会话中所做的任何后续更改。此选项卡本地启动恢复使用选项卡的现有会话存储生命周期，与下面的普通浏览器草稿限制分开。隐身启动恢复仅保留在内存中。普通的重新连接使已提交的提示保持可见，并使用 **Reconnecting**。 **重试**和**检查交付**等待就绪连接。更改网关、凭据或经过身份验证的所有者将清除私人演示。断开连接时，普通后续消息可以进入本地队列。在重新连接后的简短帐户恢复检查期间，提交的输入保留在编辑器中。检查完成后，队列准入将恢复，但传递仍会等待，直到初始消息得到解决。

如果网关明确拒绝第一次发送，则 **Retry** 在同一会话和目标上创建新的发送尝试。如果传递不确定，**Check传递**会查找原始用户消息或显示输入被保留或消耗的确切网关收据。它永远不会重新发送提示、提供工作人员或将丢失的历史记录视为交付失败的证据。匹配的收据会清除浏览器启动保留，但并不意味着运行已完成。提示保持可见，直到聊天收到相应的网关拥有的输入或转录消息，然后切换到该权威副本而不重复。保留的输入保持其网关拥有的状态，包括中断或取消的输入。如果没有收据，提示和附件仍然可以访问，并且排队的后续操作仍然保留。您可以继续起草或排队普通消息。检查对话，或者如果您选择开始单独的尝试，则复制保留的提示。此恢复不保证在网关重新启动时进行一次性交付。如果浏览器存储拒绝恢复更新，请保持当前页面打开以保留其内存中输入。

当中断的远程放置草稿需要删除时，清理会通过会话密钥回收放置，使用预期的会话标识对其进行存档，然后使用写入范围的仅存档删除协定。清理错误仍然可见。如果成功清理中断的隐身启动，当前窗格将保留其提示和中断通知的只读副本。它不会重新创建会话或重新发送消息；该副本仅在当前浏览器选项卡和凭证范围内持续。恢复暂停或未确认的恢复本身并不请求删除。

未发送的文本和暂存的附件只能在相同的浏览器配置文件和网关凭证范围内恢复；它们永远不会存储在网关上或跨设备同步。浏览器会将每个网关凭据范围的 20 个最近编辑的草稿范围保留最多 7 天，每个草稿最多包含 25 个 MiB 附件数据，但它可以更快地清除浏览器存储。成功发送或创建新会话、显式附件删除或确认会话删除都会停用相应的浏览器草稿。如果删除后清理失败，请清除 Control UI 源站的站点数据以将其删除。清除站点数据还会删除所有其他浏览器草稿。如果草稿的附件超出上限，当前选项卡将保留它们并显示现有存储警告，但只有文本是可重新启动恢复的。 OpenClaw **Incognito** 草稿永远不会持久。关闭隐身模式会恢复当前文本和附件的浏览器自动保存，无需再次编辑。切换新会话目标，或将现有的隐身聊天保留为“设置”并按“后退”返回，会将未发送的文本和附件保留在当前选项卡中。重新加载或关闭选项卡会丢弃未发送的输入。当未发送的隐身草稿保留在聊天窗格、新会话或其导航切换中时，自动 UI 更新会暂停。如果更新需要新页面，则发送仍然不可用；选择 **Refresh** 和 **Review private Draft** 来复制文本或下载暂存文件、保持选项卡打开或明确放弃该草稿并重试刷新。其他未保存的工作防护仍然适用。此保护需要运行更新的 UI 的文档；服务器更新无法将其改装到已打开的旧页面中。手动浏览器重新加载或关闭选项卡仍然会丢弃仅内存草稿。在仅限选项卡的内联发件箱中提交的隐身消息保留其单独的重新加载行为。在私有浏览器窗口中，IndexedDB 的可用性和生命周期由浏览器控制，并且存储的数据通常在私有会话结束时被清除。新会话页面右上角控制栏中的 **Incognito** 切换会停用浏览器草稿并创建一个仅 Web 线程，其会话条目、转录和压缩状态在创建后或直到网关重新启动（以先到者为准）在内存中保留 24 小时； OpenClaw 还跳过其自动内存刷新。代理保留其正常工具，因此显式保存请求或工具驱动的文件写入仍然可以保留数据。模型提供者仍然处理消息，并且仍然记录与内容无关的审计元数据。远程放置在将会话分派给其工作人员之前开始保留其模型和推理选择。

<a id="register-an-existing-repository" />

**Projects.** 地点选取器列出了使用 `projects.register` 记录的已配置代理工作区和存储库。只读连接接收项目名称和 ID；结帐路径和原始 URL 仅包含在 `operator.write` 中。管理员可以浏览到 Git 签出并选择 **注册为项目**；只写操作员会看到一条提示，将他们引导至该流程。选择一个项目通过 `sessions.create` 发送其 ID，因此它可以直接运行或为可选的工作树隔离提供源，而无需提交原始路径。如果代理工作区已移动或删除，请更新该代理的已配置工作区路径。如果记录的结帐已移动或删除，请在开始另一个会话之前重新注册它。

您还可以通过 [Gateway CLI](/cli/gateway/query#gateway-call-%3Cmethod%3E) 注册现有结账。注册需要`operator.admin`；列表需要 `operator.read`。

```bash
openclaw gateway call projects.register \
  --params '{"path":"/srv/projects/example","name":"example"}' --json
openclaw gateway call projects.list --json
```

即使 CLI 在另一台计算机上运行，​​也请在运行网关的计算机上使用绝对路径。网关服务帐户必须能够访问 Git 签出，并且其 `HEAD` 必须解析为提交。注册记录现有的结账，而不是克隆它。 `name` 是可选的，默认为签出目录的名称。

再次注册相同的解析存储库根会返回其现有项目 ID 和显示名称。传递不同的 `name` 不会重命名现有项目。

`projects.list` 通过只读工作线程读取已提交的注册表行，而无需检查 Git 或加入不相关的状态写入。注册时需要时初始化注册表；列出空注册表并不会创建它。最近的项目和文件夹不会等待会话显示详细信息刷新。具有 `operator.write` 的操作员可以请求 `{"includeObserved":true}` 从可见会话和托管工作树中发现其他签出。列表立即返回最后一个 Git 发现快照，同时一个有界后台通道刷新相同的签出集。冷集最初仅包括记录的工作树事实；发现完成后，将出现仅会话签出。快照一分钟后，外部远程更改以及移动或删除的结账会在第一个列表的后台刷新。更改的签出集会启动新的发现，网关关闭会取消挂起的刷新并清除快照。列表在发现期间保留会话快照，并在回复之前重新检查贡献会话。不相关的会话创建和活动不会使正在进行的列表无效；更改对贡献会话的访问权限仍需要重试。

GitHub.**中的** 项目搜索相同的选择器或粘贴 GitHub HTTPS 或 `git@github.com` 存储库 URL。对于远程目标，创建记录该源，并且运行器在调度期间获取它；不需要网关项目克隆。对于网关执行，选择器克隆到网关管理的项目区域。最近的存储库源保留其 URL，而不创建本地路径。公共存储库搜索和克隆以匿名方式进行。私密远程结账使用有效共享`tools.github`身份；下面的发现凭证仅授予选择器访问权限。对于附属存储库和私有存储库，首选显式 `gateway.controlUi.github.token` SecretRef，以便此服务访问具有明确的运行时所有者。将`gateway.controlUi.github.host`设置为所选的Enterprise主机；省略的凭证主机表示 `github.com`。发货的 `GH_TOKEN` 和 `GITHUB_TOKEN` 后备仅适用于 `github.com`。设置 `gateway.projects.nativeGitHubSearch: true` 的可信主机会为每次搜索准备当前本机系统 GitHub 身份；这适用于受保护的 `gh` 包装器或主机登录，并保留本机身份的 60 秒缓存和旋转栅栏。 Ambient `GH_ENTERPRISE_TOKEN` 或 `GITHUB_ENTERPRISE_TOKEN` 需要 `GH_HOST` 来匹配所选的 Enterprise 主机；仍支持特定于主机的本机登录。当 Control UI SecretRef 是显式的时，其确切环境或存储名称将从代理执行中排除，而不清除不相关的本机 GitHub CLI 变量。搜索将 GitHub 响应页面缓存 60 秒，在同一凭证的查询之间共享附属存储库。过期页面返回 `stale: true`，同时每页运行一次有界后台刷新，在 GitHub 提供 ETag 时使用 ETag。每个响应都会重新检查请求连接和当前的 GitHub 身份；撤销或取消将停止交付。每个出站请求还会重新检查发起请求者的权限。刷新属于网关并在其生命周期内停止。搜索需要 `operator.read`，克隆需要 `operator.write`，删除网关管理的克隆结帐需要 `operator.admin`。当实时会话或托管工作树仍然引用签出时，克隆删除会被拒绝。 SecretRef 所有权不是 OS- 用户安全边界；当同一帐户进程不受信任时，使用沙箱、专用主机或专用 OS 用户。

对于 GitHub 企业部署，配置 `gateway.github.host` 和 `gateway.github.apiBaseUrl`。 GitHub 企业服务器使用`https://HOSTNAME/api/v3`；其 GraphQL 请求使用 `/api/graphql`。要在新会话上预选存储库，请设置 `gateway.projects.defaultRepository.url` 和（可选）其 `ref`。 OpenClaw 从 URL 派生存储库身份，并通过现有 `cloudWorkers.projectProfiles` 映射选择工作人员配置文件。该配置文件可以使用任何配置的提供程序，包括通过 Crabbox 插件使用 Azure。默认值仅返回给 `sessions.create` 授权的客户，并且仅在用户没有保存项目选择时适用；选择一个文件夹或另一个项目会覆盖它。

```json5
{
  gateway: {
    github: { host: "ghe.example.test", apiBaseUrl: "https://ghe.example.test/api/v3" },
    controlUi: {
      github: {
        host: "ghe.example.test",
        token: { source: "store", provider: "default", id: "example-enterprise-service-token" },
      },
    },
    projects: {
      defaultRepository: { url: "https://ghe.example.test/acme/private-repo.git", ref: "main" },
    },
  },
  cloudWorkers: {
    projectProfiles: { "ghe.example.test/acme/private-repo": "example-worker" },
  },
}
```

在创建会话之前，使用“工作量”菜单选择“快速模式”。新会话在第一个本地或远程回合开始之前保留该选择。

初始 `/think` 命令完成后刷新会话会更新聊天的“工作量”设置。

有关代理 GitHub CLI 身份和 Git 作者设置，请参阅 [`tools.github`](/gateway/config-tools#tools-github)。

过期的隐身链接会显示过期通知，而不是普通的新对话。 **新的隐身会话** 打开一个新的私人对话，并在当前选项卡中保留未发送的作曲家文本和附件；它不会自动发送它们。以前提交的未发送的消息保留在过期的会话中以供复制或丢弃，而无需重试操作。

在多用户 Gateway 上，只有管理员作用域的连接才能创建或查看隐身线程，其他会话无法通过代理会话工具或转录搜索访问它们。隐身功能可以防止存储层和其他由 Gateway 中介的用户访问，但无法防止 Gateway 所有者或进程操作员访问；后者始终可以观察实时会话。

**浏览文件夹** 通过 `fs.listDir` 打开地点选择器的内联网关目录浏览器。在路径字段中键入内容会在键入时过滤当前文件夹的子文件夹（精确匹配和前缀首先匹配，隐藏文件夹仅在文本以点开头时匹配）；输入新的目录前缀会列出该目录。 Up/Down 突出显示一个文件夹，按 Enter 键打开它，按 Tab 补全其名称。写入范围浏览从配置的代理工作区开始，无法在其上方导航； realpath 检查还拒绝逃离工作区的符号链接。管理员连接可以浏览任意网关路径。最近的地方仅恢复当前连接可以提交的网关文件夹；新会话不会浏览或记住节点文件系统路径。本地提交可以使用同一往返中的第一条消息调用`sessions.create`。远程提交使用上述创建、分派、然后发送顺序。如果网关创建会话但拒绝第一次发送，则聊天会在重新加载时保留提示和错误； **Retry** 通过已创建的会话发送它，而不是创建另一个会话。

### <a id="github-read-freshness"></a> GitHub 阅读新鲜度

GitHub 悬停预览、存储库搜索和帐户显示事实会重用上次成功的结果，而有界后台请求会刷新过期的元数据。他们的 RPC 响应将结果标记为 `stale: true`。冷读和显式预览刷新仍然等待GitHub。失败的刷新丢弃旧的结果；下一个请求报告失败或重试。

每个请求仍会检查当前访问、身份选择和令牌轮换。发布获得自己经过验证的凭据。详细的 PR 读取在显示内容或作业数据之前保留其实时公共存储库和精确头部检查。

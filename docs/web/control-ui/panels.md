停靠在当前页面旁边而不是替换它的表面。在移动聊天中，最右侧的 **Panels** 按钮对 **Details**、文件和可用工具进行分组。选定的工具可以填充对话区域，而不是共享狭窄的空间；加宽窗口可恢复保存的桌面布局。 **Details** 在作曲家上方打开全角覆盖。桌面保留 **Layout** 菜单和单独的 **Details** 控件。

详细信息使会话元数据可见。当拉取请求和自动化包含项目时，它们会显得展开；空白部分被完全省略。您可以折叠填充的部分，而无需普通更新重新打开它们。加载或失败的自动化读取会显示其状态并重试操作，而不会出现空的披露。任务进度仍然可以独立折叠。

## <a id="openclaw-system-care"></a> OpenClaw 系统维护

打开 **设置 → 要求 OpenClaw** 与系统设置和修复代理交谈。要在当前页面旁边打开它，请单击侧边栏页脚中的 **Home** 并选择 **Ask OpenClaw** 选项卡，或使用 **Ask OpenClaw**命令面板操作。整页和可停靠面板共享一个机器范围的对话，其持久的历史记录在网关上。关闭 UI 永远不会取消转弯；重新打开 Ask OpenClaw 显示已完成的对话。该面板停靠在右侧或底部，记住其在浏览器配置文件中的位置和大小，并在整个页面打开时隐藏自身。

如果未配置 AI 提供程序，Ask OpenClaw 会提供 **连接 AI 提供程序**。如果配置的运行时无法启动或验证，对话将保持可见，并显示实际错误和 **Retry**。在验证成功之前，发送将保持禁用状态。重试会检查运行时，而无需重新发送之前的消息或清除草稿。

当没有其他内容具有焦点时，入门引导建议可以集中推荐的答案。如果您已经将焦点放在作曲家或其他控件上，则到达的建议会将您的键盘焦点保留在那里。

每条聊天消息都会携带你当前正在查看的 Control UI 页面，作为不受信任的环境提示，因此像“配置这个频道”或“为什么这个页面是空的？”之类的请求，会根据你正在查看的页面来解析。

引导式频道设置、工作区技能设置、网页搜索提供商设置和本地 Gateway 设置会作为托管向导在聊天中运行。向导问题会保留在对话中，涉及机密信息的步骤会在浏览器中遮蔽输入，成功的配置流程会被审计并重新验证。如果所选的网页搜索提供商需要安装插件，而安装失败，设置流程会停止并报告失败，而不是假装提供商已经配置完成。

对于 Gateway 设置，请说 `configure gateway`，以选择端口、绑定地址、令牌或密码身份验证，以及 Tailscale 暴露方式。在第一个问题出现之前，网页界面会警告：应用已保存的设置需要重启，这可能会导致聊天断开，或需要重新登录 Control UI。向导只会修改配置；准备好应用设置时，请说 `restart gateway`。它只管理本地 Gateway，因此远程模式的更改仍需在 `openclaw onboard` 或 `openclaw configure` 中进行。

说 `import memory` 将检测到的本地内存复制到现有的默认代理工作区中。此流程不会更改配置或导入凭据或技能，不需要重新启动网关，并区分已确认的导入、没有要导入的内容、提供程序故障以及某些文件可能已被复制的故障。如果默认工作区不存在，请先完成登录。请参阅 [ 导入助理内存 ](/web/control-ui/settings#import-assistant-memory) 以了解可以针对其他代理或替换现有导入的更广泛页面，以及 [`openclaw setup`](/cli/openclaw) 以了解操作和审批合同。

在入门引导之外，此页面每次访问最多可以显示一个可忽略的事件筹码。它对常规网关流量保持沉默，仅对报告禁用的配置重新加载器、配置的通道 disconnect/degradation、失败的通道检查或不可用的通道凭据的运行状况快照做出反应。仅当事件更为严重时，较新的事件才会取代待处理的筹码；关闭或使用芯片会使该访问的事件提示静音。单击芯片会以真实的 `openclaw.chat` 消息的形式发送其诊断问题，因此脚本会记录该请求，并且 OpenClaw 会执行诊断。入门引导从来不会显示这些事件筹码。

## <a id="home-dock"></a> 家庭扩展坞

使用**家**侧边栏页脚中的按钮，或侧边栏折叠时工具栏中的按钮，以在当前页面旁边打开所选代理的主要对话。选择**问OpenClaw**同一扩展坞中的选项卡用于系统设置和修复。当同一个主页对话已与页面打开时，停靠栏将保持隐藏状态，而不是显示两次。

您的主页草稿和附件遵循页面和 Dock 之间的对话。仍在准备的文件将保持其进度，“删除”操作和“发送”将等待准备完成。

主页可以在您的消息中包含有限制的、引用的工作上下文参考。在发送之前，该引用遵循页面的代理、会话、标题和可见文件，而不仅仅是接收它的主页对话。您可以在发送前将其删除。

发送的消息在您的文字下方显示附加的 **Context**，而不是将生成的上下文显示为消息文本。打开它以检查捕获的会话、页面、代理、工作区、文件或选择； **技术细节**显示快照为JSON。当您发送时，快照将被冻结，包括通过队列和重试。复制或编辑您的消息不包括生成的参考。它仍然是参考数据，而不是访问其他对话的指令或许可。没有录制附件的较旧邮件将保持不变。

## <a id="plugin-conversation-docks"></a> 插件对话码头

插件页面可以提供一个操作来在页面旁边打开其对话。它使用与主页相同的聊天窗格、草稿、附件、右侧或底部放置、调整大小和关闭控件。打开它会取代“主页”、“询问 OpenClaw”或其他对话底座。它在页面导航中保持打开状态，并在与聊天或仪表板页面打开相同的对话时隐藏。关闭后，码头就不再开放。只读访问和会话错误遵循正常的聊天规则。插件可以包含有界页面引用，发送后显示为 **Context Attached**；它仍然是不可信的参考数据。

## <a id="operator-terminal"></a> 操作终端

操作员终端默认启用；设置 `gateway.terminal.enabled: false` 选择退出。终端需要 `operator.admin` 连接并在活动代理工作区中打开主机 PTY。新选项卡遵循当前选择的聊天代理。

当终端被禁用或您的连接缺乏管理员访问权限时，主终端页面会显示不可用通知和 **New session** 按钮以返回到 Composer。

在 Linux 和 macOS 上，Bun 上运行的网关使用 Bun 的本机 PTY，而没有 Node 运行时，仅在提供 `Bun.Terminal.pause()` 和 `resume()` 的构建上，例如OpenClaw Bun 分叉版本还包含 macOS 儿童退出修复。其他 Bun 版本对终端 I/O. 使用 Node 帮助程序保持 Node 在网关的 `PATH` 上可用； OpenClaw 会跳过 Bun 的 `node` 填充程序，并且不可用的 Node 可执行文件会在安装指导中产生启动错误。 Windows 保留 `node-pty`。请参阅 [Bun 兼容性 ](/install/bun-compatibility#known-limitations)。

启用更改热应用，无需重新启动网关。禁用会关闭附加的、分离的和会话拥有的终端，并取消挂起的打开。重新启用允许新的会话；关闭的会话不会返回。重新加载 Control UI 页面以获取更新的内容安全策略。

<Warning>
该终端是一个不受限制的主机 shell，并会继承 Gateway 进程环境。如果在不应让管理员操作员获得主机 shell 的部署中，请使用 `gateway.terminal.enabled: false` 将其禁用。对于 `sandbox.mode: "all"` 的 agent，OpenClaw 会拒绝终端会话；将某个活跃 agent 更改为该模式会关闭其现有的以及进行中的终端会话。
</Warning>

使用 **Ctrl + 反勾** 在所选聊天窗格的统一侧面板中切换 **Terminal** 选项卡。您还可以从面板的 **+** 菜单打开 **Terminal**。共享面板停靠在右侧或底部，随浏览器视口调整大小，可以在聊天窗格上展开，并保留多个 shell 选项卡。该坞站仍可用于临时操作员 shell。从 **启动本机 CLI 新会话** ，或在终端中打开 Claude Code 或 Codex 目录会话，打开 [ 主终端页面 ](/web/urls#terminal-urls) ，在替换 Composer 的同时保留侧边栏和应用程序镶边。请参阅 [ 网关配置 ](/gateway/configuration-reference#gateway) 以了解 `gateway.terminal.enabled` 和可选的 `gateway.terminal.shell` 覆盖。

选择终端文本会自动复制它。简短的 **Copied to Clipboard** 通知确认复制成功，无需占用键盘焦点。如果剪贴板访问失败，则不会出现成功通知。

终端会话在聊天侧面板标题中显示为选项卡；在面板的 **+** 菜单中再次选择 **Terminal** 将打开另一个 shell，而会话、上传和停靠到底部操作则位于标题中。移动到主区域的终端保留其自己的选项卡条。

统一面板还托管 **Browser**、**Files**、**Review**、**Side chat** 和能力相关**桌面**和**讨论**选项卡。其打开或最小化状态、活动选项卡、选项卡顺序、宽度、停靠和展开状态都存储在当前浏览器配置文件中的每个会话中，因此切换会话或重新加载会恢复每个会话自己的工作布局。没有保存面板布局的聊天对话不会继承在另一个会话中打开的面板。拖动选项卡以对其重新排序，关闭选项卡而不关闭其他工具，或使用面板关闭按钮最小化整个面板。

在从左到右和从右到左布局中，侧面板分隔线都遵循指针和箭头键的方向。

聊天和每个工具都有自己的辅助导航命名区域。使用工具交换聊天可以使每个选项卡与其自己的内容相关联，包括在多个拆分窗格中打开同一对话时。

连接的 **Desktop** 查看器在其选项卡隐藏时保持连接 30 秒，因此快速切换到聊天并返回可恢复相同的桌面和大小调整模式。隐藏时输入和远程调整大小会暂停。 30 秒后，查看器会断开连接并在重新打开时重新连接。关闭“桌面”选项卡、更改其会话或计算机或丢失网关连接会立即释放它。在鼠标或触摸拖动过程中隐藏桌面也会断开桌面连接，因此按下的远程按钮无法停留。 **Disconnect** 使其保持断开连接，直到您选择 **Reconnect**。桌面在解析其来源和连接时使用一个居中的加载指示器。

当您打开聊天时，面板会自动显示分配给该确切会话的可用桌面以及来自最新成功浏览器工具结果的浏览器选项卡（当该选项卡仍在运行时）。 Discovery 仅读取现有资源：它从不启动浏览器、配置桌面或附加不相关的全局或子会话资源。会话和清单事件，加上新的浏览器结果，在聊天可见时刷新发现。没有显式会话元数据的资源仍然可以通过手动面板控件使用。

自动显示重复使用现有面板并将已选择的工具保留在前面。自动发现的选项卡不会出现在已保存的布局中，包括在调整大小或停靠之后，因此重新加载会在打开资源之前再次验证资源。移动聊天以全角方式显示这些面板，就像手动打开的面板一样；其他窄窗格保留其底部停靠布局。最小化面板或关闭浏览器或桌面选项卡会禁用当前浏览器配置文件中该会话的进一步自动显示，包括重新加载后； **+**菜单仍然可以手动打开它们。

所有者授权的非沙盒代理可以使用 `terminal` 工具列出、读取、调整大小或关闭操作员已从同一聊天会话的终端面板打开的终端。代理无法打开 shell，并且访问仍处于精确会话范围内：代理无法检查或控制独立操作员终端或属于另一个会话的终端。终端输入遵循有效的会话和主机执行权限策略：**完全访问**（`full`或YOLO）立即发送； **Guarded** （`guarded`） 和 **Workspace**（`workspace`，包括仅接受或监护人审核的流程）需要对该确切输入进行明确的一次性批准； **只读** （`read-only`） 或`tools.exec.mode: "deny"` 完全禁止输入。批准一项输入绝不会授予对终端的不受限制的访问权限。

将一个或多个文件拖到活动终端上，或使用回形针按钮选择文件。 OpenClaw 在拥有 PTY 的计算机上暂存每个文件，并将 shell 引用的绝对路径粘贴到光标处；它从不按 Enter 或执行输入。紧凑的批次指示器显示当前文件和已完成的计数。取消将停止剩余批次而不粘贴路径；失败的传输保持可见，因此您可以从该文件重试，而无需重新上传已完成的文件。选择 **插入上传路径** 仅使用其已完成的文件来完成失败的批次，然后单独选择任何剩余文件。如果批处理在其早期上传可能已过期之前保持打开状态，请取消它并再次选择文件。

每个文件最多接受 16 个 MiB 的图像、PDF、档案和其他文件类型。新上传的文件必须符合 256 MiB 的共享限制以及每个暂存目录 64 个文件，包括来自其他终端选项卡和先前进程的文件。当达到任一限制时，移动或删除暂存文件，或等待清理，然后重试。现有的未过期文件不会被驱逐以腾出空间，包括升级后保留在这些限制之上的上传文件。暂存文件使用 POSIX 主机上的专用系统临时目录（目录模式 `0700`、文件模式 `0600`）或 Windows 上用户配置文件 ACL 边界下的目录，以及 24 小时清理计时器，因此可以移动或复制需要保留的任何内容。

重命名暂存文件或重试失败的清理不会重新启动已安排的清理截止时间。

如果分段在进程崩溃后保持锁定状态，请在拥有终端的计算机上找到错误中指定的相对锁定目录：本地终端的网关主机或节点终端的配对节点。在 Windows 上，在运行该网关或节点主机的帐户的主目录下解析它。在POSIX主机上，在该进程的系统临时目录下解析它；检查其服务环境，因为 `TMPDIR`、`TMP` 或 `TEMP` 可能与您的 shell 设置不同。然后停止使用该暂存根的所有网关和节点主机进程，仅删除指定的锁定目录，然后重新启动它们。这使得暂存文件完好无损。不完整的锁定记录永远不会自动清除，因为它无法证明另一个写入器已停止。

路径插入支持 PowerShell、`cmd.exe` 和已识别的 POSIX shell（`sh`、Bash、Dash、Ash、Ksh、Zsh 和 Fish），包括 Windows 上的 Git Bash。其他 shell 重写会被拒绝，因为它们的引用规则无法安全推断；在 WSL 内运行本机 WSL 终端和 Linux 上传路径的网关。包含 `%` 或 `!` 的 `cmd.exe` 路径也会被拒绝，因为该 shell 即使在双引号内也会扩展这些字符。

配对节点 Codex、Claude Code、OpenCode 和 Pi 终端还支持上传路径插入，包括带空格和撇号的 Windows 路径。插入的输入仍然可编辑，并且永远不会自动提交。

会话侧栏中发现的 Claude Code 和 Codex 会话在主终端页面中打开其本机 CLI。在 **设置 › 聊天** 中，设置 **在** 中打开 Codex/Claude 线程到 **终端** 以使正常行单击打开 `codex resume` 或`claude --resume`；默认值仍然是只读 OpenClaw 查看器。行的右键单击或 kebab 菜单始终提供这两种选择，并且当该会话符合条件时，查看器标题包括 **在终端中打开**。

升级后，旧版本已排队的目录打开请求在坞站中完成一次。新请求使用主终端页面；该页面不保留目录打开意图。

资格判定按会话和主机分别进行。Gateway 本地会话会在 Gateway 主机上启动由提供方拥有的 resume 命令。成对节点会话会在所属节点上启动允许列表中的提供方命令，并且只转发该 PTY 的输出、输入和调整大小事件；这不会暴露通用节点 shell，也不会接受浏览器提供的命令。文件上传使用单独的、大小受限的 `terminal.upload` 节点命令，并且仍绑定到已打开的终端会话。请在该命令首次出现时批准节点配对升级。不提供匹配的 terminal-resume 命令的节点，包括没有双向流式传输的嵌入式 worker bridge，会继续保留查看器并将打开终端显示为不可用；较旧的节点仍然可以运行终端，但不能接收拖拽文件。

独立的操作员会话（包括主终端页面和终端焦点演示）是连接拥有的。离开主航站楼航线不关闭其PTY；返回到其终端会话 URL 重新连接它。主页和扩展坞保留单独的终端选项卡。页面重新加载、笔记本电脑睡眠或网络信号会在网关上分离而不是杀死它，并且同一浏览器选项卡在重新连接时重新连接并重播最近的输出。分离的连接拥有的会话在 `gateway.terminal.detachedSessionTimeoutSeconds` 后被终止（默认 300 秒；`0` 恢复断开连接时终止）。附加这些会话之一仍然是 tmux 风格的接管。

以代码 0 正常退出的 shell 会自动关闭其终端选项卡，包括在 `logout`、`exit` 或 EOF 之后。关闭最后一个终端选项卡将关闭其面板，无论是停靠在右侧还是底部，除非还有其他工具选项卡。非零退出、信号、断开连接和错误保持可见以供检查。在最后一个选项卡关闭后，全屏终端将保持其新会话控件可用。

关闭连接选项卡会取消该打开或附件请求。其他选项卡和排队的请求仍然可用，并且延迟响应不会重新打开已取消的选项卡或显示其错误。

从聊天会话的终端面板打开的会话拥有的会话不绑定到浏览器连接。 `terminal.attach` 将每个浏览器添加为查看器，而不获取所有权，并且关闭已建立的查看器选项卡只会分离该浏览器。会话拥有的 PTY 会一直保留，直到确切的会话代理关闭它们、它们的 shell 退出、会话被存档、策略禁用它们或网关关闭。 `terminal.list` 将每个条目标记为连接或代理拥有。

重置隐身会话会关闭其对话拥有的终端，并在删除会话之前取消待打开的终端。

所有网关终端 PTY 都是进程本地的。网关重启结束它们；新进程启动后，PTY 会话及其回滚不会恢复。

`/terminal` 的主终端页面也可作为 [ 焦点演示 ](/web/urls#focus-presentation-routes) 提供。 iOS 和 Android 应用程序将此页面嵌入其终端屏幕中，重用存储的网关凭据；可用性遵循相同的 `gateway.terminal.enabled` 和 `operator.admin` 门，当连接的网关不提供终端时，页面会显示通知。焦点演示移除了应用程序镶边；它不会调用浏览器全屏。

### <a id="terminal-fonts"></a> 终端字体

该终端将 **JetBrains Mono** 与 **Symbols Nerd Font Mono** 捆绑在一起，用于电力线分隔符和标准 Nerd Font 图标。默认不需要安装字体或第三方字体服务。

在 **设置 → 外观 → 版式 → 终端字体** 中，输入本地等宽字体系列名称，例如 `FiraCode Nerd Font Mono` 或选择 **使用默认值**。清除该字段以将其重置。该字体必须安装在运行浏览器的计算机上，而不是远程网关或 shell 主机上。该网关的设置保留在该浏览器中；缺少的字体会回退到捆绑的默认字体。更改适用于打开的终端，无需重新启动 shell，包括全页和聚焦的终端视图。

终端渲染器当前不支持编程连字（例如 `=>` 的连接箭头），即使使用支持连字的字体也是如此。

## <a id="browser-panel"></a> 浏览器面板

要求您的代理“打开浏览器侧边栏”或“显示浏览器侧面板”以显示此面板。当 `screen` 工具可用时，代理使用 `browser_show`（`browser_hide` 来隐藏它）。 `sidebar_show` 和 `sidebar_hide` 控制会话列表。打开浏览器面板不会创建或展开 [ 浏览器仪表板](/web/dashboards#share-a-browser-dashboard-with-your-agent)。

Control UI 在统一聊天侧面板中附带了一个 **Browser** 选项卡，该选项卡在任何常规 Web 浏览器中呈现网关控制的浏览器（与 [ 浏览器工具 ](/tools/browser-control) 驱动的同一代理） - 无需本机 Web 视图。当连接的网关向 `operator.admin` 连接通告 `browser.request` 时，它会出现在面板的 **+** 菜单中； **Files** 中的地球操作可切换它。在常规 Web 浏览器中，在其面板选项卡已打开时再次选择 **Browser** 会创建另一个代理浏览器选项卡。该面板显示实时截屏视频，在流不可用时提供屏幕截图回退，以及选项卡、可编辑的 URL 栏、back/forward/reload 和在浏览器中打开，并将点击、滚轮滚动和基本打字转发到远程页面。远程页面遵循共享面板：打开它、调整其大小或切换选项卡将远程浏览器视口的大小调整为面板的可用空间，因此快照会填充面板，而不是按照代理上次使用的任何大小进行渲染。

滚轮滚动针对指针下方的可滚动容器，包括从左到右或从右到左布局的反向聊天列表和水平列表。

当面板或浏览器仪表板可见时，稍后的远程调整大小也会将页面重新同步到可用空间。隐藏面板使远程视口保持独立。无法满足请求大小的浏览器不会重复调整大小，而其报告的尺寸保持不变。

浏览器选项卡直接显示在聊天侧面板标题中，下面是 URL 工具栏。当启用自动图标提取并且图标可用时，每个选项卡都会显示其页面图标。关闭最后一个浏览器选项卡会使浏览器面板保持打开状态，因此您可以使用 **+** 创建另一个选项卡。当浏览器移至主区域时，其选项卡将显示在其自己的工具栏上方。

当网关浏览器停止时，选择**启动浏览器**。当启动等待时，面板会显示加载指示器。如果启动失败，它会显示错误并恢复**启动浏览器**，以便您可以重试。

当代理浏览器预览刷新时，当前页面保持可见，并且重新加载图标在工具栏中旋转。仅在第一页图像可用之前才会出现加载骨架。如果刷新失败，面板将保留上一个图像并在其上方显示错误。

要粘贴到代理浏览器选项卡或浏览器仪表板中，请单击页面的输入字段，然后按 macOS 上的 **⌘V** 或 **Ctrl+V** 上的 Windows/Linux，或者右键单击该字段并选择**粘贴**。纯文本插入到远程光标处，包括密码字段和框架内的字段。粘贴不会提交表单或将剪贴板复制到网关的系统剪贴板。这需要一个受管理的浏览器； Chrome MCP 现有会话配置文件不支持它。

在 macOS 应用程序中，同一面板还托管由 WebKit 本地渲染的 **Mac 选项卡**，以及来自网关的 **Agent 浏览器选项卡**。 Mac 选项卡无需 `browser.request` 即可使用；代理浏览器选项卡保留上述网关和操作员访问要求。在仪表板中单击的外部链接将作为聊天侧面板中的 Mac 选项卡打开，或者在非聊天路由上的 shell 级浏览器停靠栏中打开。当“设置”打开时，外部链接会在默认浏览器中打开，因为“浏览器”面板被隐藏。 Mac 选项卡具有选项卡条、URL 栏、back/forward/reload/stop、在默认浏览器中打开和关闭控件。 Mac 选项卡显示页面自己的图标。 Mac 选项卡属于打开它们的聊天会话：另一个会话以其自己的空浏览器面板启动，返回将恢复原始会话的选项卡。窗口会保留这些选项卡，直到它们关闭或窗口结束。打开同一链接仅在该会话中重用其现有选项卡，包括重定向后保留的原始 URL。非聊天浏览器底座有自己的选项卡。登录 cookie 在窗口内保持共享。在打开链接时选择另一个选项卡会在打开请求完成时保留您的选择。

会话本地 Mac 选项卡需要 Mac 应用程序和网关服务的 Control UI 来支持会话所有权。在交错升级期间，较旧的 app/UI 组合将保留其现有的共享选项卡行为，以便继续进行浏览。在没有会话所有权的情况下创建的选项卡将保持窗口共享，直到关闭或窗口结束；一旦双方都更新，新选项卡就会成为会话本地的。

在 macOS 应用程序之外，在 **设置 → 基础设施 → 浏览器** 下启用 Control UI 浏览器 **中的**Open 链接，以将外部 HTTP（S） 链接路由到此面板中的新代理浏览器选项卡中。默认情况下，浏览器本地首选项处于关闭状态，并且仅在面板可用时出现。它隐藏在 macOS 应用程序中，因为未经修改的外部仪表板链接会在“设置”之外作为 Mac 选项卡打开。发送旧版 `inline` 请求的旧版 Control UI 捆绑包会打开默认浏览器。同源链接、标记为下载的链接、Shift/Alt 单击、file/editor 链接、电子邮件和电话链接、右键单击操作以及显式在浏览器中打开操作将保留其现有行为。

在macOS应用程序中，修改点击打开默认浏览器；右键单击 **在浏览器面板中打开**、**在默认浏览器中打开** 或 **的外部仪表板链接复制链接**。 Mac 选项卡内的新窗口链接会在打开者会话中打开另一个 Mac 选项卡，而指针激活的下载则移交给默认浏览器。不可显示的响应仅针对指针激活的主机导航进行切换；其他不可显示的响应将被默默取消。

每个代理浏览器选项卡在就地导航和目标替换中都保持一个稳定的身份，因此即使网关以不同的顺序返回选项卡，其选定状态、键盘焦点、URL、页面快照和浏览器操作也保持一致。

要保存在面板中打开的资源，请单击铅笔和指针图标旁边的 **下载文件**。下载时图标会变成旋转图标，预览保持打开状态，工具栏下方不会显示进度或成功消息。 Mac 选项卡显示“保存”对话框并使用选项卡的登录浏览器会话。代理选项卡使用其浏览器配置文件的会话来保存显示的资产，然后通过网关的经过身份验证的媒体路由传送文件；仪表板不获取外部资产 URL。代理下载遵循浏览器配置文件的下载支持和网络策略。远程浏览器节点传输保留现有的每个文件 10 MiB 限制。如果下载失败，面板会显示错误，并提供使用 **在浏览器中打开** 的选项。无法下载空白和加载选项卡。

Chromium 不会公开本机下载重定向以进行策略检查。因此，具有默认网络策略、专用网络限制或主机名 allow/block 限制的代理配置文件会在开始任何下载流量之前拒绝此工具栏操作。使用 **在浏览器中打开** 来保存这些资源。此限制不会影响 Mac 选项卡及其本机“保存”对话框。

两种捕获模式为代理程序封装页面上下文。对于 Mac 选项卡，任一模式都会捕获实时 WebKit 页面的一次性快照。将捕获的选项卡导航到不同的 URL 将退出捕获模式并恢复其实时视图：

- **标注（铅笔）**：在页面上手绘标记。**发送到聊天**会将笔画合成到屏幕截图中，并将一张结构化标注卡片添加到当前聊天编辑器中。该卡片会将生成的页面和区域上下文与图像保存在一起，而不是将其插入到可编辑的草稿中。
- **检查（指针）**：悬停以查看光标下的元素（选择器、可访问名称、角色、大小）；单击以通过同一卡片流程添加这些详细信息和突出显示的屏幕截图。删除注释卡只会删除该图像及其生成的上下文，保留您的草稿和其他附件，并提供短暂的保存**撤消**。对于代理浏览器选项卡、检查、滚轮滚动和back/forward需要`browser.evaluateEnabled`（默认情况下打开）。

一个编辑器最多接受四张浏览器标注卡片，以及总计 8,000 个字符的生成标注上下文。达到任一限制后，浏览器面板会保留当前捕获内容，以便你移除卡片后重试；撤销也会保留该限制，而不会驱逐另一张卡片。

暂存图像、文件、粘贴图像、大粘贴文本、浏览器注释和混合附件包在路径更改、分割窗格重新安装、硬重新加载和应用程序重新启动时与其编写器和会话保持一致。 [新会话页面](/web/control-ui/sessions-and-sidebar#new-session-page)中描述的浏览器本地保留、范围和处置规则也适用于现有会话编辑器。如果附件超出耐用上限，当前选项卡将保留它们并显示存储警告；文本仍然可以重新启动恢复，但这些附件则不能。如果浏览器完全拒绝存储，当前选项卡将保留实时作曲家并显示相同的警告，但该草稿在重新启动后无法恢复。

## <a id="github-side-panel"></a> GitHub 侧板

捆绑的 [GitHub 插件 ](/plugins/github) 贡献了该阅读器及其悬停预览。默认情况下它是启用的。禁用该插件会删除这些贡献，并将 GitHub 链接保留为普通外部链接。其他插件可以通过 [Plugin SDK](/plugins/sdk-overview) 贡献相同的对接读取器表面。

单击 GitHub 问题、拉取请求或提交链接，以在对话旁边的浏览器样式选项卡中阅读它。每个选项卡都有一个 GitHub 图标、标题和关闭控件；地址栏和 GitHub**链接上的**Open 保持可见。从聊天中打开同一项目会选择其现有选项卡。阅读器内的链接和地址栏中输入的 URL 可导航当前选项卡，并具有独立的后退和前进历史记录。 **+** 按钮打开一个新选项卡。内存中最多保留十个选项卡，包括在它们之间切换时加载的文档。

打开或加载项目可使键盘焦点保持在您正在键入的位置。 **+** 按钮使地址栏聚焦，以便您可以输入新的 URL。

阅读器显示描述、问题和拉取请求讨论评论、提交评论、发布的内联 PR 审阅评论（带有 file/line 和差异上下文）以及可扩展文件差异。评论时间戳链接到 GitHub 上的来源。 Markdown 图像和独立 HTML 图像附件内嵌显示；当图像无法加载时，全尺寸链接仍然可用。内联图像请求使用阅读器插件的匿名图像解析器（如果可用）；因此，GitHub 附件无需浏览器 CORS 标头即可工作。没有图像解析器的读者使用匿名 CORS 并省略跨域凭据和引荐来源网址。脚本和嵌入式应用程序小部件永远不会在这些文档中运行。

可调整大小的面板是只读的，并且支持公共存储库。长时间的讨论和大的补丁是有限的，并被标记为不完整。刷新再次获取当前项目。在手机上，读者遵循共享面板的响应式布局和扩展控件。在 GitHub**上使用**Open 进行完整页面、私有存储库或诸如发布评论和合并之类的操作。 Cmd/Ctrl-click 和文档链接上的中键单击保留正常的浏览器行为；中键单击选项卡可将其关闭。不通告详细功能的连接会保持正常打开链接。

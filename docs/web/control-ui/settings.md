设置下的所有内容，以及侧边栏链接到的设置所属页面。

浏览器设置升级支持 2026 年 7 月 1 日或之后发布的版本编写的形状。旧的顶级会话选择将被忽略；在侧栏中再次选择一个会话。保存的对话保留在网关上。

**返回应用程序** 返回您在打开“设置”之前使用的工作区页面，包括其选定的会话和 URL 过滤器。当编辑器或对话框不使用该键时，Escape 会执行相同的操作。在“设置”页面之间移动不会更改返回目标。

在**搜索设置**中，Escape会在离开设置之前清除搜索。当输入法正在撰写文本时，Escape 会保留该输入法，而不是清除搜索或导航离开。

使用**搜索设置**查找页面和配置字段。搜索 **Typography**、**font** 或 **Chat prose** 以跳转到外观中的界面和聊天散文字体控件。创作的架构标签仍然可以使用 `tag:<name>` 进行搜索，但不会显示为字段徽章。标签不是根据设置名称、敏感性或复杂性推断的。对于使用 `storage` 标签创作的字段，请将其与 `Log tag:storage File` 等文本组合。多个标签需要一个字段来匹配每个标签。

具有超过八个选项的模型菜单包括搜索。按模型名称或 provider/model 参考进行筛选，然后选择一个结果进行应用。键入或关闭菜单将使当前选择保持不变。简短的菜单保持紧凑，并且在设置支持的情况下自定义模型条目仍然可用。

当网关拒绝无效设置时，**未应用设置**保留您的草稿并提供**显示原因**、**重试**和**放弃草稿和重新加载**。放弃将删除所有未保存的配置编辑并重新加载已保存的设置。清除文本字段是一种编辑，而不是丢弃：接受空字符串的设置会保留该显式值。

全局模型默认值适用于每个代理。保存时切换设置代理不会更改保存目标。如果保存失败，**Retry** 重新提交该更改；恢复后，控件将遵循保存的配置，包括来自另一个客户端的后续更新。

配置编辑（包括在保存待处理时恢复值）不会影响刷新和重新连接。如果保存结果未知，UI 会保留您的草稿并暂停不相关的设置写入，直到刷新确认保存的修订或您明确重试保存或放弃草稿。即使恢复的草稿看起来没有变化，保存指示器也会使 **Retry** 保持可用，并防止托管 UI 重新加载丢失未解决的草稿。 **Retry** 重复失败的保存或应用操作。重新连接后查看旧的保存值并不能确认先前的写入已停止； UI 使不确定性保持可见，因此以后的提交无法删除您的恢复。其他作者的更改保留原始草稿并报告冲突，而不是默默地替换您的编辑。原始编辑器草稿仍然只能手动保存。

未解决的“保存”或“应用”仍与其原始网关绑定。切换网关不会传输待处理的更改：重新连接到原始网关以重试，或在编辑新网关之前放弃保留的草稿。

在 **Models** 中，**Connect 提供程序** 提供由已安装的提供程序插件声明的仅凭据登录方法。连接会保存凭据，而无需选择其启动模型。如果模型限制隐藏了提供商，请选择 **显示所有提供商模型** 或 **保留当前限制**；仅保存凭证并不能扩大访问范围。选择 **Models → 连接提供商 → 在此网关** 上查找现有连接或打开 [ 设置和显式模型激活](/start/onboarding)。保存凭证不会激活模型；对于所选代理来说，测试和使用模型仍然是一个单独的选择。如果保存已开始，取消操作会使对话框保持打开状态，直到保存的结果到达。离开页面会关闭待处理的登录输入并让活动保存完成，以便稍后可以开始登录而不会丢失保存的凭据。

模型选择器显示所选代理可用的身份验证方法。单个订阅或明确选择的帐户包含其电子邮件（如果可用）；显示多个帐户和混合 API/subscription 凭据，无需猜测哪个帐户将运行。 **Utility Model → Auto** 还显示了从全局主模型派生的推荐小模型，包括从该模型继承的显式帐户选择。没有推荐小模型的提供商是这么说的。当代理运行时，特定于代理的覆盖仍然优先。

打开面板共享提供商登录状态。配置编辑会保持该状态，直到网关发布更新的身份验证信息；凭证更改、重新连接和到期期限仍然会刷新它。

在首次运行 **Model Setup** 期间，重新加载浏览器会在同一正在运行的网关上恢复未完成的提供程序向导，而无需重复您的答案。从当前问题继续，或选择 **Cancel** 以在网关确认取消后释放提供商选择。未提交的输入不会被保存。如果网关重新启动或不再有向导，则 **再次检查** 刷新当前设置，而无需启动另一次提供程序尝试；恢复守卫会一直保留，直到可以验证模型或待处理的尝试到期。

## <a id="environment-identity"></a> 环境标识

当您运行多个网关时，设置 `gateway.controlUi.environment` 以区分它们的浏览器选项卡和窗口：

```json5
{
  gateway: {
    controlUi: {
      environment: { label: "edge", color: "amber" },
    },
  },
}
```

该环境添加了 2 px 顶部条纹、代理头像环、侧边栏和窄顶栏中的标签药丸、浏览器标题后缀以及匹配的图标。标签经过修剪，必须包含 1-24 个字符。可用颜色有 `teal`、`amber`、`purple`、`coral`、`pink`、`blue`、`green`、`red` 和 `gray`。标签和颜色在登录前故意可见；保留 `environment` 未设置以保持标准外观不变。

## <a id="browser-tab-icon"></a> 浏览器选项卡图标

在 **设置 → 外观 → 浏览器选项卡图标** 中，选择 **Default**、**代理头像**，或者**Lobsterdex**。默认保留主题和网关环境图标。代理头像跟随明确选择的代理，在不裁剪的情况下调整其图像，并在不可用时恢复为默认值。 Lobsterdex 可让您从该浏览器中已解锁的龙虾中选择固定的龙虾。活动和注意力点在每种模式下都保持可见。

Lobsterdex 解锁保持浏览器本地；此设置不会同步您的收藏。在您选择的龙虾未解锁的另一个浏览器上，OpenClaw 会保留选择，但显示“默认”，直到该龙虾解锁或您选择其他来源。没有自定义上传、每个选项卡选择或特定于代理的覆盖。

此设置仅更改您的选项卡图标。要自定义代理的映像，请使用 **Agent 设置 → 概述 → Identity**；编辑该图像会更改共享代理身份，而不仅仅是您的网站图标。

该选择将保存到已连接网关上的经过身份验证的配置文件中，并具有浏览器本地镜像。如果没有可写的配置文件，它会保留在浏览器本地。此设置不会更改其他人的选项卡图标。

## <a id="community-invitation"></a> 社区邀请

侧边栏的紧凑型 **Community** 条目可按需打开 Discord、Reddit 和 X 链接。在手机上，链接显示在底部工作表中；较大的屏幕使用居中对话框。该工作表不会自动打开，关闭它会将焦点返回到 **Community**，而不隐藏该条目。链接在新选项卡中打开。

这取代了促销邀请卡。现有的浏览器本地卡消除保持不变；它们不会隐藏紧凑的条目。要为使用 Control UI 部署的每个人隐藏社区，请在为 UI 提供服务的网关上运行以下命令：

```bash
openclaw config set gateway.controlUi.communityInvite false
```

网关应用更改后，重新加载浏览器页面或重新连接以获取它。该设置属于为 UI 提供服务的网关，包括当 UI 连接到不同的远程网关时。使用 `true` 重新启用它可以恢复紧凑条目。

## <a id="personal-identity"></a> 个人身份

经过身份验证的人员拥有持久的网关配置文件，其中包含显示名称、头像、链接电子邮件和可选的经过验证的 GitHub 身份。打开 **设置 → 配置文件 → Identity** 以更新可编辑字段。该个人资料会跨浏览器跟踪经过身份验证的人员；清除浏览器站点数据并不会删除它。

个人资料照片通过在线名册、人员卡片和聊天中经过身份验证的网关路由加载。配对的浏览器使用其批准的读取范围。当 Mac 应用程序通过 SSH 隧道连接到可信代理网关时，如果其配对凭据被拒绝，图像请求可以使用连接的已保存密码。凭证保留在请求标头中；没有可用图像的个人资料显示姓名缩写。

在单用户网关上，身份不明的运营商跨设备共享一份持久的所有者配置文件，包括设备令牌重新连接。其未设置的显示名称源自网关主机帐户的全名，而不是其登录名；保存的名称永远不会被覆盖。如果没有全名，侧边栏将显示 **Owner**。配置 `gateway.roles` 后，仅 token/password 连接接收此所有者配置文件；其他未识别的连接会在“身份”中看到解释，而不是编辑控件。所有者配置文件没有电子邮件并且不授予任何其他权限。

在macOS上，当没有保存OpenClaw头像时，所有者头像默认为网关主机帐户的用户图片。这使用运行网关的 Mac，包括当您从其他设备连接时。已保存的头像始终优先。 OpenClaw 在本地读取图片并通过认证的头像路由提供调整大小的副本；其他人的个人资料永远不会继承它。重新启动网关以获取更改后的 macOS 图片。如果无法读取图片，缩写字母仍然可见。

**设置→个人资料→连接帐户**显示选定的**Gateway**，保存的**Person**和**范围：Personal**。选择 **添加帐户**，然后从网关目录中选择提供商和登录方法。 Browser/device 登录、受保护的凭据输入、进度和取消使用一个引导流程。这些是 `openclaw models accounts login` 管理的相同个人帐户，而不是 `models auth` 管理的计算机本地 system/agent 凭证。帐户控制遵循网关分配的配置文件，包括单用户网关上的共享所有者配置文件。如果连接没有配置文件，该部分将解释缺少的身份并提供 **连接设置**，而不显示提供程序凭据输入。共享网关令牌和设备配对本身并不能区分多用户网关上的人员。请参阅 [ 每人模型帐户](/concepts/multi-user#per-person-model-accounts)。

通过 Cloudflare Access 或 Tailscale Serve 支持的 GitHub- 登录会使用经过验证的公共头像和帐户链接填充只读 **GitHub 帐户** 行，而无需替换自定义 OpenClaw 头像。 **Git 合著者credit** 是一个单独的开关，默认情况下对于经过验证的帐户处于打开状态，用于控制共享会话的未来提交。请参阅 [ 用户模型 ](/concepts/user-model#gateway-profile-and-github-credit) 以了解验证、重试、帐户更改、不回复隐私和资格规则。

**设置→配置文件→GitHub连接**分别显示**我的GitHub**和**系统GitHub**。已识别人员（包括读取范围的操作员）只能连接和断开自己的帐户；管理员还可以更改共享系统帐户。对于已识别的用户，默认连接到 **For me**，并且永远不会更改其登录身份、共同作者首选项或共享执行默认值。个人凭据支持显式网关代理的 **Publish PR** 操作，而不是普通的代理 shell 命令。请参阅 [GitHub 连接](/concepts/user-model#github-connections)。

管理员还可以在此处查看默认代理的有效 GitHub 帐户和验证状态。 **查看代理账户**打开**代理设置→工具→GitHub账户**，其中任何代理的账户来源、凭证类型、OAuth到期和刷新状态都可用。经过身份验证的 [GitHub Actions widgets](/tools/show-widget#read-github-actions-runs) 使用此有效代理帐户。 **Verified** 与 GitHub 确认账户；对每个数据请求检查存储库权限。

为 Control UI 链接预览保留的凭证不包括在代理身份验证及其显示状态中，包括当预览凭证使用 SecretRef 时。

在 **代理设置 → 概述 → Identity** 下设置代理的显示名称、表情符号和头像。该身份由该代理存储并由 Control UI 客户端共享。如果文字记录显示头像，则保存和流式传输助理回复将使用配置的代理图像或文本头像。没有配置头像的代理会忽略重复的后备图标。

2026 年 7 月之前的浏览器范围头像覆盖不再迁移；而是为每个代理设置头像。

在 **Agent 设置 → 文件** 中，未读文件在其内容加载之前一直无法编辑和预览。如果初始读取失败，请选择 **Refresh** 重试。已加载的文件和保留的草稿在刷新期间保持可编辑；当前文件内容加载后，**Reset** 变得可用。当您切换文件选项卡或选择另一个代理并返回时，未保存的编辑将保留在其代理中。返回从磁盘读取当前文件，同时保留您的编辑；如果文件在其他地方发生更改，则保存会保留现有的冲突恢复选择。这些草稿仅存在于打开的代理设置页面中：在离开页面、重新加载浏览器或更改网关连接之前保存。普通的重新连接可以保留它们。

在其他地方，没有自定义图像或表情符号的代理使用生成的面孔来填充圆形头像。它的颜色、眼睛、嘴巴和纯色或柔和的背景来自代理 ID，因此同一代理在重新加载和客户端时保持相同的面孔。重命名代理的显示名称不会改变其外观。生成的面孔是装饰性的，并不表示活动或模型选择。

## <a id="gateway-host-status"></a> 网关主机状态

连接设置使用一个 **Gateway Secret** 字段作为配置的令牌或密码。网关接受任一有线字段；其身份验证模式选择配置的秘密。成功的令牌模式连接后，UI 仅记住当前浏览器选项卡和网关的会话存储中的秘密。密码保留在内存中并且永远不会保留。

当连接正常且未更改时，**Settings → Gateway** 显示 **Connected**，而没有连接操作。编辑 URL 或秘密会显示 **应用并重新连接** 和 **放弃更改**。当连接尝试运行时，未更改的设置会显示禁用的 **Connecting…** 或 **Reconnecting…** 操作。编辑 URL 或机密可启用 **Apply 和重新连接**，因此您可以替换卡住重试的连接。断开的连接提供 **Connect** 或 **重试连接**。打开 **连接详细信息** 以获取身份验证和心跳信息，或使用其 **Reconnect** 操作对当前连接进行故障排除。

单独的 **Session** 部分在此浏览器中保存当前网关的 **Default session**，而无需重新连接。会话编辑和连接编辑具有独立的 Save/Apply 和丢弃操作。切换网关会恢复该网关保存的会话选择。

打开 **Settings → Gateway** 可查看 **Gateway Host** 卡以及网关机器、LAN 地址、操作系统、运行时、正常运行时间、CPU 负载、内存以及每个安装的本地磁盘的空间。省略了安装在 `/boot/efi` 或 `/efi` 上的 Linux EFI 引导分区。该卡在可见时与活动图共享十秒 `system.info` 刷新；已安装磁盘发现和状态目录磁盘空间重用三十秒快照。机器名称、CPU 计数、CPU 模型在 Gateway 进程启动时采样一次；重新启动网关以反映 CPU 拓扑更改。进程计数器、平均负载和事件循环运行状况在每个请求上都保持实时状态。 Linux 磁盘采样直接读取文件系统统计信息，不需要 `df` 实用程序。 RPC 需要 `operator.read` 示波器。如果已安装磁盘发现不可用，则该卡会保留状态目录磁盘读取（如果可用）。没有所需范围的连接会忽略该卡。在获取第一个统计数据时会出现微光占位符，并在启用减少运动的情况下保持静止；刷新使之前的读数和正常运行时间保持可见。磁盘路径显示在其标签中，没有重复的工具提示。

**Connection** 卡还显示平均 ping 以及 p50、p95 和 p99 往返时间（以毫秒为单位）。当页面可见时，它每十秒采样一次，并总结当前连接的最后 100 个成功样本。样本计数使小集合可见；随着样本的积累，p95 和 p99 变得更加有用。重新连接、切换网关或离开页面都会重置读数。失败的请求将被排除并显示为重试通知。

ping 图表显示各个往返行程。 **Gateway Activity** 使用相同的 CPU、进程内存和事件循环延迟图作为调试覆盖，在可见时每十秒采样最多 100 个快照。 CPU 包括事件循环利用率，内存显示进程 RSS 和已使用的堆，延迟显示网关的事件循环 p99 和最大延迟。这些是网关过程测量，与连接 ping 和下面的机器范围 **Gateway Host** 读数分开。网关、外观、设备、系统和系统繁忙度共享同一连接的状态读取，因此打开设置旁边的托盘不会增加 `system.info` 流量。隐藏选项卡会暂停这些读取，并在可见时恢复。缓存的样本保留其原始时间戳和测量的往返时间。活动轮询通过 `system.info` 读取进程计数器，而不运行操作员 `status` 报告使用的完整任务和会话检查。

Ping 通过现有的 WebSocket 测量轻量级 `last-heartbeat` 请求，包括网关请求处理。它不是 ICMP ping 或模型响应时间。

## <a id="language-support"></a> 语言支持

Control UI 在首次加载时根据您的浏览器区域设置进行本地化。要稍后覆盖它，请打开 **设置 → 外观 → 语言**。

- 支持的区域设置：`en`、`ar`、`de`、`es`、`fa`、`fr`、`hi`、`id`、 `it`、`ja-JP`、`ko`、`nl`、`pl`、`pt-BR`、`ru`、`sv`、`th`、 `tr`、`uk`、`vi`、`zh-CN`、`zh-TW`
- 非英语翻译会在浏览器中按需加载。
- 所选区域设置会保存在浏览器存储中，并在以后访问时复用。
- 缺失的翻译键会回退为英语。

一旦第一次翻译刷新完成，就会为相同的非英语区域设置生成文档翻译，包括瑞典语 （`sv`）。自定义文档网站支持这些区域设置，包括泰语 （`th`） 和波斯语 （`fa`）。

## <a id="appearance-themes"></a> 外观主题

要求代理列出主题，按名称或描述选择一个主题，或者设计并应用新主题。 `theme` 工具使用与外观相同的目录和配置文件选择。插件主题和代理创建的个人主题与内置主题及其名称和描述一起显示。个人资料主题更改可实时到达连接的浏览器；插件主题添加、更新和删除在插件热重新加载后生效，无需重新启动网关或重新加载浏览器。如果选定的插件主题不可用，Claw 会暂时渲染，并在主题再次可用时返回选择。外观中的加载错误提供 **Retry** 来刷新目录和调色板。

个人主题定义将保存到您经过身份验证的网关配置文件中。现有的浏览器本地tweakcn 导入仍保留在本地，并且永远不会自动上传。代理报告选择已保存；离线的浏览器在下次连接时应用它。重新连接会保留您待定的本地选择，同时刷新您的个人资料中的其他外观首选项。即使首选项为“系统”，仅提供一种颜色模式的主题也会使用该模式。明确的重音和字体覆盖继续优先于主题。

外观面板具有内置的 Claw、Knot、Dash、Absolutely、Tide、Beacon、Phosphor、CRT、Manuscript、Rosé 和 Miami 主题（Claw 为默认主题），以及由启用的插件贡献的主题、通过代理保存的个人主题以及一个浏览器本地调整cn 导入插槽。每个主题都有自己的自托管字体，仅在选择或预览时加载：Claw 使用 Instrument Sans，Knot 使用 Geist，Dash 将 DM Sans 与 Fraunces 配对用于聊天散文，Absolutely 将 Space Grotesk 与 Lora 配对用于聊天散文，Tide 使用 IBM Plex Sans，Rosé 使用 DM Sans，Miami 使用 Space格罗泰斯克。 Beacon 的目标是 WCAG AAA （7：1） 与 Atkinson Hyperlegible Next 字体的对比度，适用于低视力、明亮的阳光、投影仪和低质量面板。 Phosphor 和 CRT 将整个表面（包括聊天散文）设置在 JetBrains Mono 中 — Phosphor 为绿色玻璃，CRT 为带有方角的黑底白字控制台。 Manuscript 是一个以光为先的主题：羊皮纸和带有青金石口音的铁胆墨水，完全采用 Lora 衬线，采用烛光黑暗模式。要导入主题，请打开[tweakcn编辑器](https://tweakcn.com/editor/theme)，选择或创建主题，单击**Share**，然后将复制的链接粘贴到外观中。导入器还接受 `https://tweakcn.com/r/themes/<id>` 注册表 URL、编辑器 URL（如 `https://tweakcn.com/editor/theme?theme=amethyst-haze`）、相对 `/themes/<id>` 路径、原始主题 ID 和默认主题名称（如 `amethyst-haze`）。

主题样式表可以设置 `--chat-composer-corner-shape`（默认 `superellipse(1.5)`），以便在绘制 `corner-shape` 的浏览器中为聊天编辑器提供不同的角族，例如 `scoop scoop round round`；其他浏览器保留圆角。

主题可以选择中性提示标记而不是龙虾吉祥物，并提供自己的长期等待状态词汇。他们还可以在作曲家壁架上偶尔添加企鹅或软呢帽访客，并在 `fedora`、`crown`、`santa`、`party` 和 `pumpkin` 目录中的特工头像上添加偶尔的帽子。没有吉祥物的主题隐藏了常驻龙虾和来访的龙虾陌生人，而普通的壁架流量在不变的 **Lobster 访问** 切换下继续。主题还可以隐藏 **Lobsterdex**，包括其访问和声音控件以及收集的龙虾选项卡图标。这会保留您的收藏、保存的选项卡图标和访问首选项；切换回显示 Lobsterdex 的主题即可恢复它们。单独隐藏 Lobsterdex 不会改变吉祥物或小动物的行为。有关可移植设置和限制，请参阅 [ 主题定义字段](/tools/theme#create-and-apply-a-personal-theme)。

插件主题还可以通过 [ 声明的艺术品 ](/plugins/manifest/surfaces#themes) 带来自己的 SVG 帽子和作曲家访客。

每个内置主题都包括应用程序画布上匹配的浅色和深色背景艺术品。小型、捆绑的无损 WebP 图像遵循所选模式，包括 System.插件主题可以[声明自己的浅色和深色背景](/plugins/manifest/surfaces#themes)，这些背景像自定义图像一样变暗；个人和导入的调色板，以及当前模式下没有的插件主题，请使用中性艺术品。现有用户保留此主题艺术品，直到他们更改背景偏好。

在**外观→背景**中，选择**无**、**主题图稿**或**自定义图像**。 **新会话页面**和**对话**是独立的：隐藏背景不会删除您的图像。第一次选择自定义图像时，请先关闭对话背景。稍后的编辑会保留您的放置选择。更改主题、字体、重音或颜色模式不会替换显式图像或重新启用 **None**。如果没有个人配置文件，则“无”、主题图稿、位置、演示和可见性仅保存在所选网关的此浏览器中。您可以在不登录的情况下选择退出；私人上传仍然需要配置文件。

自定义图像属于您经过身份验证的个人资料，而不是共享对话。上传静态 JPEG、PNG 或 WebP，最多 8 MiB 和 25 兆像素。网关将其大小调整为最长边最多 2560 像素，剥离元数据，并保存最多 2 MiB 的标准化 JPEG。不保留原始文件。您可以保留一张图像； **Replace image** 替换它，**Remove image** 删除它。选择“无”或主题图稿会保留图像以供以后使用。上传需要配置文件写入权限； Control UI 解释了个人资料或权限何时不可用。

选择 **Faded** 将图稿淡入画布中，或选择 **全出血** 将其保留在整个画布上。两者都使用活动调色板来保护文本对比度；这些模式改变了覆盖范围，而不是可读性。即使在最大强度下，自定义图像的可见性也是有限的，并且全出血始终保留主题颜色的覆盖。未保存演示模式时，默认为淡入淡出。两种模式都会使作曲家和用户消息气泡保持稳定，并淡化顶部栏附近的艺术作品。 **图像可视性**调节装饰强度；移动滑块可在“设置”中短暂预览背景。插件主题图稿将其调色板安全强度保持在默认值或以下；在其上方，滑块将图稿提升到相同的固定上限自定义图像停止处，达到 100%。源和演示是独立的，因此更改或删除图像不会重置所选模式。

缺失的图像会留下正常的主题色画布。禁用表面不请求私有图像。增加对比度和强制颜色抑制装饰图像；降低透明度会抑制自定义艺术品并恢复不透明的书写表面。不联系外部图像主机。

从tweakcn导入的主题仅存储在当前浏览器配置文件中；它们不会写入网关配置，也不会跨设备同步。替换导入的主题会更新一个本地插槽；如果导入的主题处于活动状态，则清除它会切换回 Claw。

在外观中选择 **不同主题** 将应用其完整的默认外观，清除界面和聊天字体覆盖并选择其自己的口音调色板。您可以随后自定义字体和重音。选择相同主题、重新加载、重新连接、接收同步首选项或更改 light/dark 模式不会重置这些自定义设置。语言、文字大小、聊天显示和其他不相关的首选项均保持不变。

安装的 UI 为其连接的网关保留实时显示首选项快照。本地更改和同一网关浏览器选项卡编辑会更新打开的作曲家，而无需重新加载。侧边栏宽度、个人铁路快捷方式和固定代理也会跨选项卡更新；折叠侧边栏保留在每个选项卡本地。调整侧边栏的大小会保留在另一个选项卡中更改的快捷方式。在另一个选项卡中选择不同的网关不会重新定位当前选项卡。凭据仍归连接所有，与此显示快照分开。

个人铁路快捷方式开始为空，其顺序在设备之间同步，以获得具有写入权限的经过身份验证的网关配置文件。通过将会话、页面、插件或人员拖动到轨道中来添加快捷方式。升级后，旧的侧边栏顺序和引脚不会保留：导轨使用新的 `ui.railShortcuts` 首选项和浏览器本地 `railShortcuts` 字段。旧值仍被存储但被忽略。新身份下保存的快捷方式保持不变；没有保存列表的配置文件不会导入共享导航或固定会话。在只读连接或没有持久配置文件的连接上，导航更改保留在浏览器本地，并且永远不会写入共享网关配置。会话所有者过滤器存储在每个网关和配置文件的浏览器中；对于已识别的配置文件，其默认值为 **我的会话** ，而身份未解析或不存在时为 **所有所有者** 。侧边栏宽度和滚动位置仍然特定于浏览器。代理切换器引脚是一个单独的浏览器配置文件首选项。参见[导航导轨](/web/control-ui/sessions-and-sidebar#navigation-rail)。

在“外观”中选择 **强调色** 预设或自定义颜色以覆盖活动主题的强调色。对于经过身份验证的网关配置文件，重音优先级是配置文件的 `ui.accent` 首选项、网关范围的 `ui.prefs.accent` 设置、操作员配置的 `ui.seamColor` 以及最后活动主题的默认值。主题选择存储显式的 `"theme"` 重音首选项，它在浅色和深色模式下使用所选主题的完整调色板，而不是继承网关范围的颜色覆盖。 **恢复默认值** 仅清除该配置文件的首选项，使网关范围的设置保持不变。没有经过身份验证的配置文件的连接将保留现有的网关范围的首选项行为。

现有的未设置和十六进制重音保留其含义；升级不会迁移或重置已保存的首选项。无法识别配置文件值 `"theme"` 的较旧 Control UI 读卡器会回退到继承的颜色。在降级到 `ui.prefs.accent` 仅接受十六进制颜色的网关之前，请删除配置的 `"theme"` 值或将其替换为 `#RRGGBB`。这不会添加数据库架构版本或首选项键。

**Typography** 块允许您选择 **Interface** 界面和单独的 **Chat prose** 界面。 **主题默认**界面和聊天散文都恢复了主题的排版； Dash 和 Absolute 保留自己的衬线聊天默认设置。 **System** 使用系统无衬线堆栈而不加载网络字体。代码保留其等宽堆栈。打开任一选取器都会按需加载自托管样本；启动时仅加载活动面。字体覆盖遵循经过身份验证的网关配置文件，并带有用于即时启动的浏览器本地镜像。如果没有配置文件，它们会保留在该浏览器中，并且永远不会写入 `openclaw.json`。

外观面板还提供了文本大小设置。它适用于聊天文本、消息编辑器文本、工具卡片和聊天侧边栏，并会将文本输入框至少保持为 16px，以免移动端 Safari 在聚焦时自动缩放。

模态对话框遵循操作系统的简化运动首选项，在启用时打开和关闭而无需进入或退出动画。

外观还带有 **Lobster 访问** 和 **Lobster 声音** 开关和 Lobsterdex。两个切换都是浏览器本地的。请参阅 [Lobster](/web/lobster) 了解作曲家访客的功能以及如何永久关闭它们。

当您的连接绑定到经过身份验证的网关配置文件时，主题、主题模式和强调色将保存到该配置文件而不是网关配置中。它们会跨设备跟踪您，而不会改变其他任何人的外观，覆盖网关范围内的 `ui.prefs` 值，并实时更新您连接的客户端。没有经过身份验证的配置文件的连接将像以前一样通过网关配置继续同步这些首选项。语言和聊天显示首选项仍然是每个连接的网关配置首选项。每个浏览器都保留一个本地镜像以供即时启动，并且文本大小保持浏览器本地大小。显式只读连接仅在该浏览器中应用首选项更改。离线时所做的更改将保持排队状态，直到稍后的连接可以写入其适用的首选项；在只读重新连接时，它们继续表现为浏览器本地首选项。参见[配置参考](/gateway/configuration-reference#ui)。

## <a id="opening-links"></a> 打开链接

在 **设置 → 外观 → 聊天** 下，启用 **在 OpenClaw** 外部打开链接，以打开 OpenClaw 外部而不是内置阅读器或浏览器面板中的 Web 链接。在网络浏览器中，链接使用普通的浏览器导航；在本机应用程序中，它们在系统的默认浏览器中打开。默认情况下该开关处于关闭状态，保留当前行为。关闭它会恢复内置阅读器和 Control UI 浏览器**首选项中任何现有的**Open 链接。当您单击浏览器预览卡的图像或 **Open** 按钮时，浏览器预览卡也会遵循此设置。他们的三点菜单在启用外部打开时在 OpenClaw**中提供**Open，在禁用外部打开时在新选项卡中提供 **Open**。显式上下文菜单选择仍然有效。

此首选项仅存储在当前浏览器或应用程序 Web 视图中，针对每个网关单独存储。它不会更改共享网关配置或跨设备同步。清除站点数据会将其重置。内部OpenClaw导航和下载不变。

## <a id="session-sources"></a> 会话源

打开侧边栏的**Filter & sort**菜单并选择**Sessionsource…**来控制**Claude Code**的自动发现， **Codex**、**OpenCode** 和 **Pi** 对话。相同的控件位于 **设置 → 外观 → 会话源**；在“设置”中搜索编码应用程序的名称和 **sessions** 会直接打开它们。

仅显示其所属插件已安装的源：Claude Code、**Codex**、**Anthropic**、 **OpenCode**，以及 Pi 的 **ACPX**。已安装但已禁用的插件仍然会暴露其发现首选项；必须启用该插件才能运行发现。

**Show … 会话** 交换机控制网关和符合条件的配对计算机上的发现。它们使用每个插件的现有发现首选项，并应用于该网关上的每个人。更改会自动保存并需要重新启动网关。 **管理插件** 打开安装和启用控件。 Pi 使用 ACPX 的 `piSessionCatalog.enabled` 偏好；其他来源使用其插件的 `sessionCatalog.enabled` 首选项。禁用发现会使提供程序和harness设置保持不变。

全新安装将启动 Claude Code 和 Codex 发现。 OpenCode 和 Pi 当前默认为打开。现有安装保留其以前的设置，包括旧的隐式默认设置。 **H 从目录菜单中的侧边栏隐藏** 仍然是单独的仅浏览器呈现首选项。

## <a id="manage-plugins"></a> 管理插件

在侧边栏中打开 **插件**，或者使用相对于已配置 Control UI 基础路径的 `/settings/plugins`，即可在不离开 Control UI 的情况下浏览和管理插件。例如，基础路径为 `/openclaw` 时，会使用 `/openclaw/settings/plugins`。即使所有可选插件都被禁用，该页面也始终可用。

`/plugins` 上的 **Plugins** 中心浏览目录。其 **Skills** 和 **Skill Workshop** 选项卡可打开位于 `/skills` 的每个代理技能管理器和位于 `/skills/workshop` 的技能工作室。 **设置 → 插件** at `/settings/plugins` 显示可搜索的本地库存。选择一个插件以打开其概述。

打开插件会在一个概述中显示其描述、发布者（可用时）、技能、工具、MCP 服务器和完整的 README。选择一个工具以阅读其完整说明。展开 MCP 服务器以查看其发布的端点、传输、身份验证方法、请求的权限以及可用的设置说明。这些描述了连接；帐户连接状态单独显示。插件可以捆绑多个 MCP 服务器。元数据栏显示可用的版本详细信息、类别、存储库和文档。安全审核链接至 ClawHub。

安装的、禁用的插件将 **Enable** 首先作为主要操作，然后是 **Ask OpenClaw**。启用的插件将主要 **Ask OpenClaw** 放在第一位，然后是 **Disable**。然后，两行在可拆卸时提供 **Uninstall** 以及 **Settings** 的图标按钮。卸载的插件将 **Install** 放在第一位。 **Install** 立即开始安装并接受分阶段插件声明的功能，而无需更改您的挂钩和模型权限。配置的安装策略警告仍然需要明确确认。从目录概览安装保持相同的 URL。其进度弹出窗口显示报告的步骤和经过的时间，包括运行时应用程序。仅在网关返回最终结果后才会显示已安装的操作。准备好新插件启用；缺少所需的配置或现有的禁用选项会使它们保持禁用状态。 **Settings** 打开一个可寻址编辑器，其中包含插件配置和可编辑的 **Permissions** 控件；返回到概述。现有的 `#configuration` 链接仍会打开编辑器。当可选的 ClawHub 元数据无法加载时，本地控件和已安装的 README 仍然可用。该目录显示了特色插件和类别架。在每个类别中，ClawHub 的选定优先级首先出现，然后是按下载顺序排列的剩余插件。 **查看全部** 保留该顺序。计算机使用群体交互式桌面和浏览器控制。其他和未分类的插件仍然可以通过搜索和已安装插件管理而不是主页部分使用。无需离开页面即可搜索查询 [ClawHub](https://clawhub.ai/plugins)。目录详细链接使用`/plugins/<catalog-id>`；仅安装链接使用 `/settings/plugins/<plugin-id>`。两者都显示相同的概述和操作。

在插件详细信息页面上打开技能以浏览其完整声明的文件夹。查看器从 `SKILL.md` 开始，包括未链接的文件和嵌套文件夹，并呈现完整的 Markdown 文档。无法渲染、超出读取限制或不可用的文件仍然可见并附有说明。安装的插件和目录插件使用相同的查看器；目录读取保持固定到选定的版本，并且不安装或执行插件。该查看器没有搜索或复制控件。读取捆绑包需要 `operator.read`。

**Skills** 选项卡保留技能状态报告、enable/disable 切换、API 按键输入和内联 ClawHub 技能搜索，范围仅限于选定的座席。 **技能研讨会**选项卡显示[学习的技能](/tools/skill-workshop)及其使用计数以及**Undo**的最新更改。 **从过去的对话中学习** 使用所选代理的配置模型和允许的工具打开正常会话。特工按照当前的创意工坊模式选择要检查的历史和技能。聊天显示进度、结果以及正常停止和后续控制。

内置插件已经存在于 Gateway 上，并显示 **启用** 或 **禁用**，而不是 **安装**。例如，Workboard 已随 OpenClaw 包含但默认禁用，因此其操作是 **启用**。捆绑插件不能被移除，只能被禁用。

读取目录和搜索 ClawHub 需要 `operator.read`。安装、启用、禁用或移除插件，以及更改 MCP 服务器，需要 `operator.admin`；对于只读操作者，这些操作会保持禁用状态。

插件声明的凭据字段支持屏蔽密钥输入和内联密钥注册链接。眼睛会显示您正在输入的密钥。如果没有输入新密钥，管理员可以选择 **Show API key** 来检索该字段和当前配置修订的存储文字。当字段、配置修订或网关连接发生更改时，显示的已保存值将再次隐藏。秘密引用和环境值永远不会被解析或泄露。保持空输入不变会保留其现有凭证。

管理员可以检查和编辑已声明凭据的秘密引用：其来源（`env`、`file`、`exec` 或 `store`）、提供者别名和标识符。网关仅返回所选字段和当前配置修订的元数据，而不解析机密。 **Cancel** 删除此字段的未保存的参考更改（包括在拒绝保存之后），同时保留其他编辑。如果“取消”无法重新加载已保存的配置，该对话框将保留草稿并显示读取错误；后台刷新无法取代挂起的取消读取。 **Save** 等待现有设置写入被确认；当写入处于挂起状态时，无法关闭该对话框。如果无法确认保存的值，对话框将保留草稿并显示恢复错误。失败的写入会保留草稿，陈旧的修订需要重新阅读。只读配置允许检查但禁用更改。环境回退仅用于检查：在其源处更改变量。保存引用不会轮换机密或验证提供者连接。没有声明凭证元数据的字段保留普通模式编辑器。

ClawHub 安装通过网关运行，并与其他网关中介的安装保持相同的信任、完整性和插件安装策略检查。安装、启用、禁用和删除操作会等待运行时应用程序，而无需重新启动网关。普通插件配置编辑也会在默认混合重新加载模式下自动应用。请参阅 [ 应用更改并检查 ](/plugins/manage-plugins#apply-changes-and-inspect) 是否有应用程序故障、清理警告和源代码编辑重新加载。添加 OAuth- 支持的 MCP 连接器后，需要从 CLI 获取一次性 `openclaw mcp login <name>`。

该页面有意聚焦于清单、发现、安装、启用和移除。对于任意 npm、git 或本地路径来源、更新以及高级插件配置，请使用 [`openclaw plugins`](/cli/plugins)。

## <a id="updates"></a> 更新

打开 **设置 → 更新** （`/settings/updates`） 以检查已安装的版本、更新策略以及活动或最新更新。 **立即更新** 打开一个确认，显示目标和重启影响。选择**更新并重启**启动；取消不会影响网关。

收件箱和帐户菜单中的新更新通知仅针对 `stable` 和 `beta` 频道显示。 `dev` 通道仍然可以在此处手动检查并启动更新，并且活动更新进度和恢复消息仍然可见。

对于 `dev` git 更新，确认、运行报告和可用更新状态在提交计数下方的单独行上显示已安装→目标短提交 SHA。当跟踪的上游是 GitHub 存储库时，**Compare 在 GitHub** 上打开比较；其他安装显示简单的修订。这可以区分共享版本号的修订版。签出刷新后，计数、修订和比较链接描述相同的已检查上游。自动更新活动保持其宣布的目标；其显示的比较仍然与该目标绑定。如果安装的版本已更改，活动将显示其目标，而不会显示过时的计数或链接。来自不同比较的提交详细信息保持隐藏。

确认后，一个更新视图会显示已排序的阶段、当前或最后一步的详细信息以及服务、版本、插件、通道和推理的验证结果。详细信息区域将换行，直到向上滚动。该对话框保持打开状态，**Gateway 重新启动…**，而连接断开。重新连接后，它从网关读取相同的运行；重新加载页面还会恢复“设置”中的活动或最新运行。

每次完成的运行都会保留一份报告，包括成功情况。失败的运行保留 **检查状态**、**重试更新** 和分类恢复操作。侧边栏更新卡显示活动阶段并打开相同的视图。已完成的运行可能会在其中显示长达 24 小时，直到您在该浏览器中确认为止。

该报告通过聊天和 CLI 共享。请参阅 [Updating](/install/updating) 以了解特定于安装的行为，并参阅 [ 运行历史记录和报告 ](/cli/update#run-history-and-reports) 以检查网关主机的运行情况。在签名的 macOS 应用程序中，应用程序拥有的本地网关仍使用 **Update Mac 应用程序 + Gateway** 和本机更新流程。

## <a id="settings"></a> 设置

在 **设置** 中，专用侧边栏包含 **询问 OpenClaw**，并以一个 **搜索设置** 字段开头，用于快速查找设置分区。

表单编辑自动保存。如果编辑挂起时连接发生变化，自动保存会暂停，直到您选择 **Save** 保留它们或 **Reload Config** 放弃它们并加载当前配置。成功的重新加载将恢复新编辑的自动保存；离线重新加载会保留待处理的草稿。设备节点绑定控件也会在配置重新加载时暂停，因此挂起的读取无法覆盖新的选择。

当高级设置重新连接时，具有已加载架构的表单在架构刷新时在您的阅读位置保持可见。在刷新完成之前，无法编辑表单和设置控件。第一次加载仍显示 **Loading schema…**，直到 schema 可用。

在代理的 **Files** 编辑器中，**Add file** 打开缺少的可选工作区文档。仅当它仍然丢失时，保存才会创建它。如果另一个编辑者或进程首先创建它，则该编辑者会保留您的草稿并报告冲突。 **Reload** 取当前文件； **Overwrite** 重新加载其当前版本，然后根据该版本保存草稿。当您切换代理或刷新时，草稿将保留其原始文件版本。如果远程工作空间提供商无法独占地创建文件，则保存会解释如何更新它或在该主机上创建文件并重新加载它；它不会默默地覆盖文件。

**Native 嵌入模式。** 本机主机可以在文档开始处注入 `window.__OPENCLAW_NATIVE_EMBED__ = { platform: "ios", formFactor: "phone" }` 以显示设置，而无需仪表板导航镶边。支持的平台有`ios`、`macos`、`android`；外形尺寸为 `phone`、`pad` 和 `desktop`。在此模式下，`/settings` 列出与设置侧边栏相同的可见组和目标。设置根目录之外的每个嵌入路由都提供“后退”按钮和标题，包括通过链接或选项卡访问的页面，例如“内存导入”、“插件”和“技能研讨会”。返回遵循应用程序导航历史记录；直接链接回退到最近的设置父项（用于内存导入的内存）或 `/settings`。布局尊重设备安全区域，并在手机宽​​度上使用触摸控制。该标志仅更改表示形式：网关范围和现有的本机设备设置功能仍然确定哪些设置可用。普通浏览器加载会保留其现有的导航。

**本机对话界面。** 通过在受信任的主框架中的文档开头注入这些全局变量，本机聊天窗口可以选择加入单个 Web 对话：

```js
window.__OPENCLAW_NATIVE_EMBED__ = {
  platform: "macos",
  formFactor: "desktop",
  surface: "conversation",
};
window.__OPENCLAW_NATIVE_CONVERSATION__ = { contract: 1 };
```

Chat 保留其窗格标题、文字记录、编辑器、侧面板和叠加层。嵌入的 Back/title 标题和代理选择器将被省略，并且不会恢复已保存的分割窗格。网络拥有发送、草稿和对话交互；本机窗口拥有其周围的导航。省略 `surface` 将保留上述设置嵌入。

主机安装 `window.webkit.messageHandlers.openclawConversation.postMessage`，Promise 回复 `{ ok: true }` 或 `{ ok: false, error }`。惰性桥在发送 `ready` 之前先发布 `__OPENCLAW_NATIVE_CONVERSATION_DOCUMENT__ = { contract: 1, documentId }`。消息携带合同和文档 ID。命令结果回显原始请求的文档 ID，包括 `stale-document` 拒绝，因此它们无法匹配其他文档的请求。主机必须在采用就绪状态之前验证当前文档的 ID，并清除其对导航、重新加载或进程终止的绑定。

本机命令将 `openclaw:native-conversation-command` 窗口事件与 `detail: { contract: 1, documentId, requestId, type, payload }` 结合使用。支持的命令包括 `navigate { agentId, sessionKey }`、`presentation { visible, active }` 和 `focus-composer {}`。每个请求收到一个`command-result`；过时文档 ID 返回 `stale-document`，未知命令返回 `unsupported`。导航就地切换会话并在目标状态到达主机后报告成功。它在收到后 15 秒内解决，包括排队命令和主机确认；失败返回 `navigate-timeout` 或 `navigate-rejected`。 `visible` 标志控制窗格显示。可见的非活动窗口持续渲染并接受导航； `active` 仅控制作曲家焦点请求。仅更改 `state` 消息携带单调修订、agent/session 上下文、标题、运行活动和连接状态。 Web 会话更改发送 `route-changed`；非聊天目标发送 `open-dashboard { path, search? }` 并保留当前对话。现有的脚本文件链接、会话链接和侧面板操作保留其窗格内处理程序。失败的仪表板切换会显示祝酒词而不离开对话。共享电线类型和验证位于 `ui/src/app/native-conversation-bridge.ts` 中。

接受显式 `null` 值的选择字段将其显示为下拉选项。对于可选字段，`null` 与清除设置或选择其默认值仍然不同。拒绝的选择（例如唯一值列表中的重复项）会将先前的选择保留在原处。

对于没有默认值的空整数字段，步进按钮会在允许的端点处初始化仅正值或仅负值范围，匹配键盘箭头。例如，最小值为 1 的字段在第一个增量时从 1 开始。

当您删除较早的行或编辑其他设置时，不完整的数组行编辑将保留在其项目中。更正该字段以保存其新值。

当您使用键盘删除列表项或映射条目时，焦点会移至下一个剩余行、删除最后一行后移至上一行，或者在集合为空时移至集合的添加按钮。被拒绝的删除会将焦点保留在其删除按钮上。

在桌面网络上，活动代理的头像显示在图标栏的顶部。单击它会打开代理菜单；在团队模式下，身份会打开工作区菜单。命令面板搜索 （⌘K） 位于页面、会话和在线按钮下方。每个视图都有一个标题行。在会话中，其标题是所有者过滤器芯片（**我的会话**、**涉及我**、**所有所有者**，或一个人的名字），后面是剩余的过滤器和折叠按钮。铁路拥有**新对话**，在团队模式下打开团队新会话菜单；图标栏底部的 **Home** 可切换主页面板并反映活动代理的主页活动和注意力状态。当某些事情需要采取行动时——失败或过期的 cron 作业、过期或过期的模型身份验证——导轨的 **Inbox** 按钮会显示一个注意徽章。打开收件箱以检查项目并导航到其所属页面。铁路身份显示代理的头像（身份图像或表情符号），其工具提示和可访问标签中包含名称；活动运行状态显示在所属会话行上。其菜单包含代理图块、**新代理**、**查看所有代理**，以及为活动代理命名的操作，例如**Harbor可以做什么？**和**Harbor设置**。通过多个配置的代理，**显示全部**图块显示他们分组的头像并启用团队模式；选择指定的代理磁贴会离开团队模式并将页面范围分配给该代理。您还可以从 **设置 → 代理** 创建代理：选择具有零个或一个代理的独立 **新代理** 按钮，或具有多个代理的代理选择器底部的项目。创建需要管理员访问权限。座席切换器首先列出固定的座席。对于超过三个代理，将鼠标悬停或键盘聚焦代理行即可显示其固定按钮；固定的代理使静音的固定保持可见，并且触摸设备始终显示控件。对于三个或更少的代理，此菜单没有固定控件，包括已经固定的代理。聚焦某一行后，按 Tab 键即可固定该行，然后按 Enter 或 Space 键即可固定或取消固定，而无需切换代理或关闭菜单。代理设置页面使用相同的 pin 首选项，存储在浏览器配置文件中。选择代理的范围包括聊天以及该代理的使用情况、自动化、工作板和会话。每个作用域页面公开一个 **Agent** 控件，并使用 **Allagents** 作为转义；这扩大了共享页面范围，而无需更改具体的聊天代理，而直接会话链接仍然打开其目标。代理设置页面保留其自己的 [URL 选择](/web/urls#route-table)，并且不遵循共享页面范围。导航栏底部的配置文件图标仍可离线使用，其可访问标签和工具提示中包含连接状态。它打开 app/account 菜单，其配置文件身份标头后面是 **Settings**、**Updates**、**Usage**、移动配对、**获取apps**、**Help**（帮助、Discord、文档和更改日志）、需要时的离线重试操作、version/build 芯片和颜色模式切换。构建芯片打开“关于”页面。当网关从 `main` 以外的分支上的源签出运行时，页脚还会以红色显示该分支名称，因此非发布网关一目了然（发布安装从不显示它）。 Apple 平台上的 Shift-Command-Comma 或其他位置的 Ctrl-Shift-Comma 可打开 **Settings**，而不会覆盖浏览器的普通 Command-Comma 快捷方式。折叠侧边栏 （⌘B） 可隐藏导航列表，同时保持图标栏及其个人快捷方式可用。单击活动轨道视图可切换其列表；选择另一个视图将打开该列表。打开主页或固定的会话、页面、插件或人员会折叠桌面上的列表，同时保持栏可用。导轨保持其自己的宽度，而不是减少保存的列表宽度。侧边栏是桌面上唯一的导航镶边，没有顶栏。狭窄的视口将侧边栏替换为紧凑标题行后面的滑盖式抽屉，其中包含抽屉切换、品牌和命令调色板搜索；在手机上，Chat 将该导航行吸收到其标题栏中，菜单和搜索控件位于会话标题旁边。

macOS Web 体验和 macOS、Linux 和 Windows 上的 Tauri 桌面应用程序共享桌面 Web 导轨和面板布局，面板和内容标题位于 52 像素标题栏行的中心。在桌面网络和这些应用程序中，会话、页面和在线有一个尾随的 **折叠侧边栏** 按钮；会话标题后面是其过滤器控件。 **新对话**留在轨道上并在团队模式下打开团队新会话菜单。折叠后仅在持久导轨旁边留下 **展开侧边栏**。搜索保持在栏内，并且本机 back/forward 按钮在展开和折叠布局中都位于内容标题之前。在 macOS 上，面板标题清除了交通信号灯，并且导轨保留了可拖动的顶部插图； Linux/Windows 将导轨与顶行对齐，并保留右上角的标题按钮。导航使用常规浏览器历史记录； macOS 应用程序还支持触控板滑动手势。

左下角的帐户页脚（包括“设置”侧边栏）显示 **Suspending…**（当网关准备或耗尽工作时），以及 **Suspished**（一旦暂停准备就绪）。重新启动状态优先。重新连接期间，来自网关的最新暂停报告使该状态保持可见；无法解释的断开连接显示 **Offline**。当网关再次接受工作或其上次暂停报告到期时，暂停指示器会清除。

侧边栏可见性属于当前选项卡，不会跨选项卡、窗口或重新加载而被记住；侧边栏的宽度仍然被记住。在桌面上，新选项卡、直接链接、书签和重新加载均以展开的侧边栏开始。中键单击或 Cmd/Ctrl-click 会话可在新选项卡中打开它，而无需更改原始选项卡。在 Mac 上按 ⌘B 或在 Windows/Linux 上按 Ctrl+B 可折叠或展开当前选项卡中的侧边栏。

待批准也有助于该铁路的 **Inbox** 关注徽章。打开收件箱检查它们并导航到“批准”页面。

当批准内联显示在不同的会话中时，会话 **请求的**Approval 使用请求会话的已加载标题，而不是打开的对话的标题。如果该元数据不可用，则将保留正常的会话名称回退，直到加载为止。此标签不会更改批准按钮解决的请求。

### <a id="side-panel-keyboard-shortcuts"></a> 侧面板键盘快捷键

侧面板 **+** 菜单和键盘快捷键概述（在 Apple 平台上为 ⌘/，在其他地方为 Ctrl+/）显示相同的面板快捷键。快捷方式可打开其面板、激活现有的隐藏选项卡或在面板可见时关闭面板。只有活动的、呈现的聊天窗格才会响应，包括当作曲家获得焦点时。可用性遵循菜单：终端、浏览器、桌面和讨论需要相应的功能；仪表板需要可用的会话板，并且在紧凑窗格中被省略。对话没有捷径。

| 控制板      | macOS | Windows / Linux  |
| ---------- | ----- | ---------------- |
| 终端   | ⌃\`   | Ctrl+\`          |
| 浏览器    | ⌘⌥⇧U  | Ctrl+Alt+Shift+U |
| 文件数      | ⌘⇧B   | Ctrl+Shift+B     |
| 边聊  | ⌘⇧S   | Ctrl+Shift+S     |
| 桌面    | ⌘⌥⇧D  | Ctrl+Alt+Shift+D |
| 讨论 | ⌘⌥⇧J  | Ctrl+Alt+Shift+J |
| 仪表板  | ⌘⌥⇧G  | Ctrl+Alt+Shift+G |
| 审阅     | ⌘⌥⇧E  | Ctrl+Alt+Shift+E |

Command+Option 和弦通过物理键接受 Option 符号； Ctrl+Alt 和弦需要匹配的 ASCII 字母才能保留非 ASCII AltGr 文本。死键和合成将被忽略。

新的面板和弦包括 Option/Alt 以避免浏览器操作，例如开发人员工具、朗读和查找上一个，以及 OpenClaw 现有的调试覆盖快捷方式。现有的终端、文件和侧聊天绑定保持不变。

### <a id="this-device-(macos-and-ios-apps)"></a><a id="this-device-macos-and-ios-apps"></a> 此设备（macOS 和 iOS 应用程序）

在 [macOS 应用程序 ](/platforms/macos) 中，“设置”包括一个 **此 Mac** 组，用于该 Mac 上的设置。 **此 Mac** （`/settings/device`） 包含应用程序行为、设备功能、浏览器登录导入和 cookie 同步以及开发人员工具。 **功能 → 桌面共享** 默认启用，并在配对批准后在 **Systems** 中提供此 Mac 的现有屏幕共享服务。它独立于代理 **计算机 Control** 和 **保持计算机唤醒**。更改它会自动重新连接这台 Mac；它不会更改远程网关主机的桌面设置或启用 macOS 屏幕共享。 **Permissions** （`/settings/device/permissions`） 显示 macOS 权限状态和操作、位置首选项以及活动计算机状态。

**Talk** 添加了一个 **Mac** 部分，用于语音唤醒、一键通、声音、麦克风和语言。 **Updates** 添加了应用程序版本、自动更新首选项和 **检查更新**。这些设备设置仅出现在 OpenClaw 应用程序内；普通浏览器保留网关设置。对话触发词是网关设置，并且在每个浏览器中都可用。

在 iOS 上，该组是 **This iPhone** 或 **This iPad**。设备页面显示外观、通知、摄像头、保持唤醒和运行状况摘要（如果有），以及打开诊断、许可证、关于和 Apple 观看的操作。仅显示应用程序发布的设置； iOS 不显示 Mac 浏览器或应用程序更新控件。权限包括设备发布的访问权限，包括对联系人或照片的有限访问权限。 iOS 上的精确位置是只读的； **打开设置**打开系统设置。通话显示设备的语音唤醒、通话模式、通话按钮、背景通话和扬声器控件。

## <a id="claws-(labs)"></a><a id="claws-labs"></a> 爪（实验室）

启用**设置→实验室→Claws**，在**Agents**页面上浏览ClawHub的官方Claw包。搜索目录，查看 Claw 将安装的文件和功能，然后选择 **Add** 以创建其代理。 Add 创建一个普通代理并打开其聊天。它不会创建单独安装的 Claw 来更新或删除。通过正常的代理控件删除代理；共享插件和 MCP 服务器仍保持安装状态。有关包合同和本地源 CLI 命令，请参阅 [Claws](/cli/claws)。

关闭实验室开关会隐藏爪子发现和添加。现有代理继续运行。

## <a id="speech-bubbles"></a> 语音气泡

**设置→实验室→语音气泡**控制`gateway.controlUi.experimental.chatBubbles`（默认关闭）。启用它会使主页默认使用气泡并公开每个对话的视图菜单切换。浏览器本地 on/off 选择优先于主页默认设置。关闭实验室会隐藏开关并恢复各处的标准视图，而不会清除这些选择；重新打开它可以恢复它们。更改适用于打开的 Control UI 页面，无需重新启动网关。

## <a id="custom-plugin-ui"></a> 自定义插件 UI

在“设置”侧边栏的 **System** 部分中，在 **Infrastruction** 后面找到 **Labs**。

**设置 → 实验室 → 自定义插件 UI** 启用本机页面、小部件、操作和视图替换用户安装的插件。默认为关闭并写入 `gateway.controlUi.experimental.customPlugins`。更改无需重新启动网关即可应用，并且连接的页面会自动刷新其插件视图。禁用后，重新加载浏览器选项卡以清除已运行的插件 JavaScript。

仅为您信任的插件作者启用它：本机 UI 在 Control UI 源中运行，具有登录操作员的网关权限。来自启用的捆绑插件（包括 Workboard）的本机 UI 在实验室关闭时仍然可用。后端插件 API、普通插件加载、沙盒仪表板小部件和 MCP 应用程序不受影响。所有插件 API 都是实验性的；有关创作和信任模型，请参阅 [ 功能插件](/plugins/feature-plugins)。

经过身份验证的本机 UI 需要 HTTPS 或浏览器信任的环回 URL。在非本地普通 HTTP 上，插件页面解释了如何打开支持的 URL；仪表板配对和后端插件操作仍然可用。

## <a id="import-assistant-memory"></a> 导入助手记忆

打开 **Settings** → **Import Memory** 将本地 Codex、Claude Code 或 Hermes 内存引入 OpenClaw 代理。网关发现其自己的主机上受支持的本地内存，因此远程 Control UI 从网关计算机而不是浏览器计算机导入。

如果代理列表加载失败，页面会显示网关错误。选择**Refresh**重试； **设置→内存**针对相同故障提供**Retry**。

1. 选择目标代理。
2. 审阅检测到的源集合和 Markdown 文件名。文件内容不会在计划响应中发送，也不会显示在页面上。
3. 选择要导入的集合并确认。应用会在写入前重新构建计划，因此过时的选择会安全失败。
4. 如果文件已存在，启用 **替换现有导入**，刷新预览，然后确认替换。

Codex 仅导入其汇总后的 `MEMORY.md` 和 `memory_summary.md`。Claude Code 会从项目自动记忆目录以及已配置的 `autoMemoryDirectory` 导入 Markdown；它不会通过此页面导入会话、设置、指令或凭据。文件会被复制到所选工作区下的 `memory/imports/` 中，活动记忆插件可在此对其进行索引。源文件不会被更改。

如需更简便的对话路径，请打开 **设置 → 询问 OpenClaw** 并说 `import memory`。聊天向导只会将新检测到的记忆复制到现有的默认代理工作区；它不会选择其他目标代理，也不会替换冲突项。它会报告每个源已确认的复制数量，并在可能于部分复制后发生失败时发出警告。当你需要选择目标、预览文件或进行替换时，请使用专用的导入记忆页面。

如果错误表明应用已完成但无法返回其结果，请在开始另一次导入之前检查迁移报告和目标文件。重试相同的待处理请求会重用其记录的结果，而网关会保留它。插件清理警告不会撤消已完成的副本。

规划和应用需要 `operator.admin` 权限。每次应用都会在状态存在时创建经过验证的 OpenClaw 备份，写入已脱敏的迁移报告，并在替换现有目标文件前保留项目级备份。有关路径和召回行为，请参阅[记忆概览](/concepts/memory#import-from-coding-assistants)。

## <a id="mcp-page"></a> MCP 页面

专用 MCP 页面是 `mcp.servers` 下的 OpenClaw- 托管 MCP 服务器的操作员视图。它本身不会启动 MCP 传输；使用它来检查和编辑保存的配置，然后在需要实时服务器证明时使用 `openclaw mcp doctor --probe`。

典型工作流：

1. 从侧边栏打开 **MCP**。
2. 检查汇总卡片，了解总数、已启用、OAuth 和已过滤服务器数量。
3. 查看每一行服务器的传输方式、启用状态、认证、过滤器、超时和命令提示。
4. 直接在 MCP 页面上添加、启用、禁用或移除服务器。明确选择 Streamable HTTP、SSE 或 stdio；stdio 命令行接受带引号的参数，例如包含空格的路径。单击式连接器和发现请使用 **插件** 页面。
5. 编辑作用域内的 `mcp` 配置部分，以配置高级服务器字段，例如环境变量、工作目录、请求头、TLS/mTLS 路径、OAuth 元数据、工具过滤器和 Codex 投影元数据。
6. 使用 **保存** 进行配置写入，或使用 **保存并发布** 让正在运行的 Gateway 应用更改后的配置。
7. 在终端中运行 `openclaw mcp status --verbose`、`openclaw mcp doctor --probe` 或 `openclaw mcp reload`，用于静态诊断、实时验证或清除缓存运行时。

该页面在渲染之前会编辑带有凭据的 URL- 之类的值，并在命令片段中引用服务器名称，因此复制的命令仍然可以使用空格或 shell 元字符。完整的 CLI 和配置参考：[MCP](/cli/mcp)。

## <a id="activity-tab"></a> Activity 标签页

从侧边栏的 **Activity** 视图中打开 **Pages** 视图，或者在 Control UI 的基本路径下访问 `/activity`。它有两个选项卡和一个深层链接检查器：

- **Sessions** 显示按天分组的最近会话活动，包括搜索、时间和人员过滤器。会话按照最新输入或完成的运行对最新的进行排序，使用与行的年龄和日期组相同的时间。引脚不影响此顺序。每行显示人工归因和配置的代理 avatar/name. 子代理会话从源、搜索结果和人员计数中排除。当网关记录了运行参考时，活动行提供 **Inspect run**。
- 列表上方的脉冲卡描述了选定的时间窗口：**过去 24 小时的每小时柱形图**，**过去 7 天的日柱形图** 和 **过去 30 天的**，以及**下过去 12 个月的每月柱线，所有时间为**，使用当地时间。其活动会话、在窗口中启动的会话（在所有时间中省略）、关联人员和现在运行的会话的计数遵循当前过滤器，并包括超出 100 行窗口的匹配项；尽管每场比赛的时间期限涵盖 12 个月，但所有时间都很重要。每个会话都会为其最新活动的栏做出贡献。
- Each 会话可以用一到三句话进行滚动回顾：做了什么以及工作进展如何。回顾使用代理的 [ 实用程序模型 ](/gateway/config-agents/models#agents-defaults-model) 并在客户端和网关重新启动之间共享。初始加载使用微光占位符；现有的回顾令人耳目一新。刷新失败会保留最后的回顾并识别刷新失败。 **Retry recap** 在网关冷却后请求再次尝试。只读查看者可以读取缓存的摘要，但无法请求生成。在具有混合权限的页面上，仅查看会话不会阻止可写会话的回顾生成。
- 具有 GitHub 结帐的会话显示关联的分支 PR 及其 added/removed 行计数。将鼠标悬停在 PR 上或通过键盘聚焦以预览其详细信息，或选择它以打开 GitHub。在打开的 PR 存在之前，分支会显示其与默认分支的差异，包括未提交的工作。这些是 checkout/PR 统计数据，而不是累计会话编辑计数；不可用的计数保持隐藏，保留的陈旧数据带有警告。
- Sessions 可以在一个紧凑的水平行中显示最多四个转录图像。在窄屏幕上，横向滚动预览即可查看剩余图像。选择一个图像以在图像查看器中将其展开。当行接近视口时加载预览，读取有限的最近记录页面； **较旧的图像** 在保留更多历史记录时继续。现有缩略图在刷新和失败重试期间仍然可见。更改会话或连接会清除以前的图库。
- **实时活动** 显示临时浏览器本地工具流上方正在运行和排队的会话。会话快照来自网关；工具流使用与聊天工具卡相同的 `session.tool` 和工具事件。
- **Run检查器**仅是深层链接，并读取网关的持久、不可变的`audit.run.inspect`仅安全投影。 RPC 包含必需的 `decisionDisplays`，而不包含原始 `decisions` 字段。在活动会话上使用 **Inspect run** 或实时活动中的运行 ID 链接，或直接打开 `/activity?view=run&run=<percent-encoded-run-id>`。重新加载或重新访问链接会再次查询网关；它永远不会从现场活动中重建身份。

会话视图拥有独立于侧边栏的查询。它的人员过滤器在分页之前使用网关的完整可见会话关联，而不是四头像参与者预览。 `sessions.list` 接受 `involvingProfileId` 和 `includePeople`；响应报告已解析的选定配置文件 ID、有限人数和 `peopleIncomplete`。只有网关配置文件显示为人。远程、代理和未解析的身份无法通过同等的原始 ID 获取配置文件名称或链接。计数和日期描述相关的会话，而不是一个人的最后输入；记录的参与、验证的创建和分配的责任仍然与查看会话的权限不同。旧的个人资料链接遵循个人资料合并。人员弹出窗口记录了不完整的参与者历史记录；页脚标识被截断的结果。

会话视图在随机的四到五秒窗口中收集会话更改事件，以后的事件无法推迟。自动刷新完成后，下一个刷新将等待其持续时间的三倍，时间范围为 5 到 15 秒。事件驱动的刷新会在浏览器选项卡隐藏时暂停，并在您返回时追上一次，尊重冷却时间。更改过滤器或重试失败的请求仍会立即加载。侧边栏的会话功能还 [ 重用行快照和步数列表读取 ](/web/control-ui/sessions-and-sidebar#sidebar-navigation)。活动链接在初始加载和导航期间保留其搜索和人员过滤器。

当新工作发生时，网关更新会进行回顾，限制正在进行的更新并在运行结束后赶上。共享队列一次最多运行两个回顾调用，并随着延迟的增加而重试临时过载或速率限制失败最多三次，以尊重提供程序重试时间。身份验证、配置和耗尽订阅失败需要在重试之前进行更正。空闲会话不会进行重复的模型调用，包括当并发重述请求携带较旧的缓存重述时。归档保留回顾并请求跟进；仍在存档会话中运行的代理可以在工作完成时更新它。重新开放或新工作恢复新鲜度检查。当活动请求时，较旧的会话会回填有界的时间块。回顾阅读用户和助理对话文本，更喜欢最终答案并跳过工具 calls/results. 现有的缓存回顾通过同一队列逐渐采用较短的格式，同时保留其先前的覆盖范围。隐身会话和子代理会话不会生成摘要。概要是生成的文本，不能确定任务是否完成或授予会话访问权限。

由代理创建的可见对话也会收到回顾，包括生成的仪表板聊天和分配给侧边栏组的对话。他们的家长会话链接并不会将他们排除在回顾生成之外；隐藏的背景子代理仍被排除在外。

超大消息通知仅适用于省略的用户或助理消息。过大的工具结果（包括屏幕截图）不会触发它。较旧的缓存通知在下一次回顾刷新之前保持可见，这将清除仅屏幕截图的通知，同时保留早期超大对话消息的通知。旧的遗漏标志会重新检查一次并用当前缓存修订版进行标记。纠正当前的回顾不会调用模型。

要查找较旧的存档对话，请在人员筛选器中选择 **Sessions**、**All time** 和 **Everyone**，然后在 **Search 会话中输入其名称或标签标题…**。此元数据搜索包括存档会话，并适用于 100 个结果窗口之前的整个呼叫者可见存储。如果结果被截断，请缩小查询范围。打开存档的比赛以读取其保留的历史记录，然后选择 **Unarchive** 继续相同的对话。

**活动会话** 在您打开实时活动时加载，并在重新连接后刷新，因此已在运行或排队的会话会在新工具事件到达之前出现。它最多显示您可以查看的 100 个会话，包括其他代理的工作和代理拥有的全局会话。当更多会话匹配时，会出现限制通知。选择链接行以打开该会话。保留的 `unknown` 会话显示没有对话链接的状态；原始 `global` 会话在外部全局会话范围内执行相同的操作，其中 Home URL 寻址不同的会话。当视图打开时，更改会更新此快照；断开连接或失败的读取会显示可见状态，而不是声称会话处于空闲状态。 **Clear** 仅清除接收事件列表。它不会清除或停止活动会话。

实时活动可保留多达 100 个有界摘要以及截断的输出预览。预览文本未经过秘密屏蔽，并且可以包含凭据。工具参数值不存储在活动状态中； UI 显示参数被隐藏并仅记录参数字段计数。

仅当此视图打开并且浏览器选项卡可见时，实时活动才会收集事件。它监视有界的、授权的 **活动会话** 名册，并在您隐藏选项卡或离开视图时释放这些订阅。不会显示打开视图之前的活动。使用搜索、工具和状态过滤器来缩小收到的条目范围。离开“活动”页面、重新加载、更改网关或身份验证上下文，以及 **Clear** 重置列表。普通重新连接会保留接收到的条目和扩展状态，然后从刷新的名册中恢复订阅。此浏览器本地提要不是视图关闭、隐藏或断开连接时所执行工作的持久记录。

运行检查器显示保留的信任域、入口、调用者、代表主体、发起人、代理定义和委托人、运行时实例、适用的授权、保证证据、沿袭和有界决策接收列表。每个事实都有一个文本证据状态。 **Absent**表示所属边界明确记录没有值； **unattributed** 表示受支持的路径没有可用的调用程序； **unknown**表示预期证据缺失或不可读； **unsupported** 表示该路径没有阶段 0 证据合约。颜色仅作为补充。

选择一个收据以查看网关的有界安全显示投影：结构操作和结果字段、证据限制和经过验证的显示出处。仅当网关从拥有的调用路径知道生产者合约时，才会出现固定的核心摘要和后续步骤。通用或未经验证的收据显示结构 `unknown` 分类，并省略其摘要、补救措施和自称所有者元数据。活动直接使用安全结果：它不执行 UI-side 推理、接收后剥离或原始接收回退。 **Enforced** 表示记录的所有者在验证确切的上下文、执行和运行元组后更改了结果。 **仅归属**记录未经声明授权而发生的事情。 **Unsupported** 表示观察没有阶段 0 执行合同。检查员将这些状态显示为文本标记和颜色，并且从不从其他字段推断原因。

收据请求仅限 50 条记录。 **加载更多收据**跟随网关的不透明光标并保持较早的页面可见。稍后页面错误不会丢弃已显示的收据。每个收据链接都会将 `receipt=<opaque-display-selector>` 以及后面的页面中的 `decision=<opaque-cursor>` 添加到所选运行或执行 URL 中。网关拥有的选择器选择投影显示行，而不暴露 URL 中存储的收据标识符或作为页面文本。重新加载该链接会请求相同的有界页面并选择相同的投影行。过期或无效的页面光标是显式检查错误；选择**重新启动检查**保留选择的运行或执行并从首页重新启动。

批准和消息传递链接使用 `approval-decision:` 和 `message-decision:` 选择器命名空间。所有者查询从与显示的收据相同的快照中的行元数据中创建每个选择器；私人收据、解决方案和事件标识符永远不会成为 URL 参数。

运行检查需要 `operator.read` 权限，以及通告 `audit.run.inspect` 的 Gateway。执行身份收集默认关闭；启用 `logging.audit.executionIdentity`，重启 Gateway，并在需要此证据时记录新的运行。保留的上下文限制为 30 天和 100,000 行。因此，已知运行可能报告身份证据不可用或已过期；当一个运行引用关联多个执行时，该运行引用也可能不明确。UI 不会在多个执行之间猜测：请选择返回的候选项，以导航到 `/activity?view=run&execution=<percent-encoded-execution-id>`，并查询该确切执行。

审计账本是尽力而为的运行证据，而不是无损的合规档案。记录缺失或过期并不能证明某次运行或操作未发生。检查器绝不会显示提示词或消息文本、命令正文、参数、文件路径、凭据、环境值、原始源标识符或任意插件数据。有关收集、隐私、保留期限和 CLI 检查详情，请参阅[审计历史](/gateway/audit)。

## <a id="meetings-page"></a> 会议页面

打开 **Pages → Meetings** 以阅读在 `/meetings` 中保存的会议记录。使用 Pages 文稿中的固定按钮，或将其拖动到导轨中，创建个人快捷方式。会议不是默认固定项目。会议记录与 **Sessions** 中的座席聊天历史记录搜索是分开的。

每个页面最多包含 50 个会议，按当地时间分组，最新的会议在前。行显示参与者预览、持续时间、可用概述以及不同的 **进行中** 和 **未捕获语音** 状态。按标题或 session/source ID 搜索，然后选择会议。现有的 `/meetings?selector=...` 链接默认打开 **Summary**，包括在捕获处于活动状态时。不搜索会议 URL。打开 **Filters** 进行提供商、帐户、代理和日期控制；当这些过滤器处于活动状态时，该披露会自动打开。提供商、帐户和代理 ID 完全匹配。日期过滤器使用 UTC 会话开始时间，具有包含下限和排除上限。 **下一页**继续排序结果； **首页**，过滤器更改，或**刷新**开始新的分页过程。读者打开正在进行的会议和已完成的会议的 **Summary**。选择 **Transcript** 读取带时间戳的语音。显式选择的选项卡保持选中状态，包括捕获结束时。带有转录搜索且没有显式选项卡的 URL 将打开 **Transcript**。带时间戳的演讲者文本显示在桌面上的列表旁边或移动设备上的单列中。其 URL 保留选定的会议和选项卡。

当页面可见并已连接时，库和活动会议每三秒自动刷新一次。 **实时捕捉**显示经过的时间；空的活动记录显示 **等待语音**。更新显示已保存的语音，因此提供商捕获和转录可能会增加延迟。后台读取保留过滤器草稿、当前转录本页面和加载的历史记录，而无需加载闪存。阅读器会自动加载每一页并保留较早的文本。隐藏的选项卡会暂停自动读取，并在再次可见时赶上。一旦注释可用，已完成的会议刷新频率就会降低；没有笔记的会议在捕获停止后会继续检查存储的摘要。

使用拥有代理的实用模型保存新语音时，主动捕获大约每五分钟生成一个摘要。汇总工作不重叠；安静的时间保留现有的笔记。配置的主要模型和文本启发式在需要时提供后备注释。 **到目前为止的摘要** 标记临时注释并显示它们的生成时间。摘要生成过程中会继续捕获，停止会议会保存新的最终摘要。

**在此转录本中搜索** 在自动加载的有界服务器页面中搜索完整存储的转录本，直到完整转录本或所有匹配项可见。 **Summary** 渲染存储的 Markdown 注释，并将转录部分保存在单独的 **Transcript** 选项卡中，并标记模型生成的或启发式出处（如果可用）。通过演讲开始会议但没有保存摘要，会自动请求生成具有写入权限的操作员。在音符到达之前，生成状态保持可见；失败提供重试。缺失的摘要和空的成绩单具有明显的空状态。保存的摘要独立于语音页面加载。如果成绩单页面超出其传输限制，您仍然可以阅读已保存的笔记并在下面的导出限制内下载导出内容。

**下载 Markdown** 下载文字记录和任何存储的摘要； **Download JSONL** 下载读者的公共话语投影，包括全文、序列、话语和说话者身份、源时间戳和最终性（如果有）。排除提供商私有元数据和本地文件系统路径；本地 CLI 导出保留其现有的原始格式。浏览器导出限制为 4 MiB，并且会明显失败，而不是下载部分文件。对于较大的导出，请使用 [ 转录本 CLI](/cli/transcripts)。存档访问需要 `operator.read` 或其 write/admin 含义以及允许读取共享存档的配置文件；代理过滤器不会绕过该限制。

如果图书馆读取或下载报告被拒绝访问，浏览器将清除其缓存的图书馆和读者页面。 **Retry** 会隐藏这些注释，直到收到新的授权响应为止，并从第一页开始阅读，无论选择的是 **Summary** 还是 **Transcript**。仅临时网络错误不会删除已加载的阅读器页面。已下载的文件仍归您所有。

在 **设置 → 通信 → 会议 capture** 中配置捕获，它也链接回库。从会议打开时，**返回应用程序** 返回到相同的会议和库过滤器。管理员可以更改现有的 `transcripts.enabled` 设置并添加、编辑或删除 `transcripts.autoStart` 源。编辑通过共享配置草稿保留帐户和源定位器、标题和自定义会话 ID。表单更改通过标准设置协调器自动保存，包括验证和冲突处理。如果重新启动中断了待处理的草稿，页脚将显示 **Autosave 在重新连接后暂停**；查看保留的草稿并选择 **Save** 以在新连接上提交它。 **Messages** 保留默认的通信部分。完整的记录模式编辑器可在 **会议捕获 → 高级设置** 下找到。

仅标题编辑可保持当前捕获运行并将新标题应用于将来的捕获；当前和保存的笔记不会被重命名。连续捕获支持可选的自定义会话 ID。将生成的 ID 保留为空，并避免重复使用同一天的 ID，这可能会与现有存档条目发生冲突。占用模式自动选择会话 ID，并忽略自定义 ID 字段。编辑器在占用模式下禁用该字段，同时保留其保存的值。运行状况将启动重试与无法安全重试的捕获尝试区分开来。请参见 [ 捕获配置 ](/cli/transcripts#configuration)。

即使在运行时加载之前，也会为新源提供具有显式自动启动设置元数据的已启用插件清单。观察到的运行时间 `canStart: false` 会阻止新的设置。清单声明了支持和必需的定位器字段。当元数据不可用时，现有条目仍然可编辑，不会丢失字段。仅附加到已处于活动状态的会议机器人的提供程序不会作为引导自动启动源提供。

捕获是语音通道的选择加入：加入语音不会录制，录制参与者不会授予命令或代理权限。 **Enabled** 允许捕获； **Armed** 报告已注册订阅，未确认录制。 **未激活** 和 **Unknown** 保持不同。当保留的清理后的 URL 无法证明原始邀请身份时，配置的 URL 源仍然未知。保存的话语计数来自持久行。最新保存的文字记录是最近更新的包含话语的会话，而不是确切的最后摄取顺序。源语音时间被明确标记；不记录摄取时间戳。连续源可能跨越多个房间。启用占用模式后，捕获会在房间清空时保存注释，并且当已知生成其存储的 ID 源时，可以在十分钟内继续从同一源和代理最近停止的捕获。提供的或未知的来源开始新的捕获，使现有的注释保持不变。语音转文本可能会使用您配置的提供商并导致提供商使用。 UI 不会播放原始音频、按需生成摘要或删除文字记录。

会议读取与 `openclaw transcripts` 相同的共享 SQLite 记录。 Discord 语音和 Google Meet、Microsoft Teams 和 Zoom 会议插件填充此商店。有关捕获设置、代理读取和导出的信息，请参阅 [ 脚本 CLI](/cli/transcripts)。

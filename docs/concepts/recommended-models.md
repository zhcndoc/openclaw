# <a id="recommended-models"></a> 推荐模型

OpenClaw 保留一份全球有序的推荐模型列表。它首先命名 OpenClaw 建议的模型，与哪个提供商为它们提供服务无关，因此一个条目涵盖了为该模型提供服务的每个提供商。提供商还可以发布自己的特色列表，该列表引导该提供商的推荐。

维护人员在 [`scripts/lib/recommended-models.json`](https://github.com/openclaw/openclaw/blob/main/scripts/lib/recommended-models.json) 中手动整理列表，并通过审查拉取请求来更改它。自动建议是一个起点；审稿人的编辑是事实的来源。

当 [ 托管目录 ](/concepts/models#hosted-catalog-updates) 发布时，每个提供商的服务模型 ID 都会与列表进行匹配；已弃用、已禁用和已替换的行永远不会匹配。目录 v2 将匹配项列为该提供商的 `recommendedModels`，按列表顺序并在提供商自己的 ID 下。当提供商为一个系列的多个列出的模型提供服务时，只会显示最新的模型。没有匹配目录行的提供者不会获得任何列表，并且目录 v1 不会包含任何列表。模型选择器首先列出提供商推荐的模型，然后将其其他模型折叠到**所有模型**下；请参见 [ 模型 ](/concepts/models#selection-source-and-fallback-strictness)。

升级后，兼容的存储目录仍然可以提供建议，即使它比已安装的版本更旧。不使用其旧模型行和价格。选择器仅将建议与当前可用的行进行匹配，因此建议无法恢复已停用或隐藏的模型。

## <a id="provider-featured-lists"></a> Provider 精选列表

一些提供商发布了他们想要展示的模型。 NVIDIA 目前唯一；它的提要是 `https://assets.ngc.nvidia.com/products/api-catalog/featured-models.json`。在发布时，每个特色 ID 通过规范化 ID 与该提供商提供的服务行进行匹配，因此 `z-ai/glm-5-3` 与 `z-ai/glm-5.3` 匹配。该提供商的 `recommendedModels` 首先按 Feed 顺序并在其自己的 ID 下列出其特色模型，然后是全局列表中尚未包含的匹配项。

提供商选择所列的获胜者：家庭规则只会修剪全局部分，因此即使提供商还为其家族中较新列出的成员提供服务，特色模型也会保留。提供程序不提供的特色 ID，或仅作为已弃用、禁用或替换的行，将被跳过并记录。当提要不可用、格式错误、为空或与所提供的模型不匹配时，提供程序将单独获取全局列表。

## <a id="entry-format"></a> 条目格式

该文件是规范化模型 ID 的 JSON 数组，最好放在第一位。它仅包含 ID：没有分数、提供者或评论。

规范化 ID 是模型的供应商中立名称：

- 小写，没有供应商或路由前缀（`claude-opus-5.5`，而不是 `anthropic/claude-opus-5.5`）
- 点版本（`claude-opus-4.5`，不是 `claude-opus-4-5`；`glm-5.3`，不是 `glm-5p3`）
- 无发布日期、修订标记或服务变体，例如 `-fp8`、`-free` 或 `-batch`

当 OpenClaw 的 id 规范化会更改条目、某个条目出现两次或列表超过 200 个条目时，发布失败。之前托管的目录将保留在原处。

## <a id="review-rules"></a> 审核规则

**Family.** 模型的系列是去掉版本号的 id：`gpt-5.6-luna` 和 `gpt-6-luna` 都是 `gpt-luna`； `qwen3.8-27b` 保持其尺寸，为 `qwen-27b`。

**Successor.** 同一系列中的较新版本是后续版本。它采用了其前身的立场，包括在发布当天；无需等待使用数据。保留前任列表，而某些提供商仅服务于前任；为两者提供服务的提供者仅显示后继者。

**新类别。** 家族名称与每个列出的家族不同的模型（例如新的 `-mini` 或 `-pro` 等级）是一个新类别，绝不是自动后继者。审阅者决定它是否属于列表以及位置。

**快速变体。** `-fast`、`-highspeed` 和类似的服务变体折叠到基本模型中。仅列出基本 ID。

**Dropping.** 当供应商弃用或废弃某个条目，或者为该条目提供服务的每个提供商也为其后继者提供服务时，删除该条目。

**Ordering.** 从模型的竞技场代理得分开始，然后通过观察到的使用情况打破平局并填补空白。审阅者可以移动任何条目；人类的判断凌驾于这两个信号之上。

# <a id="session-search"></a> 会话搜索

`sessions_search` 在可见的过去会话中搜索用户和助理文本。每个结果都包含 `sessionKey`、时间戳、角色和简短的匹配摘录。将返回的 `sessionKey`、`messageId` 和 `sessionId` 一起传递给 `sessions_history` 以重新打开匹配的上下文，包括会话重置之前保留的历史记录。如果没有 `messageId`，历史记录将返回最新的重置相关尾部。保留在当前视图中的显式 `messageId`（包括重置后保留的预重置行）保留当前视图行为，并且可以包括稍后的重置后轮流。当前视图外部保留的活动路径行的显式 `messageId` 打开原始闭合间隔，并且不会混合稍后的重置后轮流。

锚定读取使用 `limit` 来绑定周围的消息。使用锚时省略 `offset`。对于 SQLite 转录历史记录，丢失或偏离路径的消息返回空历史记录而不是最新的尾部；不属于所选会话密钥的 `sessionId` 将被拒绝。这些规则也适用于本地嵌入模式，无需运行网关。

## <a id="visibility-and-output"></a> 可见性和输出

搜索使用与 `sessions_history` 相同的配置会话可见性规则。默认值 `tools.sessions.visibility: "all"` 允许未沙盒的呼叫者在网关上跨代理搜索会话，包括其他用户的对话。跨代理访问默认处于启用状态，并受 `tools.agentToAgent` 管辖；设置 `enabled: false` 以阻止普通的跨代理访问或使用 `allow` 限制代理对（请求者拥有的本机子代理和 ACP 子会话在 `tree` 或 `all` 下保持可访问）。当呼叫者需要更窄的会话可见性时，设置显式 `agent`、`tree` 或 `self`。每对等 DM 路由分隔对话上下文，但不限制会话工具可见性。

在应用结果限制之前，调用者有效可见范围之外的结果将被删除。当启用生成会话可见性时，沙盒代理仍仅限于它们生成的会话。隐身会话仍然被排除在外； `all` 缩小可见性会阻止普通的跨代理访问。

摘录保留转录文本，包括凭据。结果受计数、摘录长度和总响应大小的限制。

每个笔录搜索请求最多允许 90 秒，为读者的 60 秒预算（包括工作人员准入）留出调度和授权空间。如果超时，请使用 `sessionKey` 重试 `sessions_search` 以搜索一个会话或多个特定查询关键字。超时并不意味着不存在匹配的会话。

## <a id="control-ui-search"></a> Control UI 搜索

命令选项板和线程页面将其会话过滤器发送到网关，网关搜索该范围内的完整授权索引历史记录。浏览器不会下载会话名册来选择要搜索的记录，并且名册页面大小不会排除较旧的匹配会话。

标题搜索将标点符号和重复的空格视为单词分隔符，因此 `per session communi` 会找到标题为 **Per-session communicationscontrols** 的对话。在会话或消息下对结果进行分组时，命令选项板使用相同的匹配规则。标识符搜索保留其字面匹配。

Control UI 消息搜索匹配最终单词作为前缀，同时要求前面的单词完整。例如，`session communi` 查找 **会话通信**。面向代理的 `sessions_search` 工具保持精确的单词匹配。

在您切换到另一个对话后，命令选项板还可以按标题或文字记录分配给自定义侧边栏组的客服人员创建的对话。未分组的生成会话和子代理运行仍然从调色板中排除。群组不会授予对私人对话的访问权限，也不会将隐身或存档会话包含在主动搜索中。

搜索返回一组有界的最佳匹配。匹配数超过结果限制是正常的，而不是不完整索引警告；优化查询以缩小结果范围。真正的索引工作和从搜索中排除的冷存档抄本具有单独的状态消息。当打开其会话并恢复历史记录时，冷记录历史记录将再次变得可搜索。搜索不会自动恢复存档的历史记录。

## <a id="index-lifecycle"></a> 索引生命周期

OpenClaw 将全文索引存储在每个 agent 的 SQLite 数据库中，与转录记录行并列。 新的用户和助手消息会在持久化它们的同一事务中被索引，因此索引不会落后于实时对话；工具结果、推理块和图像被排除在外。 只有转录的活动分支可被搜索。

早于索引生成的转录（例如通过 `openclaw doctor` 导入的会话）以及其活动分支已被回退的会话，会在下一次搜索开始时通过后台协调进行重新索引。 因此，带有 `indexing: true` 的响应可能是不完整的；请在索引完成后重试。 删除会话会在同一事务中移除其索引条目。

搜索使用 SQLite 的 Unicode 单词标记器并删除变音符号。

## <a id="session-search-vs.-memory-search"></a><a id="session-search-vs-memory-search"></a> 会话搜索 vs. 记忆搜索

使用 `sessions_search` 获取原始会话记录中的确切单词或短语。使用 [`memory_search`](/concepts/memory-search) 进行持久存储文件和语义回忆。 [ 实验会话记忆语料库 ](/concepts/memory-search#session-memory-search) 是对这种精确转录搜索的语义补充。
